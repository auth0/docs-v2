Learn the core concepts behind securing AI agents with Auth0.

<CardGroup>
  <Card title="User Authentication for AI Agents" href="/ai/docs/intro/user-authentication" icon="user-check">
    Integrate Auth0 into your AI agents to secure user authentication with social, enterprise, and custom identity providers.
  </Card>
  <Card title="Delegated Authorization for AI Agents" href="/ai/docs/intro/delegated-authorization" icon="key">
    Enable your AI agents to call APIs on a user's behalf using OAuth 2.0, with access scoped to only what the user has explicitly consented to.
  </Card>
  <Card title="Call First-Party APIs on User's Behalf" href="/ai/docs/intro/call-first-party-apis-on-users-behalf" icon="lock">
    Enable your AI agents to securely call first-party APIs on behalf of authenticated users.
  </Card>
  <Card title="Call Third-Party APIs on User's Behalf" href="/ai/docs/intro/call-third-party-apis-on-users-behalf" icon="share-nodes">
    Enable your AI agent to call third-party APIs on the user's behalf with Token Vault.
  </Card>
  <Card title="Asynchronous Authorization" href="/ai/docs/intro/asynchronous-authorization" icon="bell">
    Enable AI agents to request user consent for sensitive actions via push notification, SMS, or email using CIBA, without interrupting the user's current session.
  </Card>
  <Card title="Authorization for RAG" href="/ai/docs/intro/authorization-for-rag" icon="database">
    Enforce fine-grained, document-level access control in RAG pipelines with Auth0 FGA, ensuring AI agents only retrieve data the current user is authorized to see.
  </Card>
