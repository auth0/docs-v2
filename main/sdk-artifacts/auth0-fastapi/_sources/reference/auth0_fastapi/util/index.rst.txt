.. py:function:: create_route_url(url: str, base: str) -> str

   Ensures route URLs are created correctly by removing the leading slash from the
   provided URL and ensuring the base URL has a trailing slash. Then uses urljoin
   to combine them.

   :param url: The URL (or path) to use.
   :param base: The base URL to use.

   :returns: A complete URL string combining the base and url.

.. py:function:: to_safe_redirect(dangerous_redirect: str, safe_base_url: str) -> Optional[str]

   Ensures that the redirect URL is safe to use by verifying that its origin matches
   the origin of the safe_base_url.

   :param dangerous_redirect: The redirect URL to check.
   :param safe_base_url: The base URL to check against.

   :returns: A safe redirect URL string if the origins match, or None otherwise.
