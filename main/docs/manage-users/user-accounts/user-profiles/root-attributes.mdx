---
title: Modifying User Profile Attributes
description: Learn about attributes available for the Auth0 normalized user profile and methods of updating them.
---

Auth0's [normalized user profile](/docs/manage-users/user-accounts/user-profiles/user-profile-structure) contains a number of root attributes (attributes stored at the first, or root, level of the object), some of which may be updated. The method to set and update attributes depends on whether you are using a connection with Auth0 as the <Tooltip tip="Identity Provider (IdP): Service that stores and manages digital identities." cta="View Glossary" href="/docs/glossary?term=Identity+Provider">identity provider</Tooltip> (IdP) or with an upstream IdP.

* When Auth0 is the IdP, you can:

  * Set attributes on user sign-up (via the Management API or public sign-up)
  * Set attributes on user import
  * Edit attributes via the Management API

  Auth0 is the IdP for [database connections](/docs/authenticate/database-connections) (both regular and custom with import mode on) and [passwordless connections](/docs/authenticate/passwordless).

* When using an upstream IdP, you have two options:

  * Use the default behavior. The upstream IdP sets attributes when users are first created and then automatically updates them with each subsequent login. These attributes are not directly editable because the IdP updates them each time the user logs in.

  * Configure connection sync with Auth0. The upstream IdP sets attributes only when users are first created but does not update them on subsequent logins, which means you can edit those attributes directly with the Management API.

  Upstream IdPs handle [social connections](/docs/authenticate/identity-providers#social), [enterprise connections](/docs/authenticate/identity-providers#enterprise), and [legal identity connections](/docs/authenticate/identity-providers#legal-identities).
