Register an agent as a first-class identity in Auth0 using the Auth0 Dashboard or Management API. Once registered, you can:

- Manage the agent using standard CRUD operations
- Associate the agent with M2M clients, issue tokens with agent identity, and track it in logs

## Required scopes

| Scope | Grants access to |
|---|---|
| `read:agents` | `GET /api/v2/agents`, `GET /api/v2/agents/{id}`, `GET /api/v2/agents/{id}/clients` |
| `create:agents` | `POST /api/v2/agents` |
| `update:agents` | `PATCH /api/v2/agents/{id}`, `POST /api/v2/agents/{id}/clients`, `DELETE /api/v2/agents/{id}/clients/{client_id}` |
| `delete:agents` | `DELETE /api/v2/agents/{id}` |

## GET /api/v2/agents

List all agents in the tenant.

**Query parameters:**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `take` | integer | 50 | Max records to return. Maximum: 100. |
| `from` | string | — | Pagination cursor from the previous response. |

**Response 200:**

```json
{
  "agents": [
    {
      "agent_id": "agt_72jbvv7LfRKYp59gtRLtkn",
      "external_agent_id": null,
      "name": "recommendation-agent-prod",
      "metadata": { "env": "prod" },
      "created_at": "2026-04-01T00:00:00.000Z",
      "updated_at": "2026-04-01T00:00:00.000Z"
    }
  ],
  "next": "MjAyNS0wNS0yMFQxMjow"
}
```

## POST /api/v2/agents

Create a new agent.

**Request body:**

```json
{
  "name": "recommendation-agent-prod",
  "external_agent_id": "my-org-agent-042",
  "metadata": {
    "env": "prod",
    "team": "personalization"
  }
}
```

| Field | Required | Notes |
|---|---|---|
| `name` | Yes | 1–255 characters. |
| `client_id` | No | Associate an existing M2M client on creation. |
| `external_agent_id` | No | Can only be set at creation time — not modifiable afterward. |
| `metadata` | No | JSON, limit 10 KB. |

**Responses:**

| Status | Meaning |
|---|---|
| 201 | Agent created. |
| 400 | Validation error (see [error codes](#error-reference)). |
| 409 | The specified `client_id` is already associated with another agent. |

## GET /api/v2/agents/{id}

Retrieve a single agent by ID.

**Responses:**

| Status | Meaning |
|---|---|
| 200 | Agent object. |
| 404 | Agent not found. |

## PATCH /api/v2/agents/{id}

Partial update. Applies a wholesale replacement to `metadata` — no merge. `external_agent_id` cannot be set or changed via this endpoint.

**Request body (all fields optional):**

```json
{
  "name": "recommendation-agent-staging",
  "metadata": {
    "env": "staging"
  }
}
```

**Responses:**

| Status | Meaning |
|---|---|
| 200 | Updated agent object. |
| 400 | Validation error. |
| 404 | Agent not found. |

## DELETE /api/v2/agents/{id}

Delete an agent (soft delete). Idempotent.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
Deletion does not remove or modify associated M2M clients. Clients that reference the deleted agent continue to function normally but no longer carry agent identity in tokens or logs. To fully clean up, unset `agent_id` on associated clients separately via `PATCH /api/v2/clients/{id}`.
</Callout>

**Responses:**

| Status | Meaning |
|---|---|
| 204 | Deleted (or already did not exist). |

## Error reference

All `/api/v2/agents` endpoints return errors in the following format:

```json
{
  "statusCode": 400,
  "error": "Bad Request",
  "errorCode": "validation_failed",
  "message": "Human-readable description of the error."
}
```

| `errorCode` | Meaning |
|---|---|
| `invalid_body` | Request body failed schema validation. |
| `inexistent_client` | The `client_id` referenced does not exist in this tenant. |
| `inexistent_agent` | The `agent_id` referenced does not exist in this tenant. |
| `agent_conflict` | An agent with the provided name already exists. |
