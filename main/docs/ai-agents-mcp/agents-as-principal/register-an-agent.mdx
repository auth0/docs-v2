Register an agent as a first-class identity in Auth0 using the Auth0 Dashboard or Management API. Once registered, you can manage the agent with the Management API using the standard CRUD operations.

## Required scopes

Before registering an agent, make sure you enable the following permissions for your Management API access token:

| Scope | Grants access to |
|---|---|
| `read:agents` | `GET /api/v2/agents`, `GET /api/v2/agents/{id}`, `GET /api/v2/agents/{id}/clients` |
| `create:agents` | `POST /api/v2/agents` |
| `update:agents` | `PATCH /api/v2/agents/{id}`, `POST /api/v2/agents/{id}/clients`, `DELETE /api/v2/agents/{id}/clients/{client_id}` |
| `delete:agents` | `DELETE /api/v2/agents/{id}` |

## Create new agent

Create and register a new agent with the Auth0 Dashboard and Management API.

<Tabs><Tab title="Auth0 Dashboard">

1. Navigate to the **Dashboard > Agents** and select **Create New Agent**.
2. Enter a name for the agent. Select **Create**.

Once successfully created, the agent should have a unique `agent_id` with the `agt_` prefix. To view the agent's details, select **View Details**.

</Tab><Tab title="Management API">

Make a `POST` request to `/api/v2/agents`:

```bash
curl --request POST \
  --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN' \
  --data '{
    "name": "recommendation-agent-prod",
    "external_agent_id": "my-org-agent-042",
    "metadata": {
      "env": "prod",
      "team": "personalization"
    }
  }'
```

| Field | Required | Description |
|---|---|---|
| `name` | Yes | 1–255 characters. |
| `client_id` | No | Associate an existing M2M client on creation. |
| `external_agent_id` | No | Can only be set at creation time — not modifiable afterward. |
| `metadata` | No | JSON, limit 10 KB. |

If successful, you should receive a response body like the following:

```json
{
    "agent_id": "agt_sJsP2T4rLopMQMWz2eEGmW",
    "name": "recommendation-agent-prod",
    "metadata": {
        "env": "prod",
        "team": "personalization"
    },
    "created_at": "2026-07-28T21:40:01.395Z",
    "updated_at": "2026-07-28T21:40:01.395Z",
    "external_agent_id": "my-org-agent-042"
}
```

The following table lists the available response codes:

| Status | Description |
|---|---|
| 201 | Agent created. |
| 400 | Validation error (see [error codes](#error-reference)). |
| 409 | The specified `client_id` is already associated with another agent. |

</Tab></Tabs>

## List all agents in the tenant

Make a `GET` request to `/api/v2/agents`:

```bash
curl --request GET \
  --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents' \
  --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN'
```

**Query parameters:**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `take` | integer | 50 | Max records to return. Maximum: 100. |
| `from` | string | — | Pagination cursor from the previous response. |

If successful, you should receive a response like the following:

```json
{
    "agents": [
        {
            "agent_id": "agt_a7RfUjvzptDidRnj5J7Kga",
            "name": "my_test_agent",
            "metadata": {},
            "created_at": "2026-07-28T17:39:57.839Z",
            "updated_at": "2026-07-28T17:39:57.839Z"
        },
        {
            "agent_id": "agt_sJsP2T4rLopMQMWz2eEGmW",
            "name": "recommendation-agent-prod",
            "metadata": {
                "env": "prod",
                "team": "personalization"

            "created_at": "2026-07-28T21:40:01.395Z",
            "updated_at": "2026-07-28T21:40:01.395Z",
            "external_agent_id": "my-org-agent-042"

}
```

## Retrieve an agent by ID

Retrieve an agent by its `agent_id`. Make a `GET` request to `/api/v2/agents/{id}`: 

```bash
curl --request GET \
  --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents/<agent_id>' \
  --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN'
```
If successful, you should receive a response like the following:

```json
{
    "agent_id": "agt_sJsP2T4rLopMQMWz2eEGmW",
    "name": "recommendation-agent-prod",
    "metadata": {
        "env": "prod",
        "team": "personalization"
    },
    "created_at": "2026-07-28T21:40:01.395Z",
    "updated_at": "2026-07-28T21:40:01.395Z",
    "external_agent_id": "my-org-agent-042"
}
```

The following table lists the available response codes:

| Status | Meaning |
|---|---|
| 200 | Agent object. |
| 404 | Agent not found. |

## Update an agent

Partial update. Applies a wholesale replacement to `metadata`, not a merge. You cannot set or change the `external_agent_id` cannot be set via this endpoint.

Make a `PATCH` request to `/api/v2/agents/{id}`:

```bash
curl --request PATCH \
  --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents/<agent_id>' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN' \
  --data '{
    "name": "recommendation-agent-staging",
    "metadata": {
      "env": "staging"
    }
  }'
```

The following table lists the available response codes:

| Status | Meaning |
|---|---|
| 200 | Updated agent object. |
| 400 | Validation error. |
| 404 | Agent not found. |

## Delete an agent 

Delete an agent (soft delete). Idempotent.

Make a `DELETE` request to `/api/v2/agents/{id}`:

```bash
curl --request DELETE \
  --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents/<agent_id>' \
  --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN'
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
Deletion does not remove or modify associated M2M clients. Clients that reference the deleted agent continue to function normally but no longer carry agent identity in tokens or logs. To fully clean up, unset `agent_id` on associated clients separately via `PATCH /api/v2/clients/{id}`.
</Callout>

The following table lists the available response codes:

| Status | Meaning |
|---|---|
| 204 | Deleted (or already did not exist). |

## Error reference

All `/api/v2/agents` endpoints return errors in the following format:

```json
{
  "statusCode": 400,
  "error": "Bad Request",
  "errorCode": "validation_failed",
  "message": "Human-readable description of the error."
}
```
The following table lists the available error codes: 

| `errorCode` | Meaning |
|---|---|
| `invalid_body` | Request body failed schema validation. |
| `inexistent_client` | The `client_id` referenced does not exist in this tenant. |
| `inexistent_agent` | The `agent_id` referenced does not exist in this tenant. |
| `agent_conflict` | An agent with the provided name already exists. |
