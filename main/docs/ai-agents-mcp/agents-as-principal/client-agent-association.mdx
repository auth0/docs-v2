An agent has a many-to-one relationship with OAuth clients. A single agent can be backed by multiple M2M clients. The `agent_id` is stored on the client entity, and associations are managed dynamically.

## Associate a client at creation

`agent_id` can be set when creating a client via `POST /api/v2/clients`:

```json
{
  "name": "My AI Client",
  "agent_id": "agt_abc123XYZ"
}
```

## Retrieve the association

Once an `agent_id` association has been made, `GET /api/v2/clients/{id}` returns it in the response body:

```json
{
  "name": "My AI Client",
  "agent_id": "agt_abc123XYZ"
}
```

## Update the association

Existing clients can be associated with an agent via `PATCH /api/v2/clients/{id}`:

```json
{
  "agent_id": "agt_abc123XYZ"
}
```

## Remove the association

Set `agent_id` to `null` to dissociate a client from its agent:

```json
{
  "agent_id": null
}
```

After dissociation, new tokens issued by the client no longer carry agent identity. Existing tokens remain valid until expiry.
