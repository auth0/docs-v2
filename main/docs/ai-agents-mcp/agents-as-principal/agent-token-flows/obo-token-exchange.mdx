In the On-Behalf-Of (OBO) token exchange, a user authenticates and receives an access token scoped to the agent resource server. The agent-linked client then exchanges this token for a delegated token using the [On-Behalf-Of Token Exchange](/docs/secure/call-apis-on-users-behalf/on-behalf-of-token-exchange). The user remains the subject throughout — the agent is identified as the actor in the `act` claim.

## User access token (before exchange)

The user authenticates via a standard login flow. The resulting token has:

- `sub` — the user ID
- `sub_profile` — `user`
- `client_profile` — identifies the originating client as a `browser_app`
- `aud` — the agent resource server

```json
{
  "iss": "https://YOUR_AUTH0_DOMAIN/",
  "sub": "auth0|user123",
  "sub_profile": "user",
  "client_id": "spa-client-id",
  "client_profile": "browser_app",
  "aud": "https://ai-agent-resource-server.example.com",
  "scope": "read:data",
  "exp": 1711820300,
  "iat": 1711816700
}
```

## Token after exchange

The agent-linked client exchanges the user token. The resulting token has:

- `sub` — the user ID (unchanged)
- `sub_profile` — `user` (unchanged)
- `client_profile` — `service ai_agent`, representing the agent-linked M2M client
- `aud` — the new resource server
- `act` — the immediate actor (the agent), with a nested `act` showing the original client that initiated the flow

```json
{
  "iss": "https://YOUR_AUTH0_DOMAIN/",
  "sub": "auth0|user123",
  "sub_profile": "user",
  "client_id": "agent-client-id",
  "client_profile": "service ai_agent",
  "aud": "https://resource-api.example.com",
  "scope": "read:data",
  "cnf": { "jkt": "NzbLsXh8uDCcd7MNwrnNZpX0ak8ACQ" },
  "exp": 1711820400,
  "iat": 1711816800,
  "act": {
    "sub": "agt_1a2b3c",
    "sub_profile": "ai_agent",
    "client_id": "agent-client-id",
    "act": {
      "sub": "spa-client-id",
      "sub_profile": "browser_app",
      "client_id": "spa-client-id"
    }
  }
}
```

The maximum delegation depth is 5 hops (4 nested `act` levels).

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
Refresh tokens are not supported for the OBO token exchange. To learn more about setup and limitations, read [On-Behalf-Of Token Exchange](/docs/secure/call-apis-on-users-behalf/on-behalf-of-token-exchange).
</Callout>

The `sub_profile` and `client_profile` claims are only present when [enabled on the resource server](/docs/ai-agents-mcp/agents-as-principal/agent-token-flows#configure-resource-server-to-receive-agent-entity-profile-claims).
