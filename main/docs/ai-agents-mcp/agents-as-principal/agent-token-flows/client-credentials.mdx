An agent-linked M2M client performs a standard client credentials grant. The agent is the subject and authenticates as itself — there is no user involved.

## Issued token

```json
{
  "iss": "https://YOUR_AUTH0_DOMAIN/",
  "sub": "agt_1a2b3c",
  "sub_profile": "ai_agent",
  "client_id": "YOUR_CLIENT_ID",
  "client_profile": "service ai_agent",
  "aud": "https://your-resource-api.example.com",
  "scope": "read:data",
  "exp": 1711820400,
  "iat": 1711816800
}
```

The `sub` claim is the agent's `external_agent_id` if one was set at creation, otherwise it is the `agent_id`. The `sub_profile` and `client_profile` claims are only present when [enabled on the resource server](/docs/ai-agents-mcp/agents-as-principal/agent-token-flows#configure-resource-server-to-receive-agent-entity-profile-claims).
