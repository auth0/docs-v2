When a token is issued for an agentic interaction, the `agent_id` (or `external_agent_id`, when set) is included in the resulting tenant log entry.

## Covered grant types

Agent identity is recorded in logs for the following grant types:

- `client_credentials` grants from agent-linked clients
- `refresh_token` grants for agent-linked clients
- OBO token exchange grants
- Standard login grants where the client is agent-linked

## Query logs

The `agent_id` field is available via the Management API log endpoints, enabling per-agent audit and anomaly detection:

```http
GET /api/v2/logs?q=agent_id:agt_72jbvv7LfRKYp59gtRLtkn
```

To learn more about querying and streaming tenant logs, read [Log Search Query Syntax](/docs/deploy-monitor/logs/log-search-query-syntax) and [Export Log Events with Log Streaming](/docs/deploy-monitor/logs/export-log-events-with-log-streaming).
