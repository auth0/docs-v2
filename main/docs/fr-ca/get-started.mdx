Auth0 est une plateforme d’identité qui permet de gérer l’accès à vos applications.

Si vous débutez en gestion des identités et des accès (IAM), découvrez les notions de base et planifiez la solution qui convient le mieux à votre technologie et à vos besoins. Si vous connaissez déjà l’IAM, vous pouvez passer directement à la création.

***

<div id="start-building">
  ## Commencez à développer
</div>

Pour démarrer rapidement, choisissez votre type d’application et suivez un tutoriel Quickstart étape par étape.

<Columns cols={2}>
  <Card title="Application native/mobile" href="/docs/fr-ca/quickstart/native">
    Application mobile ou de bureau qui fonctionne nativement sur un appareil, comme iOS ou Android.
  </Card>

  <Card title="Application monopage" href="/docs/fr-ca/quickstart/spa">
    Application web JavaScript qui s’exécute dans le navigateur, comme AngularJS + Node.js ou React.
  </Card>

  <Card title="Application web traditionnelle" href="/docs/fr-ca/quickstart/webapp">
    Application web traditionnelle qui s’exécute sur le serveur, comme Express.js ou ASP.NET.
  </Card>

  <Card title="Backend/API" href="/docs/fr-ca/quickstart/backend">
    Une API ou un service protégé par Auth0, comme une Express.js API ou une API ASP.NET.
  </Card>

  <Card title="Agent IA" href="https://auth0.com/ai/docs">
    Un agent IA pour appeler des API externes au nom de l’utilisateur et utiliser des contrôles avec intervention humaine, comme LangChain ou LlamaIndex.
  </Card>
</Columns>
