Dans les flux d’[utilisateurs anonymes](/docs/fr-ca/manage-users/sessions/anonymous-sessions), où aucun utilisateur n’est authentifié, Auth0 offre un mécanisme permettant d’établir une session anonyme.

Auth0 émet un jeton de session et un [jeton d’accès](/docs/fr-ca/secure/tokens/access-tokens) en réponse à une requête [`/anonymous/token`](/docs/fr-ca/manage-users/sessions/anonymous-sessions#gather-anonymous-sessions-data). Pour en savoir plus, consultez [Configurer les sessions anonymes](/docs/fr-ca/manage-users/sessions/anonymous-sessions/configure-anonymous-sessions).

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  * Le jeton de session contient l’identité de l’utilisateur anonyme et les attributs relatifs à la session.
  * Le jeton d’accès est généralement un [JSON Web Token (JWT)](/docs/fr-ca/secure/tokens/json-web-tokens) dont les revendications peuvent être lues et traitées par un serveur de ressources (API), tandis que le jeton de session est opaque et ne peut être lu que par Auth0.
</Callout>

En règle générale, un utilisateur a besoin d’un nouveau jeton d’accès lorsqu’il accède à une ressource pour la première fois ou après l’expiration du jeton d’accès qui lui a été accordé précédemment.

Un jeton de session est un justificatif que votre application peut utiliser pour obtenir un nouveau jeton d’accès au besoin. Vous pouvez continuer à demander de nouveaux jetons d’accès jusqu’à l’expiration de [`anonymous_session_lifetime`](/docs/fr-ca/manage-users/sessions/anonymous-sessions/configure-anonymous-sessions#configure-anonymous-sessions-in-your-auth0-tenant).

<div id="session-token-benefits">
  ## Avantages du jeton de session
</div>

* Un jeton de session n&#39;est pas lié à l&#39;appareil qui a créé la session. Il peut être transféré et utilisé sur un autre appareil.

* Un jeton de session peut être inclus dans les requêtes d’autorisation, et les renseignements qu&#39;il contient sont accessibles dans [Actions](/docs/fr-ca/customize/actions/actions-overview) afin de compléter la transaction de connexion.
