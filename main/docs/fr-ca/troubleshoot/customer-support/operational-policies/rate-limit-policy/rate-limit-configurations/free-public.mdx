  <Accordion title="My Account API : Limites de requêtes pour les points de terminaison de My Account API dans le type d’abonnement Free.">
    Chaque point de terminaison de My Account API est encadré par deux politiques de limite de requêtes : une politique par tenant (portée : tenant, intervalle : seconde) comme garde-fou principal, et une politique par utilisateur (portée : tenant + utilisateur, intervalle : minute) comme garde-fou secondaire. Un petit nombre de politiques sont classées comme endpoint&#95;params — elles s’appliquent uniquement lorsqu’un paramètre de requête précis est présent (p. ex. ?type=) et partagent leur point de terminaison physique avec une politique sœur.

    Niveau du tenant :

    | Ressource                                                                       | Limite en rafale | Limite soutenue | Fréquence d’actualisation | Portée |
    | ------------------------------------------------------------------------------- | ---------------- | --------------- | ------------------------- | ------ |
    | My Account API Rate Limit – Authentication Methods Read (Tenant Scope)          | 2                | 2               | seconde                   | Tenant |
    | My Account API Rate Limit – Authentication Methods Read Filtered (Tenant Scope) | 5                | 5               | seconde                   | Tenant |
    | My Account API Rate Limit – Authentication Methods Write (Tenant Scope)         | 2                | 2               | seconde                   | Tenant |
    | My Account API Rate Limit – Connected Accounts Create Flow (Tenant Scope)       | 1                | 1               | seconde                   | Tenant |
    | My Account API Rate Limit – Connected Accounts Read Accounts (Tenant Scope)     | 1                | 1               | seconde                   | Tenant |
    | My Account API Rate Limit – Connected Accounts Read Connections (Tenant Scope)  | 1                | 1               | seconde                   | Tenant |
    | My Account API Rate Limit – Connected Accounts Write (Tenant Scope)             | 1                | 1               | seconde                   | Tenant |
    | My Account API Rate Limit – Factors Read (Tenant Scope)                         | 25               | 25              | seconde                   | Tenant |
    | My Account API Rate Limit – Organizations Read (Tenant Scope)                   | 5                | 5               | seconde                   | Tenant |

    Niveau tenant, utilisateur :

    | Ressource                                                                     | Limite en rafale | Limite soutenue | Fréquence d’actualisation | Portée              |
    | ----------------------------------------------------------------------------- | ---------------- | --------------- | ------------------------- | ------------------- |
    | My Account API Rate Limit – Authentication Methods Read (User Scope)          | 2                | 2               | minute                    | Tenant, utilisateur |
    | My Account API Rate Limit – Authentication Methods Read Filtered (User Scope) | 5                | 5               | minute                    | Tenant, utilisateur |
    | My Account API Rate Limit – Authentication Methods Write (User Scope)         | 2                | 2               | minute                    | Tenant, utilisateur |
    | My Account API Rate Limit – Connected Accounts Create Flow (User Scope)       | 10               | 10              | minute                    | Tenant, utilisateur |
    | My Account API Rate Limit – Connected Accounts Read Accounts (User Scope)     | 5                | 5               | minute                    | Tenant, utilisateur |

  <Accordion title="API SCIM : limites de requêtes pour les points de terminaison de l’API SCIM entrante dans les abonnements au cloud public qui comprennent des connexions d’entreprise.">
    Les limites de connexion et de locataire sont évaluées dans l’ordre à chaque requête : la limite de connexion est vérifiée en premier, et la limite de locataire n’est vérifiée que si la limite de connexion n’est pas dépassée.

    Niveau connexion, locataire :

    | Ressource | Limite en rafale | Limite soutenue | Fréquence d’actualisation | Portée |
    | --------- | ---------------- | --------------- | ------------------------- | ------ |

    Niveau locataire :

    | Ressource                                                                                    | Limite en rafale | Limite soutenue | Fréquence d’actualisation | Portée    |
    | -------------------------------------------------------------------------------------------- | ---------------- | --------------- | ------------------------- | --------- |
    | Limite anti-attaques de l’API SCIM – portée locataire (s’applique à tous les terminaux SCIM) | 5                | 5               | seconde                   | Locataire |
  </Accordion>

  <Accordion title="API My Organization : limites de taux pour l’API My Organization dans le type d’abonnement Free.">
    Limitation de débit à deux niveaux : bucket d’org (principal, qui détermine les en-têtes de réponse) + bucket de locataire (plafond secondaire pour toutes les orgs d’un locataire).

    Niveau du locataire :

    | Ressource                                                           | Limite en rafale | Limite soutenue | Fréquence de renouvellement | Portée    |
    | ------------------------------------------------------------------- | ---------------- | --------------- | --------------------------- | --------- |
    | My Org API Rate Limit – Terminaux de lecture (portée du locataire)  | 8                | 4               | seconde                     | Locataire |
    | My Org API  Rate Limit – Terminaux d’écriture (portée du locataire) | 4                | 2               | seconde                     | Locataire |

    Niveau de l’Organization :

    | Ressource                                                                | Limite en rafale | Limite soutenue | Fréquence de renouvellement | Portée       |
    | ------------------------------------------------------------------------ | ---------------- | --------------- | --------------------------- | ------------ |
    | My Org API Rate Limit – Terminaux de lecture (portée de l’Organization)  | 8                | 4               | seconde                     | Organization |
    | My Org API  Rate Limit – Terminaux d’écriture (portée de l’Organization) | 4                | 2               | seconde                     | Organization |
  </Accordion>
