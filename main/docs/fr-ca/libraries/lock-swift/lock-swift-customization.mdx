Vous trouverez ci-dessous de nombreuses options pour configurer le style et l&#39;apparence de Lock. De plus, plusieurs options permettent aussi de modifier le comportement et les fonctionnalités de Lock sur la page [Options de configuration du comportement](/docs/fr-ca/libraries/lock-swift/lock-swift-configuration-options).

## Personnaliser l’apparence de Lock {#customizing-locks-appearance}

Vous pouvez ajouter des options de personnalisation du style à l’initialisation de votre Lock à l’aide de `withStyle`.

```swift lines
Lock
  .classic()
  .withStyle {
	  $0.title = "Company LLC"
	  $0.logo = LazyImage(name: "company_logo")
	  $0.primaryColor = UIColor(red: 0.6784, green: 0.5412, blue: 0.7333, alpha: 1.0)
	}
  .present(from: self)
```

## Options de style pour l’en-tête {#header-style-options}

### headerBlur {#headerblur}

Style d’effet de flou utilisé. Peut prendre n’importe quelle valeur définie dans `UIBlurEffectStyle`.

```swift lines
.withStyle {
  $0.headerBlur = .extraLight
}
```

### headerColor {#headercolor}

Couleur utilisée pour l’arrière-plan de l’en-tête. Par défaut, il n’y a pas de couleur, seulement un effet de flou.

```swift lines
.withStyle {
  $0.headerColor = UIColor? = nil
}
```

### logo {#logo}

Image du logo dans l’en-tête. La résolution minimale recommandée est de 200 pixels (largeur) sur 200 pixels (hauteur).

```swift lines
.withStyle {
  $0.logo = LazyImage(name: "company_logo")
}
```

### headerCloseIcon {#headercloseicon}

L’icône « fermer » dans l’en-tête peut être modifiée.

```swift lines
.withStyle {
  $0.headerCloseIcon = LazyImage(name: "ic_close")
}
```

### headerBackIcon {#headerbackicon}

L’icône &quot;retour&quot; dans l’en-tête peut être modifiée.

```swift lines
.withStyle {
  $0.headerBackIcon = LazyImage(name: "ic_close")
}
```

## Options de style pour le titre {#title-style-options}

### hideTitle {#hidetitle}

Masque le titre de l’en-tête et affiche seulement le logo. Par défaut, cette option est définie à faux.

```swift lines
.withStyle {
  $0.hideTitle = false
}
```

### title {#title}

Texte du titre utilisé dans l’en-tête

```swift lines
.withStyle {
  $0.title = "Company LLC"
}
```

### titleColor {#titlecolor}

Couleur utilisée pour le titre de l’en-tête.

```swift lines
.withStyle {
  $0.titleColor = UIColor.black
}
```

## Options de style pour les boutons et les composants {#button-and-component-style-options}

### buttonTintColor {#buttontintcolor}

Couleur de teinte utilisée pour le bouton principal.

```swift lines
.withStyle {
  $0.buttonTintColor = UIColor.white
}
```

### disabledColor {#disabledcolor}

Couleur utilisée pour les composants désactivés de Lock.

```swift lines
.withStyle {
  $0.disabledColor = UIColor(red: 0.8902, green: 0.898, blue: 0.9059, alpha: 1.0)
}
```

### disabledTextColor {#disabledtextcolor}

Couleur utilisée pour le texte des composants désactivés de Lock.

```swift lines
.withStyle {
  $0.disabledTextColor = UIColor(red: 0.5725, green: 0.5804, blue: 0.5843, alpha: 1.0)
}
```

### hideButtonTitle {#hidebuttontitle}

Masquer le titre du bouton principal et afficher seulement l’icône. Par défaut, cette option vaut faux.

```swift lines
.withStyle {
  $0.hideButtonTitle = false
}
```

### primaryColor {#primarycolor}

Couleur utilisée comme couleur principale pour Lock.

```swift lines
.withStyle {
  $0.primaryColor = UIColor.orange
}
```

## Styles de la barre d’état {#status-bar-styles}

### UIStatusBarAnimation {#uistatusbaranimation}

L’animation de mise à jour de la barre d’état du Lock Controller.

```swift lines
.withStyle {
  $0.UIStatusBarAnimation = .none
}
```

### statusBarHidden {#statusbarhidden}

La visibilité de la barre d’état du Lock Controller.

```swift lines
.withStyle {
  $0.statusBarHidden = false
}
```

### UIStatusBarStyle {#uistatusbarstyle}

Le style de la barre d’état de Lock Controller.

```swift lines
.withStyle {
  $0.UIStatusBarStyle = .default
}
```

### UISearchBarStyle {#uisearchbarstyle}

Le style de la barre de recherche de Lock <Tooltip tip="Passwordless : forme d’authentification qui ne repose pas sur un mot de passe comme premier facteur." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Passwordless">Passwordless</Tooltip>.

```swift lines
.withStyle {
  $0.UISearchBarStyle = .default
}
```

### OAuth2 {#oauth2}

Toute connexion OAuth2 autre qu’une connexion de base de données peut avoir des styles personnalisés en mappant un nom de connexion à un `AuthStyle`

```swift lines
.withStyle {
  $0.oauth2["slack"] = AuthStyle(
    name: "Slack",
    color: UIColor(red: 0.4118, green: 0.8078, blue: 0.6588, alpha: 1.0),
    withImage: LazyImage(name: "ic_slack")
  )
}
```

### seperatorTextColor {#seperatortextcolor}
