Le SDK Auth0 pour PHP fournit une classe `Auth0\SDK\API\Management`, qui regroupe les méthodes permettant d’accéder à la [Management API](https://auth0.com/docs/api/management/v2) et d’effectuer des opérations sur votre tenant Auth0. Avec cette interface, vous pouvez facilement :

* Rechercher et créer des utilisateurs
* Créer et mettre à jour des applications
* Récupérer des entrées de journal
* Gérer des Rules

... et bien plus encore. Consultez notre [référence de l’API](https://auth0.com/docs/api/management/v2) pour voir tout ce qu’il est possible de faire !

<div id="authentication">
  ## Authentification
</div>

Pour utiliser la <Tooltip tip="Un produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>, vous devez vous authentifier de l’une des deux façons suivantes :

* Pour un accès temporaire ou pour faire des tests, vous pouvez [générer manuellement un jeton d’API](/docs/fr-ca/secure/tokens/access-tokens/management-api-access-tokens) et l’enregistrer dans votre fichier `.env`.
* Pour un accès prolongé, vous devez créer et exécuter un Client Credentials Grant lorsque l’accès est requis. Ce processus est détaillé sur la [page de l’Authentication API](/docs/fr-ca/libraries/auth0-php/using-the-authentication-api-with-auth0-php).

Quelle que soit la méthode, le jeton généré doit avoir les scopes requis pour les opérations que votre application doit exécuter. Consultez la [documentation de l’API](https://auth0.com/docs/api/management/v2) pour connaître les scopes requis pour le point de terminaison précis auquel vous essayez d&#39;accéder.

Pour accorder les scopes nécessaires :

1. Accédez à [APIs](https://manage.auth0.com/#/apis) &gt; Auth0 Management API &gt; onglet **Machine to Machine Applications**.
2. Repérez votre application et autorisez-la.
3. Cliquez sur la flèche pour développer la ligne et sélectionnez les scopes requis.

Vous pouvez maintenant vous authentifier de l’une des deux façons ci-dessus et utiliser ce jeton pour effectuer des opérations :

```php lines
$management = new \Auth0\SDK\API\Management\Wrapper\ManagementClient(
    new \Auth0\SDK\API\Management\Wrapper\ManagementClientOptions(
        domain: $_ENV['AUTH0_DOMAIN'],
        clientId: $_ENV['AUTH0_CLIENT_ID'],
        clientSecret: $_ENV['AUTH0_CLIENT_SECRET'],
    ),
);
```

Le `ManagementClient` expose les points de terminaison en tant que propriétés (par exemple, `$management->users` et `$management->clients`). Les résultats sont renvoyés sous forme d’objets typés — vous récupérez les valeurs en appelant des méthodes nommées (comme `getEmail()` ou `getName()`) plutôt qu’en désérialisant un array brut.

<div id="example-search-users-by-email">
  ### Exemple - Rechercher des utilisateurs par courriel
</div>

Ce point de terminaison est documenté [ici](https://auth0.com/docs/api/management/v2#!/Users/get_users).

```php lines
$users = $management->users->list(
    new \Auth0\SDK\API\Management\Users\Requests\ListUsersRequestParameters([
        'q'             => 'email:j*',
        'perPage'       => 5,
        'includeTotals' => true,
    ]),
);

foreach ($users as $user) {
    printf("%s <%s> - %s\n", $user->getNickname() ?? 'No nickname', $user->getEmail() ?? 'No email', $user->getUserId());
}
```

<div id="example-get-all-clients">
  ### Exemple - Obtenir tous les Clients
</div>

Ce point de terminaison est documenté [ici](https://auth0.com/docs/api/management/v2#!/Clients/get_clients).

```php lines
$clients = $management->clients->list(
    new \Auth0\SDK\API\Management\Clients\Requests\ListClientsRequestParameters([
        'perPage'       => 5,
        'includeTotals' => true,
    ]),
);

foreach ($clients as $client) {
    printf("%s - %s\n", $client->getName(), $client->getClientId());
}
```
