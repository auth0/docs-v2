<ParamField body="phoneCountryCode?" type="string">
  Le pays ISO 3166-1 alpha-2 sélectionné par l’utilisateur pour `phone` (par exemple, `'US'`), à partir d’un `code` dans `countryCodes.available`. Le pays transmis fait foi : le serveur y ajoute son indicatif, donc `phone` doit contenir le numéro national sans indicatif. Omettez ce champ pour conserver le comportement actuel, où le serveur détermine lui-même le pays et `pickCountryCode()` modifie la sélection sur un écran distinct.
</ParamField>
