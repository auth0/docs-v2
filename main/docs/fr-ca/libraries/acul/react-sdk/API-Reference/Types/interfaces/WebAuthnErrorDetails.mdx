---
title: "WebAuthnErrorDetails"
---

Détails d’une erreur WebAuthn du navigateur.

```ts Example
export interface WebAuthnErrorDetails {
  /**
   * Le nom de l'erreur (p. ex., « NotAllowedError »).
   */
  name: string;
  /**
   * Le message d'erreur.
   */
  message: string;
  /**
   * Toutes les propriétés d'erreur supplémentaires.
   */
  [key: string]: string | number | boolean | undefined;
}
```

## Indexable {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

Toute propriété supplémentaire de l’erreur.

<ParamField body="message" type="string">
  Le message d’erreur.
</ParamField>

</ParamField>
