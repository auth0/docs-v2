---
title: "Membres de l’utilisateur"
---

```ts Example
export interface UserMembers {
  id: string | null;
  email: string | null;
  username: string | null;
  phoneNumber: string | null;
  picture: string | null;
  enrolledFactors: Array<string> | null;
  enrolledEmails: Array<EnrolledEmail> | null;
  enrolledPhoneNumbers: Array<EnrolledPhoneNumber> | null;
  enrolledDevices: Array<EnrolledDevice> | null;
  organizations: Organizations[] | null; // OPT-IN 
  userMetadata: { [key: string]: string } | null; // OPT-IN
}
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  * OPT-IN : vous devez configurer explicitement ces propriétés pour les rendre disponibles à l’écran. Pour en savoir plus, consultez [Configurer ACUL](/docs/fr-ca/customize/login-pages/advanced-customizations/configure).

  * Lorsque le serveur Auth0 n’a pas connaissance de l’utilisateur actuel, les propriétés `user` ne sont pas disponibles dans les écrans suivants :

  | Écrans                          | Écrans                       | Écrans                          | Écrans                                 |
  | ------------------------------- | ---------------------------- | ------------------------------- | -------------------------------------- |
  | Écrans Login                    | Écrans MFA OTP               | Écrans Accepter l’invitation    | Écrans InterstitialCaptcha             |
  | Écrans Signup                   | Écrans MFA Phone             | Écrans Device Code              | Écrans Réinitialiser le mot de passe   |
  | Écrans Passkey                  | Écrans MFA Push              | Écrans Vérification de l’e-mail | Écrans MFA Country Codes               |
  | Écrans Challenge                | Écrans MFA Recovery Code     | Écrans Logout annulé            | Écrans MFA Detect Browser Capabilities |
  | Écrans Identifiant d’e-mail     | Écrans MFA WebAuthn          | Écrans Logout terminé           | Écrans MFA Enroll                      |
  | Écrans Identifiant de téléphone | Écrans Accepter l’invitation | Écrans Brute Force Protection   |                                        |
</Callout>
