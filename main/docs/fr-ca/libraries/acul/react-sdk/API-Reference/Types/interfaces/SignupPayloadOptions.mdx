<ParamField body="phoneCountryCode?" type="string">
  Le pays ISO 3166-1 alpha-2 que l’utilisateur a sélectionné pour `phoneNumber` (par exemple, `'US'`), à partir d’un `code` dans `countryCodes.available`. Le pays soumis fait foi : le serveur ajoute son indicatif téléphonique; `phoneNumber` doit donc être le numéro national, sans indicatif. Omettez-le pour conserver le comportement existant, où le serveur détermine lui-même le pays et `pickCountryCode()` modifie la sélection dans un écran distinct.
</ParamField>
