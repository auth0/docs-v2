---
title: "ThemeIdentifiers"
---

```ts Example
export interface ThemeIdentifiers {
  loginDisplay?: 'unified' | 'separate';
  otpAutocomplete?: boolean;
  phoneDisplay?: {
    masking?: 'show_all' | 'hide_country_code' | 'mask_digits';
    formatting?: 'regional' | 'international';
  };
}
```

## Propriétés {#properties}

<ParamField body="loginDisplay?" type="&#x22;unified&#x22; | &#x22;separate&#x22;">
  Disposition des champs d&#39;identifiant sur les écrans de connexion et d&#39;inscription. `'unified'` affiche un seul champ qui accepte n&#39;importe quel identifiant activé; `'separate'` affiche un champ par identifiant activé.
</ParamField>

<ParamField body="otpAutocomplete?" type="boolean" />

<ParamField body="phoneDisplay?" type="object">
  <Expandable title="propriétés">
    <ParamField body="formatting?" type="&#x22;regional&#x22; | &#x22;international&#x22;">
      Mise en forme d&#39;un numéro de téléphone déjà saisi lors de son affichage : `'regional'` suit la convention nationale du pays du numéro, `'international'` inclut l&#39;indicatif téléphonique.
    </ParamField>

    <ParamField body="masking?" type="&#x22;show_all&#x22; | &#x22;hide_country_code&#x22; | &#x22;mask_digits&#x22;">
      Portion d&#39;un numéro de téléphone déjà saisi qui est dévoilée lorsqu&#39;il est réaffiché à l&#39;utilisateur.
    </ParamField>
  </Expandable>
</ParamField>
