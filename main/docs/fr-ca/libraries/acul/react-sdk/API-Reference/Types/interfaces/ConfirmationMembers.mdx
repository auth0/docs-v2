---
title: "ConfirmationMembers"
---

Interface décrivant les membres de l’écran de confirmation.

```ts Example
export interface ConfirmationMembers extends BaseMembers {
  /**
   * Poursuit la création du compte après la vérification de l'OTP.
   * @param payload Options personnalisées facultatives à inclure avec la requête.
   */
  proceedToSignup(payload?: CustomOptions): Promise<void>;

  /**
   * Refuse l’inscription automatique et ramène l'utilisateur au écran de connexion sans créer de compte.
   * @param payload Options personnalisées facultatives à inclure avec la requête.
   */
  goBack(payload?: CustomOptions): Promise<void>;
}
```
