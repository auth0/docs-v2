Options pour effectuer des opérations de connexion avec un fournisseur d’identité sociale

```ts Example
export interface FederatedLoginOptions {
  /** Le nom de la connexion sociale à utiliser */
  connection: string;
  /** Toute option personnalisée supplémentaire */
  [key: string]: string | number | boolean;
}
```
