---
title: "ExperimentMembers"
---

Interface décrivant l’expérimentation [Experiment Center](/docs/fr-ca/customize/experiment-center) active attribuée à l’écran actuel.

```ts Example
export interface ExperimentMembers {
  experimentId: string;
  variationId: string;
  variationName: string | null;
  variationDescription: string | null;
  config: { [key: string]: unknown };
  isControl: boolean;
}
```

## Propriétés {#properties}

<ParamField body="config" type="Record">
  Configuration résolue pour la variation attribuée. Chaque clé correspond à un nom de configuration (par exemple, `'show_passkey'`) défini par l&#39;expérimentation.

  Chaque entrée est encapsulée sous la forme `{ value: <resolved value> }`. Lisez la valeur avec `config['<key>']?.value` plutôt que l&#39;entrée elle-même, car l&#39;objet d&#39;encapsulation est toujours évalué comme vrai.

  Le modèle `Experiment` convertit un `config` absent ou `null` en objet vide (`{}`); `config` n&#39;est donc jamais `null`.
</ParamField>

<ParamField body="experimentId" type="string">
  Identifiant unique de l&#39;expérimentation active.
</ParamField>

<ParamField body="isControl" type="boolean">
  Indique si la variation attribuée est la variation témoin.
</ParamField>

<ParamField body="variationDescription" type="string">
  Description lisible de la variation attribuée. Vaut `null` pour certaines variations.
</ParamField>

<ParamField body="variationId" type="string">
  Identifiant unique de la variation attribuée.
</ParamField>

<ParamField body="variationName" type="string">
  Nom lisible de la variation attribuée. Vaut `null` pour certaines variations.
</ParamField>
