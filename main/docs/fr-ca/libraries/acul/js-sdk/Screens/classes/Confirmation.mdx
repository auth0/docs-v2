---
title: "Confirmation"
description: "Décrit toutes les propriétés et méthodes permettant de personnaliser l’écran `confirmation` de Universal Login."
---

La classe Confirmation implémente les fonctionnalités de l’écran `confirmation`. Cet écran s’affiche après la vérification d’un OTP lorsqu’Auth0 détecte une possibilité d’inscription automatique, permettant à l’utilisateur de confirmer ou de refuser la création d’un compte.

  <img style={{maxHeight:"400px"}} src="/docs/images/cdy7uua7fh8z/ACUL/confirmation.png" alt="Écran de confirmation" />
</Frame>

<div id="constructors">
  ## Constructeurs
</div>

Créez une instance du gestionnaire d’écran de confirmation :

```typescript Example
import Confirmation from '@auth0/auth0-acul-js/confirmation';
const confirmationManager = new Confirmation();
await confirmationManager.proceedToSignup();
```

<div id="properties">
  ## Propriétés
</div>

<ParamField body="branding" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/BrandingMembers">BrandingMembers</a></span>}>
  Fournit des configurations liées à l’image de marque, comme le thème et les paramètres d’image de marque.

<ParamField body="client" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/ClientMembers">ClientMembers</a></span>}>
  Fournit des configurations liées au client, comme `id`, `name` et `logoUrl`, pour l’écran `confirmation`.
</ParamField>

<ParamField body="organization" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/OrganizationMembers">OrganizationMembers</a></span>}>
  Fournit des renseignements sur l’Organization de l’utilisateur, comme `id` et `name`.
</ParamField>

<ParamField body="prompt" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/PromptMembers">PromptMembers</a></span>}>
  Contient des données sur le prompt actuel du flux d’authentification.
</ParamField>

<ParamField body="screen" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/ScreenMembers">ScreenMembers</a></span>}>
  Contient des détails propres à l’écran `confirmation`, y compris sa configuration et son contexte.
</ParamField>

<ParamField body="tenant" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/TenantMembers">TenantMembers</a></span>}>
  Contient des données liées au tenant, comme `id` et les métadonnées associées.
</ParamField>

<ParamField body="transaction" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/TransactionMembers">TransactionMembers</a></span>}>
  Fournit des données propres à la transaction pour l’écran `confirmation`, comme les identifiants actifs et les états du flux.
</ParamField>

<ParamField body="untrustedData" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/UntrustedDataMembers">UntrustedDataMembers</a></span>}>
  Gère les données non fiables transmises au SDK, comme les données saisies par l’utilisateur pendant le flux de confirmation.
</ParamField>

<ParamField body="user" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/UserMembers">UserMembers</a></span>}>
  Détails de l’utilisateur actif, y compris `username`, `email` et `roles`.
</ParamField>

<div id="methods">
  ## Méthodes
</div>

<ParamField body="proceedToSignup" type="Promise<void>">
  Cette méthode confirme l’inscription automatique et poursuit la création du compte après la vérification par OTP.

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  await confirmationManager.proceedToSignup();
  ```
</ParamField>

<ParamField body="goBack" type="Promise<void>">
  Cette méthode refuse l’inscription automatique et ramène l’utilisateur à l’écran de connexion sans créer de compte.

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  await confirmationManager.goBack();
  ```
</ParamField>

<ParamField body="changeLanguage" type="Promise<void>">
  Cette méthode modifie la langue d’affichage de la page Universal Login.

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  confirmationManager.changeLanguage({
    language: 'fr',
  });
  ```

  **Paramètres de la méthode**

  <Expandable title="Paramètres">
    <ParamField body="options">
      [LanguageChangeOptions](/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/LanguageChangeOptions).
    </ParamField>

    <ParamField body="language" type="string" required>
      Le code de paramètres régionaux de la langue souhaitée (par exemple, `'en'`, `'fr'`, `'es'`).
    </ParamField>

    <ParamField body="persist?" type="&#x22;session&#x22;">
      Lorsque cette valeur est définie sur `'session'`, la langue sélectionnée est enregistrée pendant toute la session.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="getErrors" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/interfaces/Error">Error</a>[]</span>}>
  Cette méthode récupère le tableau des erreurs de transaction à partir du contexte, ou un tableau vide s’il n’y en a aucune.
</ParamField>
