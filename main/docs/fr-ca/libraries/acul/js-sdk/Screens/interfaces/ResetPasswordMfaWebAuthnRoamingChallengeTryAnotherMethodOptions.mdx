TryAnotherMethodOptions

```ts Example
export interface TryAnotherMethodOptions extends CustomOptions {
  /**
   * Facultatif. Si `true`, et si le contexte d'écran (`screen.showRememberDevice`)
   * indique que la mémorisation de l'appareil est une option, cela signale l'intention
   * de l'utilisateur de mémoriser ce navigateur/appareil.
   * @type {boolean | undefined}
   */
  rememberDevice?: boolean;
}
```

## Propriétés {#properties}

<ParamField body="rememberDevice?" type="boolean">
  Facultatif. Si `true` et que `screen.showRememberDevice` vaut aussi `true`,
  le SDK inclura `rememberBrowser=true` lors de la soumission du formulaire.
</ParamField>
