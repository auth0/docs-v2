<ParamField body="phoneCountryCode?" type="string">
  Le pays, au format ISO 3166-1 alpha-2, que l&#39;utilisateur a sélectionné pour `phone` (par exemple `'US'`), tiré d&#39;un `code` de `countryCodes.available`. Le pays soumis fait autorité : le serveur ajoute son indicatif en préfixe, donc `phone` doit être le numéro national, sans indicatif. Omettez-le pour conserver le comportement actuel, où le serveur déduit lui-même le pays et où `pickCountryCode()` modifie la sélection dans un écran distinct.
</ParamField>
