<ParamField body="phoneCountryCode?" type="string">
  Le pays ISO 3166-1 alpha-2 que l&#39;utilisateur a sélectionné pour `phoneNumber` (par exemple `'US'`), provenant d&#39;un `code` de `countryCodes.available`. Le pays soumis fait autorité : le serveur ajoute son indicatif téléphonique en préfixe, donc `phoneNumber` doit être le numéro national, sans indicatif. Omettez-le pour conserver le comportement actuel, où le serveur détermine lui-même le pays et où `pickCountryCode()` modifie la sélection dans un écran distinct.
</ParamField>
