---
title: "AvailableCountryCode"
---

```ts Example
export interface AvailableCountryCode {
  code: string;
  label: string;
  dialCode: string;
}
```

## Propriétés {#properties}

<ParamField body="code" type="string">
  Le code de pays ISO 3166-1 alpha-2 (par exemple, `"US"`). Soumis sous la forme `phoneCountryCode`. Non unique dans la liste — un pays ayant plusieurs indicatifs téléphoniques génère une entrée par indicatif.
</ParamField>

<ParamField body="dialCode" type="string">
  L&#39;indicatif téléphonique précédé du signe plus (par exemple, `"+1"`). Affichage seulement.
</ParamField>

<ParamField body="label" type="string">
  Le nom du pays, localisé selon la langue d&#39;affichage.
</ParamField>
