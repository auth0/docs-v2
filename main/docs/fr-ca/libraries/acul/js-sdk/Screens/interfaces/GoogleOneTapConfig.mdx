---
title: "GoogleOneTapConfig"
---

Configuration de Google One Tap / FedCM, fournie par le serveur dans `screen.data.google_one_tap`.

```ts Example
export interface GoogleOneTapConfig {
  client_id: string;
  nonce: string;
  context: string;
  itp_support: boolean;
  auto_select: boolean;
  cancel_on_tap_outside: boolean;
}
```

## Propriétés {#properties}

<ParamField body="auto_select" type="boolean">
  Lorsque `true`, les identifiants sont renvoyés automatiquement, sans interaction de l’utilisateur, si une seule session Google est disponible et a déjà donné son consentement.
</ParamField>

<ParamField body="cancel_on_tap_outside" type="boolean">
  Lorsque `true`, l’invite One Tap se ferme si l’utilisateur clique à l’extérieur. Définissez cette valeur sur `false` pour exiger une fermeture explicite.
</ParamField>

<ParamField body="client_id" type="string">
  L’ID client Google OAuth 2.0 de cette application.
</ParamField>

<ParamField body="context" type="string">
  Modifie le titre et les messages affichés dans l’invite One Tap. Valeurs acceptées : `"signin"` (par défaut), `"signup"`, `"use"`.
</ParamField>

<ParamField body="itp_support" type="boolean">
  Lorsque `true`, active la prise en charge d’Intelligent Tracking Prevention (ITP) pour les navigateurs Safari/WebKit qui limitent les témoins tiers.
</ParamField>

<ParamField body="nonce" type="string">
  Une valeur aléatoire utilisée pour associer les identifiants à cette session et prévenir les attaques par réinsertion.
</ParamField>
