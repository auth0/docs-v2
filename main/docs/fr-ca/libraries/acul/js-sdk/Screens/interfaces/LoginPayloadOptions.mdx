Options pour effectuer des opérations de connexion

```ts Example
export interface LoginOptions {
  /** L'identifiant de l'utilisateur, dans son orthographe d'origine. Facultatif si `identifier` est fourni. */
  username?: string;
  /** L'identifiant à utiliser pour la connexion. Facultatif si `username` est fourni — `identifier` a préséance si les deux sont fournis. */
  identifier?: string;
  /** Ce que contient `identifier` (ou `username`) — provient généralement de `screen.data.activeIdentifierType`. */
  identifierType?: IdentifierType;
  /** Le mot de passe servant à l'authentification */
  password: string;
  /** Pays au format ISO 3166-1 alpha-2 pour un identifiant téléphonique, provenant d'un `code` de `countryCodes.available`. */
  phoneCountryCode?: string;
  /** Valeur de CAPTCHA facultative, si elle est requise */
  captcha?: string;
  /** Toute option personnalisée supplémentaire */
  [key: string]: string | number | boolean | undefined;
}
```

## Indexable {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

Toute option personnalisée supplémentaire

## Propriétés {#properties}

<ParamField body="captcha?" type="string">
  Valeur de CAPTCHA facultative, si elle est requise
</ParamField>

<ParamField body="identifier?" type="string">
  L&#39;identifiant utilisé pour la connexion — courriel, nom d&#39;utilisateur ou téléphone, selon `identifierType`. Facultatif si `username` est fourni; si les deux sont fournis, `identifier` a préséance.
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/type-aliases/IdentifierType">IdentifierType</a></span>}>
  Ce que contient `identifier` (ou `username`). Généralement lu à partir de `screen.data.activeIdentifierType`. Omettez-le pour soumettre l&#39;identifiant sans type.
</ParamField>

<ParamField body="password" type="string">
  Le mot de passe servant à l&#39;authentification
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  Le pays ISO 3166-1 alpha-2 associé à un identifiant téléphonique, tiré d&#39;un `code` de `countryCodes.available`. Requis lorsque `identifierType` vaut `phone`. Transmettez le numéro national — l&#39;indicatif est ajouté côté serveur.
</ParamField>

<ParamField body="username?" type="string">
  L&#39;identifiant de l&#39;utilisateur, dans son orthographe d&#39;origine. Facultatif si `identifier` est fourni — requis sinon.
</ParamField>
