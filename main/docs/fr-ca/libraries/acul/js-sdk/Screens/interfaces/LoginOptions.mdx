---
title: "LoginOptions"
---

```ts Example
export interface LoginOptions {
  username?: string;
  identifier?: string;
  identifierType?: IdentifierType;
  phoneCountryCode?: string;
  captcha?: string;
  [key: string]: string | number | boolean | undefined;
}
```

## Indexable {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

## Propriétés {#properties}

<ParamField body="captcha?" type="string" />

<ParamField body="identifier?" type="string">
  L’identifiant de connexion — courriel, nom d’utilisateur ou numéro de téléphone, selon `identifierType`. Facultatif si `username` est fourni; si les deux sont fournis, `identifier` prévaut.
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/fr-ca/libraries/acul/js-sdk/Screens/type-aliases/IdentifierType">IdentifierType</a></span>}>
  Indique ce que contient `identifier` (ou `username`). Généralement obtenu à partir de `screen.data.activeIdentifierType`. Omettez-le pour envoyer l’identifiant sans en préciser le type.
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  Le code de pays ISO 3166-1 alpha-2 d’un identifiant téléphonique, provenant d’un `code` de `countryCodes.available`. Obligatoire lorsque `identifierType` est `phone`. Transmettez le numéro national — l’indicatif est ajouté côté serveur.
</ParamField>

<ParamField body="username?" type="string">
  L’identifiant de l’utilisateur, dans son orthographe d’origine. Facultatif si `identifier` est fourni — obligatoire autrement.
</ParamField>
