title: "SelectCountryCodeOptions"
---

Options permettant de sélectionner un indicatif de pays

```ts Example
export interface SelectCountryCodeOptions {
  /** Le code de pays (p. ex. 'US', 'GB') */
  country_code: string;
  /** L’indicatif téléphonique (p. ex. '+1', '+44') */
  phone_prefix: string;
  /** Toute option personnalisée supplémentaire */
  [key: string]: string | number | boolean | undefined;
}
```

## Indexable {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

Toute option personnalisée supplémentaire
