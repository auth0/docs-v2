L’objet `event` du déclencheur Actions custom-token-exchange fournit des renseignements contextuels sur l’exécution du déclencheur.

```json Event Object
{
  "secrets": {},
  "client": {
    "client_id": "string",
    "metadata": {},
    "name": "string"
  },
  "request": {
    "body": {},
    "geoip": {},
    "ip": "string",
    "method": "string"
  },
  "resource_server": {
    "identifier": "string"
  },
  "tenant": {
    "id": "string"
  },
  "transaction": {
    "requested_scopes": [],
    "requested_token_type": "string",
    "subject_token": "string",
    "subject_token_type": "string"
  }
}
```

<div id="eventtransaction">
  ## `event.transaction`
</div>

<ResponseField name="event.transaction" type="object">
  Détails sur la transaction d&#39;échange de jeton personnalisé en cours.

  <Expandable title="Propriétés d’event.transaction" defaultOpen>
    <ResponseField name="actor_token" type="string" post={["optional"]}>
      Le jeton d’acteur fourni dans la request d’échange de jetons.
    </ResponseField>

    <ResponseField name="actor_token_type" type="string" post={["optional"]}>
      Le type du jeton d’acteur fourni dans la demande d’échange de jeton.
    </ResponseField>

    <ResponseField name="actor_token_user" type="dictionary" post={["optional"]}>
      L’utilisateur représenté par le jeton d’acteur. Cette valeur n’est présente que si actor&#95;token&#95;type est urn:ietf:params:oauth:token-type:id&#95;token et que le jeton d’acteur fourni dans la demande d’échange de jetons est un jeton ID valide généré par Auth0.

      <Expandable title="propriétés de actor_token_user" defaultOpen>
        <ResponseField name="app_metadata" type="dictionary">
          Champs personnalisés qui stockent des renseignements sur un utilisateur et influencent son accès, comme le plan de soutien, les rôles de sécurité ou les groupes de contrôle d’accès.
        </ResponseField>

        <ResponseField name="created_at" type="string">
          Horodatage indiquant quand le profil utilisateur a été créé.
        </ResponseField>

        <ResponseField name="email" type="string" post={["optional"]}>
          (unique) Adresse courriel de l’utilisateur.
        </ResponseField>

        <ResponseField name="email_verified" type="boolean">
          Indique si l’utilisateur a vérifié son adresse courriel.
        </ResponseField>

        <ResponseField name="family_name" type="string" post={["optional"]}>
          Nom de famille de l’utilisateur.
        </ResponseField>

        <ResponseField name="given_name" type="string" post={["optional"]}>
          Prénom de l’utilisateur.
        </ResponseField>

        <ResponseField name="last_password_reset" type="string" post={["optional"]}>
          Horodatage indiquant la dernière réinitialisation ou modification du mot de passe de l’utilisateur. Ce champ n’existe pas lors de la création de l’utilisateur. Cette propriété est offerte uniquement pour les connexions Database.
        </ResponseField>

        <ResponseField name="name" type="string" post={["optional"]}>
          Nom complet de l’utilisateur.
        </ResponseField>

        <ResponseField name="nickname" type="string" post={["optional"]}>
          Surnom de l’utilisateur.
        </ResponseField>

        <ResponseField name="phone_number" type="string" post={["optional"]}>
          Numéro de téléphone de l’utilisateur.
        </ResponseField>

        <ResponseField name="phone_verified" type="boolean" post={["optional"]}>
          Indique si l’utilisateur a vérifié son numéro de téléphone.
        </ResponseField>

        <ResponseField name="picture" type="string" post={["optional"]}>
          URL menant à la [photo de profil de l’utilisateur](https://auth0.com/docs/users/change-user-picture).
        </ResponseField>

        <ResponseField name="updated_at" type="string">
          Horodatage indiquant la dernière mise à jour ou modification du profil de l’utilisateur.
        </ResponseField>

        <ResponseField name="user_id" type="string">
          (unique) Identifiant unique de l’utilisateur.
        </ResponseField>

        <ResponseField name="user_metadata" type="dictionary">
          Champs personnalisés qui stockent des renseignements sur un utilisateur sans incidence sur les ressources auxquelles il peut accéder, comme l’adresse professionnelle, l’adresse domiciliaire ou les préférences de l’utilisateur.
        </ResponseField>

        <ResponseField name="username" type="string" post={["optional"]}>
          (unique) Nom d’utilisateur de l’utilisateur.
        </ResponseField>

        <ResponseField name="enrolledFactors" type="array of objects" post={["optional"]}>
          Tableau des facteurs d’authentification auxquels l’utilisateur s’est inscrit.
        </ResponseField>

        <ResponseField name="multifactor" type="array of string" post={["optional"]}>
          Liste des fournisseurs d’authentification multifacteur (MFA) auprès desquels l’utilisateur est inscrit. Ce tableau est mis à jour lorsque l’utilisateur s’inscrit à la MFA et lorsqu’un administrateur réinitialise les inscriptions MFA d’un utilisateur.
        </ResponseField>

        <ResponseField name="identities" type="array of objects">
          Contient des renseignements récupérés auprès du fournisseur d’identité auprès duquel l’utilisateur s’est initialement authentifié. Les utilisateurs peuvent aussi associer leur profil à plusieurs fournisseurs d’identité; ces identités apparaîtront alors également dans ce tableau. Le contenu d’un objet de fournisseur d’identité varie selon le fournisseur.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="metadata" type="dictionary" post={["optional"]}>
      &#91;Accès anticipé&#93; Objet contenant des données partagées entre les Actions personnalisées pendant toute la durée d’une transaction.
    </ResponseField>

    <ResponseField name="scopes_demandés" type="array of string">
      Les scopes demandés (le cas échéant) fournis dans la demande d’échange de token.
    </ResponseField>

    <ResponseField name="type_de_jeton_demandé" type="string">
      Le type de token qu’Auth0 doit générer. Par exemple : urn:ietf:params:oauth:token-type:access&#95;token.
    </ResponseField>

    <ResponseField name="subject_token" type="string">
      Le jeton du sujet fourni dans la requête d’échange de jetons.
    </ResponseField>

    <ResponseField name="subject_token_type" type="string">
      Le type de subject&#95;token&#95;type fourni dans la requête d’échange de token.
    </ResponseField>
  </Expandable>
</ResponseField>
