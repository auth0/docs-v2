L’objet `event` du déclencheur Actions password-reset-post-challenge fournit des renseignements contextuels sur l’exécution du déclencheur.

```json Event Object
{
  "secrets": {},
  "authentication": {},
  "authorization": {
    "roles": []
  },
  "client": {
    "client_id": "string",
    "metadata": {},
    "name": "string"
  },
  "connection": {
    "id": "string",
    "name": "string",
    "strategy": "string"
  },
  "request": {
    "body": {},
    "geoip": {},
    "ip": "string",
    "method": "string",
    "query": {}
  },
  "stats": {
    "logins_count": 0
  },
  "tenant": {
    "id": "string"
  },
  "transaction": {},
  "user": {}
}
```
