L’objet `event` du déclencheur Actions custom-phone-provider fournit des informations contextuelles sur son exécution.

```json Event Object
{
  "secrets": {},
  "client": {
    "client_id": "string",
    "metadata": {},
    "name": "string"
  },
  "notification": {
    "as_text": "string",
    "as_voice": "string",
    "delivery_method": "string",
    "message_type": "string",
    "recipient": "string"
  },
  "request": {
    "geoip": {},
    "ip": "string",
    "method": "string"
  },
  "tenant": {
    "id": "string"
  },
  "user": {}
}
```

</div>

<ResponseField name="event.client" type="object">

  <Expandable title="propriétés de event.client" defaultOpen>
    <ResponseField name="client_id" type="string">
      L’ID client de l’application à laquelle l’utilisateur se connecte.
    </ResponseField>

    <ResponseField name="metadata" type="dictionary">
      Objet contenant d’autres propriétés de l’application.
    </ResponseField>

    <ResponseField name="name" type="string">

    </ResponseField>
  </Expandable>
</ResponseField>

<div id="eventconnection">
  ## `event.connection`
</div>

<ResponseField name="event.connection" type="object" post={["optional"]}>
  Renseignements sur la connexion utilisée pour authentifier l’utilisateur.

  <Expandable title="propriétés de event.connection" defaultOpen>
    <ResponseField name="id" type="string">
      L’identifiant unique de la connexion.
    </ResponseField>

    <ResponseField name="metadata" type="dictionary" post={["optional"]}>
      Métadonnées associées à la connexion.
    </ResponseField>

    <ResponseField name="name" type="string">
      Le nom de la connexion utilisée pour authentifier l’utilisateur (par exemple, `twitter` ou `some-g-suite-domain`).
    </ResponseField>

    <ResponseField name="strategy" type="string">
      Le type de connexion. Pour les connexions sociales, `event.connection.strategy === event.connection.name`. Pour les connexions d’entreprise, la stratégie peut être `waad` (Windows Azure AD), `ad` (Active Directory/LDAP), `auth0` (connexions de base de données), etc.
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="eventnotification">
  ## `event.notification`
</div>

<ResponseField name="event.notification" type="object">
  <Expandable title="propriétés de event.notification" defaultOpen>
    <ResponseField name="as_text" type="string">
      Le texte tel que nous l&#39;avons rendu, prêt à être envoyé par message texte.
    </ResponseField>

    <ResponseField name="as_voice" type="string">
      Le texte tel que nous l&#39;avons rendu, prêt à être envoyé comme message vocal.
    </ResponseField>

    <ResponseField name="code" type="string" post={["optional"]}>
      Le mot de passe à usage unique que nous avons généré pour ce message dans certains cas (p. ex. `otp_verify`, `otp_enroll`). S&#39;il est fourni, il est important de le communiquer à l&#39;utilisateur final.
    </ResponseField>

    <ResponseField name="delivery_method" type="string">
      Le mode de livraison du message. Peut être `text` ou `voice`.

      Valeurs autorisées : `text`, `voice`
    </ResponseField>

    <ResponseField name="from" type="string" post={["optional"]}>
      Le numéro de téléphone de l&#39;émetteur, conforme à la norme E.164.
    </ResponseField>

    <ResponseField name="locale" type="string" post={["optional"]}>
      Le paramètre régional utilisé pour rendre le message, par exemple `en_US`, tel que défini dans la spécification BCP-47.
    </ResponseField>

    <ResponseField name="message_type" type="string">
      Le type de message envoyé, comme `otp_verify` ou `blocked_account`.

      Valeurs autorisées : `otp_verify`, `otp_enroll`, `blocked_account`, `change_password`, `password_breach`
    </ResponseField>

    <ResponseField name="recipient" type="string">
      Le numéro de téléphone du destinataire, conforme à la norme E.164.
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="eventuser">
  ## `event.user`
</div>

<ResponseField name="event.user" type="dictionary">
  Objet décrivant l’utilisateur au nom duquel la transaction en cours a été initiée.

  <Expandable title="propriétés de event.user" defaultOpen>
    <ResponseField name="app_metadata" type="dictionary">
      Champs personnalisés contenant des renseignements sur un utilisateur qui influencent son accès, comme son plan de soutien, ses rôles de sécurité ou ses groupes de contrôle d’accès.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      Horodatage indiquant la date de création initiale du profil utilisateur.
    </ResponseField>

    <ResponseField name="email" type="string" post={["optional"]}>
      (unique) Adresse courriel de l’utilisateur.
    </ResponseField>

    <ResponseField name="email_verified" type="boolean">
      Indique si l’utilisateur a vérifié son adresse courriel.
    </ResponseField>

    <ResponseField name="family_name" type="string" post={["optional"]}>
      Nom de famille de l’utilisateur.
    </ResponseField>

    <ResponseField name="given_name" type="string" post={["optional"]}>
      Prénom de l’utilisateur.
    </ResponseField>

    <ResponseField name="last_password_reset" type="string" post={["optional"]}>
      Horodatage indiquant la dernière réinitialisation ou modification du mot de passe de l’utilisateur. Ce champ n’existe pas à la création de l’utilisateur. Cette propriété est offerte uniquement pour les connexions de base de données.
    </ResponseField>

    <ResponseField name="name" type="string" post={["optional"]}>
      Nom complet de l’utilisateur.
    </ResponseField>

    <ResponseField name="nickname" type="string" post={["optional"]}>
      Surnom de l’utilisateur.
    </ResponseField>

    <ResponseField name="phone_number" type="string" post={["optional"]}>
      Numéro de téléphone de l’utilisateur.
    </ResponseField>

    <ResponseField name="phone_verified" type="boolean" post={["optional"]}>
      Indique si l’utilisateur a vérifié son numéro de téléphone.
    </ResponseField>

    <ResponseField name="picture" type="string" post={["optional"]}>
      URL pointant vers la [photo de profil de l’utilisateur](https://auth0.com/docs/users/change-user-picture).
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      Horodatage indiquant la dernière mise à jour ou modification du profil de l’utilisateur.
    </ResponseField>

    <ResponseField name="user_id" type="string">
      (unique) Identifiant unique de l’utilisateur.
    </ResponseField>

    <ResponseField name="user_metadata" type="dictionary">
      Champs personnalisés contenant des renseignements sur un utilisateur qui n’ont aucune incidence sur ce à quoi il peut accéder, comme son adresse professionnelle, son adresse résidentielle ou ses préférences.
    </ResponseField>

    <ResponseField name="username" type="string" post={["optional"]}>
      (unique) Nom d’utilisateur de l’utilisateur.
    </ResponseField>

    <ResponseField name="identities" type="array of objects" post={["optional"]}>
      Contient des renseignements récupérés auprès du fournisseur d’identité auprès duquel l’utilisateur s’est initialement authentifié. Les utilisateurs peuvent également associer leur profil à plusieurs fournisseurs d’identité; ces identités figureront alors aussi dans ce tableau. Le contenu de chaque objet de fournisseur d’identité varie selon le fournisseur.
    </ResponseField>
  </Expandable>
</ResponseField>
