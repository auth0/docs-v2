L’objet `event` du déclencheur Actions post-login fournit des informations contextuelles sur l’exécution du déclencheur.

```json Event Object
{
  "secrets": {},
  "client": {
    "client_id": "string",
    "metadata": {},
    "name": "string"
  },
  "connection": {
    "id": "string",
    "name": "string",
    "strategy": "string"
  },
  "request": {
    "body": {},
    "geoip": {},
    "ip": "string",
    "method": "string",
    "query": {}
  },
  "stats": {
    "logins_count": 0
  },
  "tenant": {
    "id": "string"
  },
  "user": {}
}
```

<ResponseField name="event.agent" type="object" post={["optional"]}>
  &#91;Accès anticipé&#93; Informations sur l’agent intervenant dans ce flux. Défini lorsque le client qui s’authentifie est lié à un agent et que les agents en tant que principaux sont activés dans le tenant; `undefined` sinon.

      &#91;Accès anticipé&#93; Métadonnées libres sous forme de paires clé-valeur associées à l’agent. Toujours définies lorsque `agent` est présent; objet vide lorsque l’agent ne possède aucune métadonnée.

    <ResponseField name="name" type="string">
      &#91;Accès anticipé&#93; Le nom de l’agent, lisible par les humains.
    </ResponseField>
