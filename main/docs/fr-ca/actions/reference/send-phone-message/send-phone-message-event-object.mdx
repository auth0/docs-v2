L’objet `event` du déclencheur Actions send-phone-message fournit des renseignements contextuels sur son exécution.

```json Event Object
{
  "secrets": {},
  "message_options": {
    "action": "string",
    "code": "string",
    "message_type": "string",
    "recipient": "string",
    "text": "string"
  },
  "request": {
    "geoip": {},
    "ip": "string",
    "method": "string"
  },
  "tenant": {
    "id": "string"
  },
  "user": {}
}
```

<div id="eventsecurity_context">
  ## `event.security_context`
</div>

<ResponseField name="event.security_context" type="object" post={["optional"]}>
  Objet contenant des signatures d’empreintes. Il est disponible uniquement si le client utilise Cloudflare. L’empreinte JA3/JA4 peut être nulle ou vide dans certains cas. C’est le plus souvent le cas pour les requêtes HTTP, car JA3 et JA4 sont calculées lors de la négociation TLS. Elle peut aussi être vide lorsque le Worker envoie des requêtes dans la même zone ou vers une zone qui n’est pas proxyfiée (ou vers un tiers).

  <Expandable title="propriétés de event.security_context" defaultOpen>
    <ResponseField name="ja3" type="string" post={["optional"]}>
      Signature d’empreinte JA3. Elle est disponible uniquement si le client utilise une connexion TLS.
    </ResponseField>

    <ResponseField name="ja4" type="string" post={["optional"]}>
      Signature d’empreinte JA4. Elle est disponible uniquement si le client utilise une connexion TLS.
    </ResponseField>
  </Expandable>
</ResponseField>

<div id="eventuser">
  ## `event.user`
</div>

<ResponseField name="event.user" type="dictionary">

    <ResponseField name="family_name" type="string" post={["optional"]}>
      Nom de famille de l’utilisateur.

      Prénom de l’utilisateur.

    <ResponseField name="last_password_reset" type="string" post={["optional"]}>
      Horodatage indiquant la dernière réinitialisation ou modification du mot de passe de l’utilisateur. Ce champ n’existe pas lors de la création de l’utilisateur. Cette propriété est offerte uniquement pour les connexions à une base de données.
    </ResponseField>

    <ResponseField name="name" type="string" post={["optional"]}>
      Nom complet de l’utilisateur.

    </ResponseField>

      URL menant à la [photo de profil de l’utilisateur](https://auth0.com/docs/users/change-user-picture).
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      Horodatage indiquant la dernière mise à jour ou modification du profil de l’utilisateur.

    <ResponseField name="user_id" type="string">
      Identifiant unique de l’utilisateur.
    </ResponseField>

    <ResponseField name="user_metadata" type="dictionary">

Les utilisateurs peuvent aussi lier leur profil à plusieurs fournisseurs d’identité ; ces identités apparaîtront alors également dans ce tableau. Le contenu de chaque objet de fournisseur d’identité varie selon le fournisseur.
    </ResponseField>

</ResponseField>
