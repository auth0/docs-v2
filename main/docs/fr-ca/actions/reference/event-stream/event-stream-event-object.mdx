L’objet `event` du déclencheur event-stream d’Actions fournit des renseignements contextuels sur l’exécution du déclencheur.

```json Event Object
{
  "secrets": {},
  "message": {
    "id": "string",
    "type": "string",
    "source": "string",
    "specversion": "string",
    "a0tenant": "string"
  }
}
```

## `event.message` {#eventmessage}

<ResponseField name="event.message" type="object">
  Le message CloudEvent contenant toutes les propriétés de l’événement.

  <Expandable title="propriétés de event.message" defaultOpen>
    <ResponseField name="id" type="string">
      Identifie l’événement.
    </ResponseField>

    <ResponseField name="type" type="string">
      Décrit le type d’événement associé à l’occurrence d’origine.
    </ResponseField>

    <ResponseField name="data" type="dictionary" post={["optional"]}>
      Les données utiles de l’événement.
    </ResponseField>

    <ResponseField name="source" type="string">
      Identifie le contexte dans lequel l’événement s’est produit.
    </ResponseField>

    <ResponseField name="specversion" type="string">
      La version de la spécification CloudEvents utilisée par l’événement.
    </ResponseField>

    <ResponseField name="time" type="string" post={["optional"]}>
      Horodatage de l’occurrence. Doit respecter la norme RFC 3339.
    </ResponseField>

    <ResponseField name="a0tenant" type="string">
      L’identifiant du locataire Auth0 auquel l’événement est associé.
    </ResponseField>

    <ResponseField name="a0stream" type="string" post={["optional"]}>
      L’identifiant du flux d’événements Auth0 par lequel l’événement a été livré.
      Présent lorsque l’événement est livré par un flux d’événements; omis lorsque
      les événements sont récupérés au moyen de l’API Events (GET /api/v2/events).
    </ResponseField>

    <ResponseField name="a0purpose" type="string" post={["optional"]}>
      La raison d’être de cet événement. Défini uniquement dans des cas particuliers, comme un événement de test; omis pour les événements normaux.

      Valeurs permises : `test`
    </ResponseField>
  </Expandable>
</ResponseField>

</ResponseField>
