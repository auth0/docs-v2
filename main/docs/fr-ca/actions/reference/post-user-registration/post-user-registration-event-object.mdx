<div id="eventsecurity_context">
  ## `event.security_context`
</div>

<ResponseField name="event.security_context" type="object" post={["optional"]}>
  Objet contenant des signatures d’empreintes. Il est disponible uniquement si le client utilise Cloudflare. L’empreinte JA3/JA4 peut être null ou vide dans certains cas. C’est le plus souvent le cas pour les requêtes HTTP, car JA3 et JA4 sont calculées au niveau de TLS. Elle peut aussi être vide lorsqu’un Worker envoie des requêtes dans la même zone ou vers une zone non proxyfiée (ou vers un tiers).

  <Expandable title="propriétés de event.security_context" defaultOpen>
    <ResponseField name="ja3" type="string" post={["optional"]}>
      Signature d’empreinte JA3. Elle est disponible uniquement si le client utilise une connexion TLS.
    </ResponseField>

    <ResponseField name="ja4" type="string" post={["optional"]}>
      Signature d’empreinte JA4. Elle est disponible uniquement si le client utilise une connexion TLS.
    </ResponseField>
  </Expandable>
</ResponseField>
