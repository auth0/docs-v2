title: Aperçu de la référence des Actions
sidebarTitle: Aperçu
description: Consultez les objets event et api disponibles pour les Actions Auth0 de chaque déclencheur, y compris les données de transaction que vous pouvez lire et les méthodes que vous pouvez appeler dans votre code personnalisé.
---

Chaque Action Auth0 reçoit deux objets lorsque son déclencheur se déclenche :

* L’**objet event** fournit le contexte de transaction en lecture seule : des détails sur l’utilisateur, la requête, le client, le tenant et la connexion au moment où le déclencheur s’est déclenché.
* L’**objet api** expose les méthodes que votre Action peut appeler pour modifier le résultat de la transaction, par exemple pour refuser l’accès, ajouter des revendications au jeton, déclencher des défis ou mettre des données en cache.

Les objets disponibles varient selon le déclencheur. Sélectionnez un déclencheur ci-dessous pour consulter la référence de ses objets event et api. Pour savoir quand chaque déclencheur se déclenche et comment y associer des Actions, consultez [Explorer les déclencheurs](/docs/fr-ca/customize/actions/explore-triggers).
