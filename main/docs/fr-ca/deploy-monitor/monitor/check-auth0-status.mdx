validatedOn: 2026-02-04
---

Accédez à la page [Auth0 Public Cloud Status](https://status.auth0.com) pour vérifier la disponibilité du service de la version Public Cloud d’Auth0.

Sélectionnez une **Région** dans le menu déroulant pour voir l’état des services de base (comme l’authentification des utilisateurs et l’authentification machine à machine) et des services complémentaires (comme <Tooltip tip="Authentification multifacteur (MFA) : processus d’authentification de l’utilisateur qui utilise un facteur en plus du nom d’utilisateur et du mot de passe, comme un code envoyé par SMS." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=MFA">MFA</Tooltip>, <Tooltip tip="Management API : un produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>, les journaux du tenant et le CDN).

Pour en savoir plus sur les régions offertes, consultez la table [Région, localité et sous-localité](/docs/fr-ca/get-started/auth0-overview/create-tenants#region-locality-and-sub-locality) dans [Create Tenants](/docs/fr-ca/get-started/auth0-overview/create-tenants).

<div id="subscribe-to-public-cloud-status-updates">
  ## Abonnez-vous aux mises à jour sur l’état de Public Cloud
</div>

Sélectionnez une **Region**, puis **Subscribe** pour recevoir des mises à jour. Vous pouvez choisir entre deux options pour consulter l’état :

1. Suivez [@auth0status](https://x.com/auth0status) sur X pour obtenir les plus récentes mises à jour sur l’état.
2. Abonnez-vous au flux Atom ou RSS d’Auth0 pour recevoir les mises à jour sur l’état qui touchent votre tenant. Remplacez `{YOUR_TENANT_DOMAIN}` par le **Domain** de votre tenant.

Pour trouver le **Domain** de votre tenant, accédez à [Auth0 Dashboard &gt; Applications](https://manage.auth0.com/dashboard/#/applications), sélectionnez une application, puis accédez à **Settings**. Le **Domain** de votre tenant figure sous **Basic Information**.

<div id="check-auth0-status-for-private-cloud">
  ## Consulter l’état d’Auth0 pour Private Cloud
</div>

Accédez à [Auth0 Public Cloud Status](https://status.auth0.com), puis sélectionnez **Private Cloud Login**.

Une fois authentifié, vous pouvez consulter l’état de tout environnement hors développement (par exemple, `travel0-prod-1`) s’il est offert sur la plateforme convergée d’Auth0.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Pour accéder à l’état de votre environnement Private Cloud, vous devez être membre du tenant de soutien Public Cloud associé. Pour en savoir plus, veuillez consulter [Ouvrir et gérer des tickets de soutien](/docs/fr-ca/troubleshoot/customer-support/open-and-manage-support-tickets) et [Gérer l’accès au Dashboard](/docs/fr-ca/get-started/manage-dashboard-access).
</Callout>

Pour revenir à la page Auth0 Public Cloud Status, sélectionnez **Auth0 Public Cloud Status** dans le menu de navigation en haut à droite.

<div id="subscribe-to-private-cloud-status-updates">
  ## S’abonner aux mises à jour de l’état de Private Cloud
</div>

Sélectionnez un environnement, puis sélectionnez **Subscribe**.

Abonnez-vous au flux Atom ou RSS d’Auth0 en copiant l’URL générée dans la zone « Subscribe » afin de recevoir les mises à jour de l’état qui touchent votre environnement.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  L’URL du flux ATOM / RSS générée est propre à chaque environnement Private Cloud et contient des jetons qui peuvent être remplacés en [communiquant avec le soutien](https://support.auth0.com/).
</Callout>
