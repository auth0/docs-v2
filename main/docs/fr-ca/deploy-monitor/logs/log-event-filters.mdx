---
description: Filtrez les journaux Auth0 par type d’événement afin de faire ressortir les erreurs, les avertissements et les opérations réussies dans l’ensemble de votre tenant pour la surveillance et la réponse aux incidents.
title: Filtrer les événements du journal
---

Dans le [Dashboard](https://manage.auth0.com/#/logs), vous pouvez filtrer les journaux par erreurs, avertissements et événements de réussite en cliquant sur la flèche du menu déroulant **Filter**.
