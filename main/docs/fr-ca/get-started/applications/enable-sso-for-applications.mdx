description: Décrit comment créer une intégration d’authentification unique (SSO) pour une application. À utiliser uniquement avec les tenants Legacy.
title: Activer les intégrations d’authentification unique pour les applications
---

Par défaut, l’<Tooltip tip="Authentification unique (SSO) : service qui, après qu’un utilisateur se connecte à une application, le connecte automatiquement aux autres applications." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=single+sign-on">authentification unique</Tooltip> (SSO) est activée pour tous les nouveaux tenants Auth0 ; toutefois, les **tenants Legacy** peuvent [choisir d’activer ou non cette fonctionnalité au niveau du tenant](/docs/fr-ca/get-started/tenant-settings/enable-sso-for-legacy-tenants). Si vous n’avez pas activé le SSO au niveau du tenant, vous pouvez l’activer pour chaque application.

Vous pouvez activer le SSO pour votre application dans le <Tooltip tip="Auth0 Dashboard : principale interface d’Auth0 pour configurer vos services." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Auth0+Dashboard">Auth0 Dashboard</Tooltip>.

<div id="prerequisite">
  ## Prérequis
</div>

Avant d’activer l’authentification unique (SSO) pour une application, vous devez d’abord créer et configurer une connexion pour chaque <Tooltip tip="Identity Provider (IdP) : service qui stocke et gère les identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=identity+provider">fournisseur d’identité</Tooltip> que vous souhaitez utiliser. Pour les fournisseurs d’identité sociaux, assurez-vous que la connexion n’utilise pas de clés de développeur lorsque vous utilisez l’[expérience Universal Login](/docs/fr-ca/authenticate/login/auth0-universal-login).

<div id="enable-sso">
  ## Activer le SSO
</div>

1. Accédez à [Auth0 Dashboard &gt; Applications &gt; SSO Integrations](https://manage.auth0.com/#/externalapps), puis sélectionnez le nom de l’intégration que vous souhaitez afficher.
2. Faites défiler la page jusqu’en bas de **Settings**, repérez **Use Auth0 instead of the IdP to do authentification unique**, activez la bascule, puis sélectionnez **Save Changes**.
