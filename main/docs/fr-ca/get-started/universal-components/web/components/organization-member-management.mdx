## Pour commencer {#get-started}

    ```tsx wrap lines
    import { OrganizationMemberManagement } from "@auth0/universal-components-react";

    export function MembersPage() {
      return <OrganizationMemberManagement />;
    }
    ```

    Pour permettre aux administrateurs d’afficher les détails d’un membre, associez `viewMemberDetailsAction` à la route qui héberge [`OrganizationMemberDetail`](/docs/fr-ca/get-started/universal-components/web/components/organization-member-detail) :

    ```tsx wrap lines
    import { OrganizationMemberManagement } from "@auth0/universal-components-react";
    import { useNavigate } from "react-router-dom";

    export function MembersPage() {
      const navigate = useNavigate();

      return (
        <OrganizationMemberManagement
          viewMemberDetailsAction={{
            onAfter: ({ userId, tab }) =>
              navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
          }}
        />
      );
    }
    ```

    <Accordion title="Exemple d’intégration complet">
      ```tsx lines
      import React from "react";
      import { useNavigate } from "react-router-dom";
      import { OrganizationMemberManagement } from "@auth0/universal-components-react";
      import { Auth0Provider } from "@auth0/auth0-react";
      import { Auth0ComponentProvider } from "@auth0/universal-components-react/spa";
      import { auditLog } from "./lib/audit-log";

      function MembersPage() {
        const navigate = useNavigate();

        return (
          <div className="max-w-5xl mx-auto p-6">
            <OrganizationMemberManagement
              createInvitationAction={{
                onBefore: (input) => {
                  const email = input.invitees[0]?.email ?? "";
                  return email.endsWith("@example.com");
                },
                onAfter: (input, createdInvitation) => {
                  auditLog.record({
                    action: "invitation_created",
                    email: input.invitees[0]?.email,
                    invitationId: createdInvitation.id,
                  });
                },
              }}
              revokeInvitationAction={{
                onBefore: (invitations) =>
                  window.confirm(`Revoke ${invitations.length} invitation(s)?`),
                onAfter: (invitations) => {
                  auditLog.record({
                    action: "invitations_revoked",
                    count: invitations.length,
                  });
                },
              }}
              resendInvitationAction={{
                onAfter: (original, newInvitation) => {
                  auditLog.record({
                    action: "invitation_resent",
                    originalId: original.id,
                    newId: newInvitation.id,
                  });
                },
              }}
              viewMemberDetailsAction={{
                onAfter: ({ userId, tab }) =>
                  navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
              }}
              removeFromOrganizationAction={{
                onBefore: (userId) =>
                  window.confirm(`Remove member ${userId} from the organization?`),
                onAfter: (userId) => {
                  auditLog.record({ action: "member_removed", userId });
                },
              }}
              assignRolesAction={{
                onAfter: ({ userId, roleIds }) => {
                  auditLog.record({ action: "roles_assigned", userId, roleIds });
                },
              }}
              customMessages={{
                header: { title: "Team Members" },
                tabs: { invitations: "Pending Invites" },
              }}
              styling={{
                variables: {
                  light: { "--color-primary": "#4f46e5" },
                  dark: { "--color-primary": "#818cf8" },
                },
              }}
            />
          </div>
        );
      }

      export default function App() {
        const domain = "YOUR_TENANT.auth0.com";
        const clientId = "YOUR_CLIENT_ID";

        return (
          <Auth0Provider
            domain={domain}
            clientId={clientId}
            authorizationParams={{ redirect_uri: window.location.origin }}
          >
            <Auth0ComponentProvider>
              <MembersPage />
            </Auth0ComponentProvider>
          </Auth0Provider>
        );
      }
      ```

## Props {#props}

### Props d&#39;affichage {#display-props}

Les props d&#39;affichage déterminent le rendu du composant sans en modifier le comportement. Utilisez-les pour masquer des sections ou activer le mode lecture seule.

| Prop         | Type      | Description                                                                                                             |
| :----------- | :-------- | :---------------------------------------------------------------------------------------------------------------------- |
| `hideHeader` | `boolean` | Masquer la section d&#39;en-tête du composant (titre et description). Valeur par défaut : `false`                       |
| `readOnly`   | `boolean` | Désactiver toutes les actions de mutation (inviter, révoquer, renvoyer, retirer, assigner). Valeur par défaut : `false` |

***

### Props d’action {#action-props}

Les props d’action gèrent les interactions utilisateur et définissent ce qui se passe lorsque les utilisateurs effectuent des opérations sur les membres et les invitations. Utilisez les hooks de cycle de vie (`onBefore`, `onAfter`) pour intégrer le routage et les analyses de votre application.

| Prop                           | Type                                                       | Description                                                      |
| :----------------------------- | :--------------------------------------------------------- | :--------------------------------------------------------------- |
| `createInvitationAction`       | `ComponentAction<CreateInvitationInput, MemberInvitation>` | Action d’invitation de membres.                                  |
| `revokeInvitationAction`       | `ComponentAction<MemberInvitation[]>`                      | Action de révocation d’une invitation.                           |
| `resendInvitationAction`       | `ComponentAction<MemberInvitation, MemberInvitation>`      | Action de renvoi d’une invitation.                               |
| `viewMemberDetailsAction`      | `ComponentAction<ViewMemberDetailsParams>`                 | Action d’affichage des détails d’un membre.                      |
| `removeFromOrganizationAction` | `ComponentAction<string>`                                  | Action de suppression d’un membre.                               |
| `assignRolesAction`            | `ComponentAction`                                          | Attribution de rôles. Les hooks reçoivent `{ userId, roleIds }`. |

**createInvitationAction**

**Type :** `ComponentAction<CreateInvitationInput, MemberInvitation>`

Contrôle la création d’invitations (jusqu’à 10 destinataires par demande).

* `onBefore(input)` s’exécute de façon synchrone avant l’envoi. Retournez `false` pour annuler.
* `onAfter(input, createdInvitation)` s’exécute après la création de l’invitation.

```tsx wrap lines
<OrganizationMemberManagement
  createInvitationAction={{
    onBefore: (input) => {
      const email = input.invitees[0]?.email ?? "";
      return email.endsWith("@example.com");
    },
    onAfter: (input, createdInvitation) => {
      auditLog.record({
        action: "invitation_created",
        email: input.invitees[0]?.email,
        invitationId: createdInvitation.id,
      });
    },
  }}
/>
```

**Routage des connexions d’invitation**

Le sélecteur d’invitations répertorie les fournisseurs d’identité SSO Entreprise admissibles ainsi que les magasins d’utilisateurs et répertoires d’utilisateurs activés configurés pour l’Organization.

Le sélecteur de connexion interroge les deux sources :

* `GET /my-org/identity-providers` (filtre selon les niveaux d’accès aux membres admissibles)
* `GET /my-org/user-stores` (filtre selon `is_enabled: true`)

```ts
type ConnectionOptionType = 'identity_provider' | 'user_store';

interface ConnectionOption {
  id: string;
  name: string;
  type: ConnectionOptionType;
}
```

La charge utile envoyée à `createInvitationAction` est acheminée à l’aide d’un seul identifiant, selon le type de connexion sélectionné :

* **Connexion SSO Entreprise sélectionnée :** la charge utile renseigne `identity_provider_id`.
* **Connexion Magasin d&#39;utilisateurs / Directory sélectionnée :** la charge utile renseigne `user_store_id`.

```ts
interface CreateInvitationInput {
  invitees: Array<{
    email: string;
    roles?: string[];
  }>;
  inviter?: {
    name?: string;
  };
  identity_provider_id?: string;
  user_store_id?: string;
  ttl_sec?: number;
}
```

Règles de routage des connexions :

* **Sélection automatique :** si une Organization ne compte qu&#39;une seule connexion admissible, celle-ci est sélectionnée par défaut et demeure modifiable.
* **Aucune connexion :** s&#39;il n&#39;existe aucune connexion admissible, le point d&#39;entrée d&#39;invitation est désactivé et affiche un message explicatif.
* **Révocation et renvoi :** le flux de révocation et de renvoi conserve la source de routage de connexion d&#39;origine (`user_store_id` ou `identity_provider_id`).
* **Admissibilité des connexions :** le sélecteur d&#39;invitation inclut les connexions configurées avec un niveau d&#39;accès de membre `limited` ou `full`.

**revokeInvitationAction**

**Type :** `ComponentAction<MemberInvitation[]>`

Contrôle la révocation des invitations (prend en charge les révocations individuelles et en lot, jusqu&#39;à 10 invitations par lot).

* `onBefore(invitations)` demande une confirmation avant la révocation. Retournez `false` pour annuler.
* `onAfter(invitations)` s&#39;exécute après la révocation des invitations.

```tsx wrap lines
<OrganizationMemberManagement
  revokeInvitationAction={{
    onBefore: (invitations) =>
      window.confirm(`Revoke ${invitations.length} invitation(s)?`),
    onAfter: (invitations) => {
      auditLog.record({
        action: "invitations_revoked",
        count: invitations.length,
      });
    },
  }}
/>
```

**resendInvitationAction**

**Type :** `ComponentAction<MemberInvitation, MemberInvitation>`

Contrôle le flux de révocation et de renvoi.

* `onBefore(invitation)` demande une confirmation avant le renvoi. Retournez `false` pour annuler.
* `onAfter(original, newInvitation)` s’exécute après la création d’une nouvelle invitation.

```tsx wrap lines
<OrganizationMemberManagement
  resendInvitationAction={{
    onAfter: (original, newInvitation) => {
      auditLog.record({
        action: "invitation_resent",
        originalId: original.id,
        newId: newInvitation.id,
      });
    },
  }}
/>
```

**viewMemberDetailsAction**

**Type :** `ComponentAction<ViewMemberDetailsParams>`

Se déclenche lorsqu’une ligne de membre ou un badge de rôles est sélectionné. Reçoit `{ userId, tab }`. Connectez ceci pour naviguer vers `OrganizationMemberDetail`.

* `onAfter({ userId, tab })` s’exécute lors de la sélection. Conservez `tab` dans l’URL de votre routeur afin d’ouvrir directement l’onglet demandé.

```tsx wrap lines
<OrganizationMemberManagement
  viewMemberDetailsAction={{
    onAfter: ({ userId, tab }) =>
      navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
  }}
/>
```

**removeFromOrganizationAction**

**Type :** `ComponentAction<string>`

Contrôle le retrait d’un membre de l’Organization (adhésion seulement ; ne supprime pas le profil utilisateur du magasin d&#39;utilisateurs Auth0). Les deux hooks reçoivent le `userId`.

* `onBefore(userId)` demande une confirmation avant le retrait. Retournez `false` pour annuler.
* `onAfter(userId)` s’exécute après le retrait.

```tsx wrap lines
<OrganizationMemberManagement
  removeFromOrganizationAction={{
    onBefore: (userId) =>
      window.confirm(`Remove member ${userId} from the organization?`),
    onAfter: (userId) => {
      auditLog.record({ action: "member_removed", userId });
    },
  }}
/>
```

**assignRolesAction**

**Type :** `ComponentAction<{ userId: string; roleIds: string[] }>`

Se déclenche après l’attribution de rôles dans la fenêtre modale de la ligne. Le nombre de rôles sélectionnés est limité à 10 par demande d’attribution, et un membre peut avoir jusqu’à 50 rôles au total. Les deux hooks reçoivent `{ userId, roleIds }`.

* `onBefore({ userId, roleIds })` valide la sélection. Retournez `false` pour annuler.
* `onAfter({ userId, roleIds })` s’exécute après l’attribution des rôles.

```tsx wrap lines
<OrganizationMemberManagement
  assignRolesAction={{
    onAfter: ({ userId, roleIds }) => {
      auditLog.record({ action: "roles_assigned", userId, roleIds });
    },
  }}
/>
```

**style**

Personnalisez l’apparence à l’aide de variables CSS et de surcharges de classes. Les variables prennent en charge les permissions `light`, `dark` et `common`. Les surcharges de classes ciblent des emplacements nommés dans l’arborescence des composants.

<Accordion title="Options de style disponibles">
  **Variables**—Propriétés personnalisées CSS

  * `common`—Appliquées à tous les thèmes
  * `light`—Thème clair uniquement
