## Pour commencer {#get-started}

    Transmettez un `userId` de votre route au composant. Reliez `onBack` à votre routeur afin que le bouton de retour ramène à la liste des membres.

    ```tsx wrap lines
    import { OrganizationMemberDetail } from "@auth0/universal-components-react";
    import { useNavigate, useParams } from "react-router-dom";

    export function MemberDetailPage() {
      const { userId } = useParams<{ userId: string }>();
      const navigate = useNavigate();

      return (
        <OrganizationMemberDetail
          userId={userId!}
          onBack={() => navigate("/members")}
        />
      );
    }
    ```

    <Accordion title="Exemple d'intégration complet">
      ```tsx lines
      import React from "react";
      import { OrganizationMemberDetail } from "@auth0/universal-components-react";
      import { Auth0Provider } from "@auth0/auth0-react";
      import { Auth0ComponentProvider } from "@auth0/universal-components-react/spa";
      import { useNavigate, useParams, useSearchParams } from "react-router-dom";
      import { auditLog } from "./lib/audit-log";

      function MemberDetailPage() {
        const { userId } = useParams<{ userId: string }>();
        const [searchParams] = useSearchParams();
        const navigate = useNavigate();
        const initialTab = searchParams.get("tab") === "roles" ? "roles" : "details";

        return (
          <div className="max-w-3xl mx-auto p-6">
            <OrganizationMemberDetail
              userId={userId!}
              initialTab={initialTab}
              onBack={() => navigate("/members")}
              removeFromOrganizationAction={{
                onBefore: (removedUserId) =>
                  window.confirm(`Retirer le membre ${removedUserId} de l'organisation ?`),
                onAfter: (removedUserId) => {
                  auditLog.record({ action: "member_removed", userId: removedUserId });
                },
              }}
              assignRolesAction={{
                onAfter: ({ userId, roleIds }) => {
                  auditLog.record({ action: "roles_assigned", userId, roleIds });
                },
              }}
              removeRolesAction={{
                onAfter: ({ userId, roleIds }) => {
                  auditLog.record({ action: "roles_removed", userId, roleIds });
                },
              }}
              customMessages={{
                member: {
                  detail: {
                    back_button: "Retour aux membres",
                    roles: { assign_button: "Attribuer des rôles" },
                  },
                },
              }}
              styling={{
                variables: {
                  light: { "--color-primary": "#4f46e5" },
                  dark: { "--color-primary": "#818cf8" },
                },
                classes: {
                  "OrganizationMemberDetail-root": "max-w-3xl mx-auto",
                },
              }}
            />
          </div>
        );
      }

      export default function App() {
        const domain = "YOUR_TENANT.auth0.com";
        const clientId = "YOUR_CLIENT_ID";

        return (
          <Auth0Provider
            domain={domain}
            clientId={clientId}
            authorizationParams={{ redirect_uri: window.location.origin }}
          >
            <Auth0ComponentProvider>
              <MemberDetailPage />
            </Auth0ComponentProvider>
          </Auth0Provider>
        );
      }
      ```

### Props requis {#required-props}

| Prop     | Type     | Description                                                                          |
| :------- | :------- | :----------------------------------------------------------------------------------- |
| `userId` | `string` | Identifiant utilisateur Auth0 du membre à afficher (par exemple, `auth0\|64abc...`). |

***

### Props d&#39;affichage {#display-props}

Les props d&#39;affichage contrôlent le rendu du composant sans en modifier le comportement. Utilisez-les pour masquer des sections ou activer le mode lecture seule.

| Prop         | Type                   | Description                                                                                                                                                                                                 |
| :----------- | :--------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hideHeader` | `boolean`              | Masque la section d&#39;en-tête du composant (titre et description). Dans la version d&#39;accès anticipé actuelle, cette prop ne masque pas l&#39;en-tête du détail du membre. Valeur par défaut : `false` |
| `readOnly`   | `boolean`              | Désactive la gestion des rôles et les actions de retrait de membres. Valeur par défaut : `false`                                                                                                            |
| `initialTab` | `'details' \| 'roles'` | L&#39;onglet affiché au départ. Créez un lien profond vers cet onglet à l&#39;aide des paramètres de requête du routeur. Valeur par défaut : `'details'`                                                    |

***

### Props d’action {#action-props}

Les props d’action gèrent les interactions de l’utilisateur. Utilisez les hooks de cycle de vie (`onBefore`, `onAfter`) pour les intégrer au routage et aux outils d’analytique de votre application.

| Prop                           | Type                      | Description                                                    |
| :----------------------------- | :------------------------ | :------------------------------------------------------------- |
| `onBack`                       | `() => void`              | Gestionnaire de clic du bouton Retour.                         |
| `removeFromOrganizationAction` | `ComponentAction<string>` | Action de suppression d’un membre.                             |
| `assignRolesAction`            | `ComponentAction`         | Attribue des rôles. Les hooks reçoivent `{ userId, roleIds }`. |
| `removeRolesAction`            | `ComponentAction`         | Supprime des rôles. Les hooks reçoivent `{ userId, roleIds }`. |

**onBack**

**Type :** `() => void`

Se déclenche lorsque l’utilisateur sélectionne le bouton Retour dans l’en-tête, ainsi qu’automatiquement après la suppression d’un membre. Connectez ce rappel à votre routeur pour revenir à la liste des membres.

```tsx wrap lines
<OrganizationMemberDetail userId={userId} onBack={() => navigate("/members")} />
```

**removeFromOrganizationAction**

**Type :** `ComponentAction<string>`

Contrôle le retrait d&#39;un membre de l&#39;organization (l&#39;adhésion seulement; le profil utilisateur n&#39;est pas supprimé du magasin d&#39;utilisateurs Auth0). Une fois le retrait effectué, le composant appelle le rappel d&#39;action ainsi que `onBack`. Ne vous fiez pas à l&#39;ordre d&#39;exécution si `onAfter` effectue des opérations asynchrones.

* `onBefore(userId)` demande une confirmation avant le retrait. Retournez `false` pour annuler.
* `onAfter(userId)` s&#39;exécute après le retrait.

```tsx wrap lines
<OrganizationMemberDetail
  userId={userId}
  onBack={() => navigate("/members")}
  removeFromOrganizationAction={{
    onBefore: (memberId) =>
      window.confirm(`Remove member ${memberId} from the organization?`),
    onAfter: (memberId) => {
      auditLog.record({ action: "member_removed", userId: memberId });
    },
  }}
/>
```

**assignRolesAction**

**Type :** `ComponentAction<{ userId: string; roleIds: string[] }>`

Se déclenche après l&#39;attribution de rôles depuis l&#39;onglet des rôles. Le nombre de rôles sélectionnés est limité à 10 par demande d&#39;attribution, et un même membre peut se voir attribuer jusqu&#39;à 50 rôles au total. Les deux hooks reçoivent `{ userId, roleIds }`.

* `onBefore({ userId, roleIds })` valide la sélection. Retournez `false` pour annuler.
* `onAfter({ userId, roleIds })` écrit dans un journal d&#39;audit ou actualise les badges de rôles.

```tsx wrap lines
<OrganizationMemberDetail
  userId={userId}
  assignRolesAction={{
    onAfter: ({ userId, roleIds }) => {
      auditLog.record({ action: "roles_assigned", userId, roleIds });
    },
  }}
/>
```

**removeRolesAction**

**Type :** `ComponentAction<{ userId: string; roleIds: string[] }>`

Se déclenche lors du retrait de rôles attribués dans le tableau des rôles (prend en charge jusqu&#39;à 10 rôles par demande de retrait). Les deux hooks reçoivent `{ userId, roleIds }`.

* `onBefore({ userId, roleIds })` demande une confirmation avant le retrait des rôles. Retournez `false` pour annuler.
* `onAfter({ userId, roleIds })` actualise l&#39;état ou les journaux d&#39;audit.

```tsx wrap lines
<OrganizationMemberDetail
  userId={userId}
  removeRolesAction={{
    onBefore: ({ roleIds }) =>
      window.confirm(`Remove ${roleIds.length} role(s)?`),
    onAfter: ({ userId, roleIds }) => {
      auditLog.record({ action: "roles_removed", userId, roleIds });
    },
  }}
/>
```

**styling**

Personnalisez l&#39;apparence à l&#39;aide de variables CSS et de remplacements de classes. Les variables prennent en charge les portées `light`, `dark` et `common`. Les remplacements de classes ciblent des emplacements nommés dans l&#39;arborescence du composant.

  * `OrganizationMemberDetail-header`
  * `OrganizationMemberDetail-tabs`
  * `OrganizationMemberDetail-detailsTab`
  * `OrganizationMemberDetail-rolesTab`

  * `OrganizationMemberAssignRolesModal-dialogContent`
</Accordion>
