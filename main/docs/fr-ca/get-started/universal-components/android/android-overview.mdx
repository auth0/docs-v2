Le SDK Auth0 [Universal Components pour Android](https://github.com/auth0/ui-components-android) offre une interface utilisateur préconçue et intégrable pour les flux d’identité Auth0 utilisant [Jetpack Compose](https://developer.android.com/compose).

Universal Components pour Android s’appuie sur le [SDK Android d’Auth0](https://github.com/auth0/Auth0.Android) et s’intègre aux [API My Account](/docs/fr-ca/manage-users/my-account-api).

<div id="prerequisites">
  ## Prérequis
</div>

Pour configurer Universal Components pour Android SDK, vous devez disposer des éléments suivants :

* Systèmes d’exploitation : **Android 11+** (API 30).
* Langage de programmation : **Kotlin 2.2+**, **Android Gradle Plugin 8.11+**, **Jetpack Compose BOM 2024.09.00+**, **JDK 17+**.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Pour activer la prise en charge des [clés d’accès](/docs/fr-ca/authenticate/database-connections/passkeys) Auth0, vous devez utiliser **Android 14+**.
</Callout>

<div id="install-the-sdk">
  ## Installez le SDK
</div>

Le SDK Universal Components pour Android est distribué sous forme de package `com.auth0.universalcomponents:universal-components` dans le dépôt [Maven Central](https://mvnrepository.com/artifact/com.auth0).

<div id="gradle">
  ### Gradle
</div>

Utilisez Gradle pour installer le SDK :

1. Ajoutez le dépôt `mavenCentral()` s’il ne figure pas dans votre fichier `settings.gradle` ou `settings.gradle.kts` :

   ```kotlin
   dependencyResolutionManagement {
       repositories {
           mavenCentral()
           google()
       }
   }
   ```

2. Ajoutez la dépendance à votre fichier `build.gradle` ou `build.gradle.kts` au niveau du module :

   ```kotlin
   dependencies {
       implementation("com.auth0.universalcomponents:universal-components:1.0.0-beta.0")
   }
   ```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Auth0 recommande d’utiliser [Auth0.Android v3+](https://github.com/auth0/Auth0.Android) dans votre application. Les versions antérieures peuvent entraîner des erreurs de compilation lorsqu’elles sont résolues avec Universal Components.
</Callout>

<div id="configure-compose">
  ### Configurer Compose
</div>

Assurez-vous d’activer [Compose](https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler#setup-compose-dependencies) dans le fichier `build.gradle` de votre application :

```kotlin wrap lines
android {
    buildFeatures {
        compose = true
    }
}
```

<div id="verify-the-installation">
  ### Vérifier l’installation
</div>

Pour vérifier l’installation du SDK Universal Components pour Android, assurez-vous que la dépendance est résolue en exécutant :

```bash wrap lines
./gradlew app:dependencies | grep universal-components
```

<div id="sample-application">
  ## Exemple d’application
</div>

Vous pouvez consulter l’exemple d’application du SDK [Universal Components pour Android](https://github.com/auth0/ui-components-android#run-the-sample-app) sur GitHub.

L’exemple d’application comprend `MainActivity.kt`, qui initialise le SDK à l’aide de `Auth0UniversalComponents.initialize()`, et `LoginSecurityScreen.kt`, qui affiche le composant `AuthenticatorSettingsComponent`.
