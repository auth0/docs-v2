Auth0 Universal Components est une bibliothèque de composants d’interface utilisateur préconçus que vous pouvez utiliser pour créer votre pipeline d’identité et votre expérience dans vos applications web et natives. Basé sur les [SDK Auth0](/docs/fr-ca/libraries) selon une approche API-first, Universal Components vous permet d’intégrer les services d’Auth0, comme la gestion des Organizations et l’inscription à la MFA, sans avoir à créer l’interface utilisateur manuellement ni à gérer des proxys backend à privilèges élevés.

Avec Universal Components, vous pouvez :

* Créer et gérer vos Organization(s) Auth0
* Gérer les rôles et les comptes d’utilisateur au sein de votre Organization
* Gérer le [Single-Sign On](/docs/fr-ca/authenticate/single-sign-on) avec Auth0 ou votre [Identity Provider (IdP) Social ou Enterprise](/docs/fr-ca/authenticate/single-sign-on/outbound-single-sign-on)
* Personnaliser l’expérience de connexion avec votre propre image de marque et vos thèmes
* Permettre aux utilisateurs de consulter et de mettre à jour les renseignements de leur compte. Cela inclut la possibilité pour les utilisateurs de choisir leurs méthodes d’authentification et de récupération de compte.

<div id="how-it-works">
  ## Fonctionnement
</div>

Universal Components agit comme couche de présentation entre votre application et Auth0, en coordonnant la communication entre votre application, les API [My Account](/docs/fr-ca/manage-users/my-account-api) et [My Organization](/docs/fr-ca/api/myorganization), ainsi que les SDK Auth0.

Les SDK Auth0 assurent la logique en prenant en charge les flux d’authentification, l’échange de jetons et la gestion des sessions. L’API My Account offre des fonctions en libre-service permettant aux utilisateurs authentifiés de gérer leur expérience d’authentification. Par exemple, les utilisateurs authentifiés peuvent choisir leurs propres méthodes d’authentification, comme la MFA ou les passkeys. L’API My Organization fournit une interface sécurisée, limitée à l’Organization, qui permet à vos clients d’affaires de gérer leurs propres Organizations dans votre tenant Auth0. Cette API sert d’assise technique à l’administration déléguée intégrée et aux intégrations API-first.

Chaque plateforme applique son propre système de conception natif aux composants afin que vous puissiez harmoniser Universal Components avec votre image de marque sans modifier vos mises en page.

<div id="choose-your-platform">
  ## Choisissez votre plateforme
</div>

Les Universal Components sont organisés selon l’API Auth0 qu’ils utilisent :

* Les composants **Web** utilisent l’[API My Organization](/docs/fr-ca/api/myorganization) pour créer des interfaces d’**administration déléguée**, où vos clients gèrent leurs propres Organizations, domaines et fournisseurs SSO. Ils prennent en charge React et Next.js, et peuvent être installés avec shadcn.
* Les composants **iOS** et **Android** utilisent l’[API My Account](/docs/fr-ca/manage-users/my-account-api) pour créer des interfaces de **libre-service destinées aux utilisateurs finaux**, où ceux-ci gèrent leurs propres méthodes d’authentification — facteurs MFA, passkeys et codes de récupération — dans votre application native.

<div id="prerequisites">
  ## Prérequis
</div>

Pour utiliser Auth0 Universal Components :

* [Créez un compte Auth0](https://auth0.com) et enregistrez une [application Auth0](/docs/fr-ca/get-started/auth0-overview/create-applications).
* **Pour les composants iOS et Android**, activez la [My Account API](/docs/fr-ca/manage-users/my-account-api) dans votre tenant. Les composants Native utilisent cette API pour créer des interfaces libre-service permettant aux utilisateurs finaux de gérer leurs méthodes d’authentification.
* **Pour les composants Web**, activez la [My Organization API](/docs/fr-ca/api/myorganization) dans votre tenant. Les composants Web utilisent cette API pour créer des interfaces d’administration déléguée.

Pour connaître les exigences propres à chaque plateforme et les étapes d’installation, consultez le guide de démarrage correspondant ci-dessus.
