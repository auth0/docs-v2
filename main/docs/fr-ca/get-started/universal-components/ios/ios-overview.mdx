Le SDK [Universal Components for iOS](https://github.com/auth0/ui-components-ios) d’Auth0 fournit une interface utilisateur prête à l’emploi et intégrable pour les flux d’identité Auth0 utilisant [SwiftUI](https://developer.apple.com/swiftui).

Universal Components for iOS repose sur le [SDK Auth0 Swift](https://github.com/auth0/Auth0.swift) et s’intègre aux [API My Account](/docs/fr-ca/manage-users/my-account-api).

<div id="prerequisites">
  ## Prérequis
</div>

Pour configurer Universal Components pour le SDK iOS, vous devez disposer des éléments suivants :

* Systèmes d’exploitation : **iOS 16.0+**
* Langage de programmation : **Swift 5+** (6 recommandé), **Xcode 16+** (26+ recommandé)

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Pour prendre en charge les [passkeys](/docs/fr-ca/authenticate/database-connections/passkeys) Auth0, **iOS 16.6+** est requis.
</Callout>

<div id="install-the-sdk">
  ## Installer le SDK
</div>

Le SDK Universal Components pour iOS est offert sous forme de package `Auth0UniversalComponents` par l’intermédiaire de [Swift Package Manager](https://swift.org/package-manager/) et de [Carthage](https://github.com/Carthage/Carthage).

<div id="swift-package-manager">
  ### Swift Package Manager
</div>

Auth0 recommande d’utiliser le gestionnaire de paquets Swift pour installer le SDK :

1. Ouvrez [**Xcode**](https://developer.apple.com/documentation/xcode).

2. Sélectionnez **File &gt; Add Package Dependencies**.

3. Ajoutez l’URL du dépôt suivante :

   ```text
   https://github.com/auth0/ui-components-ios.git
   ```

4. Sélectionnez la version `1.0.0-beta.0` ou une version ultérieure.

5. Ajoutez `Auth0UniversalComponents` à la cible de votre application.

<div id="carthage">
  ### Carthage
</div>

Si vous utilisez le gestionnaire de dépendances [Carthage](https://github.com/Carthage/Carthage) :

1. Ajoutez ce qui suit à votre fichier Cartfile :

   ```text
   github "auth0/ui-components-ios" ~> 1.0.0
   ```

2. Exécutez la commande suivante :

   ```bash
   carthage bootstrap --platform iOS --use-xcframeworks
   ```

<div id="verify-the-sdk-installation">
  ### Vérifier l’installation du SDK
</div>

Pour vérifier l’installation du SDK Universal Components pour iOS, importez le module `Auth0UniversalComponents` dans un fichier Swift afin de confirmer que le framework est accessible :

```swift wrap lines
import Auth0UniversalComponents
```

<div id="sample-application">
  ## Application exemple
</div>

Vous pouvez consulter sur GitHub l’application exemple iOS [`AppUIComponents`](https://github.com/auth0/ui-components-ios/tree/main/AppUIComponents) d’Universal Components.

L’application exemple comprend `AppUIComponentsApp.swift`, qui sert de point d’entrée principal de SwiftUI pour l’initialisation du SDK, ainsi que `ThemeManager.swift`, qui gère l’injection de thèmes personnalisés et le changement de thème à l’exécution.
