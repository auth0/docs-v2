---
title: Trouvez le nom de votre tenant ou son ID
description: Trouvez le nom et l’ID de votre tenant Auth0 dans le Dashboard afin de les utiliser pour configurer des SDK, effectuer des requêtes aux API ou remplacer des variables dans la documentation Auth0.
---

Chaque tenant Auth0 a un nom. Vous utilisez souvent ce nom dans votre code pour identifier le tenant. Lorsque vous voyez la variable `{yourTenantId}`, `{yourTenantName}`, `{yourTenant}` ou une variable semblable dans la documentation Auth0, remplacez-la par le nom du tenant.

1. Accédez à l’[Auth0 Dashboard](https://manage.auth0.com/#).
2. Dans le coin supérieur gauche, repérez le nom du tenant à côté du logo Auth0.
