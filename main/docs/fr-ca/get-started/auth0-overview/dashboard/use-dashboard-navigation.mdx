Le menu de navigation de l’Auth0 Dashboard vous aide à trouver plus rapidement ce dont vous avez besoin. Il comprend une barre latérale améliorée avec des sections organisées, un système de fil d’Ariane unifié et une hiérarchie visuelle améliorée.

<div id="enable-auth0-dashboard-navigation">
  ## Activer la navigation dans Auth0 Dashboard
</div>

Lorsque la fonctionnalité de navigation est offerte pour votre tenant, une fenêtre contextuelle d’activation s’affiche lors de votre première connexion :

1. Sélectionnez **Essayer maintenant** pour activer immédiatement la nouvelle navigation ou **Peut-être plus tard** pour fermer la fenêtre contextuelle.

* Si vous choisissez **Peut-être plus tard**, la fenêtre contextuelle réapparaîtra dans 14 jours.

2. Après avoir activé cette option, vous pouvez désactiver la fonctionnalité de navigation dans le menu de votre profil utilisateur :

* Sélectionnez l’icône de votre profil dans le coin supérieur droit du Dashboard.
  * Cliquez sur la nouvelle bascule de navigation pour revenir à l’ancienne interface de navigation.

Votre préférence est enregistrée et conservée d’une session à l’autre.

<div id="how-it-works">
  ## Fonctionnement
</div>

La navigation dans Auth0 Dashboard regroupe les éléments connexes en sections logiques aux noms clairs, axés sur les flux de travail, afin de faciliter la navigation. Une barre d’actions de page persistante apparaît en haut de chaque page et comprend le fil d’Ariane, les onglets, les actions et le bouton de bascule de la barre latérale, afin de garder les commandes importantes visibles pendant le défilement.

Les fils d’Ariane apparaissent désormais dans la barre d’actions plutôt que d’être dispersés dans les en-têtes de page, ce qui assure une navigation contextuelle uniforme. La nouvelle navigation propose également une présentation et une structure modernes repensées pour améliorer la convivialité.

Lorsque vous naviguez entre les sections dans Auth0 Dashboard, la navigation affiche une barre latérale gauche repensée. La barre latérale est organisée selon les sections suivantes :

| Section                         | Contenu                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Principale (sans étiquette)     | Accueil : page d’accueil du Dashboard pour commencer<br />Agents : configuration des agents d’IA<br />Utilisateurs : gestion des utilisateurs<br />Organizations : gestion des organisations<br />Paramètres : configuration du tenant et gestion du compte                                                                                                                             |
| Intégration                     | Applications : enregistrer et gérer vos applications<br />API : enregistrer et gérer vos API<br />Authentification : configurer l’authentification (Database, Passwordless)<br />Connexions : gérer les connexions sociales<br />SSO d’entreprise : gérer les connexions d’entreprise et les profils libre-service<br />Autorisation : créer et gérer les rôles                         |
| Personnalisation                | Image de marque : éditeur visuel pour le thème Universal Login<br />Pages : personnalisation des pages Universal Login et Forms<br />Portails : éditeur visuel pour les pages de portail<br />Domaines : gérer les domaines personnalisés                                                                                                                                               |
| Messagerie                      | Courriels : modèles de courriel et configuration<br />Téléphone : paramètres de messagerie téléphonique                                                                                                                                                                                                                                                                                 |
| Automatisation et extensibilité | Actions : créer et gérer des Auth0 Actions<br />Events : diffuser les événements d’authentification vers des services externes<br />Extensions : modules complémentaires officiels et tiers<br />Rules : règles héritées (pour les configurations existantes)<br />Hooks : hooks hérités (pour les configurations existantes)                                                           |
| Sécurité et surveillance        | Protection contre les attaques : protection contre les robots, la limitation du débit par IP, les attaques par force brute et les mots de passe compromis<br />Contrôle d’accès : listes de contrôle d’accès<br />Security Dashboard : aperçu de la sécurité et indicateurs de menaces<br />Logs : consulter les logs d’activité<br />Analytique : analyse de l’utilisation et rapports |

<div id="browser-support">
  ## Compatibilité des navigateurs
</div>

La nouvelle navigation nécessite des navigateurs modernes prenant en charge `localStorage` afin d’enregistrer l’état de la barre latérale. En cas de problème, vous pouvez toujours revenir à la navigation classique à l’aide de la bascule du menu de profil.
