<Card title="Avant de commencer">
  * Installez [Node.js v18 ou version ultérieure](https://nodejs.org/en/download) sur votre système.
  * Créez un [compte Auth0](https://auth0.com/) actif avec des autorisations d’administrateur.
  * Installez au moins un client MCP pris en charge ([Claude Desktop](https://claude.ai/download), [Cursor](https://www.cursor.com/downloads) ou [Windsurf](https://www.windsurf.com/editor), par exemple).
</Card>

Aidez votre équipe et vos utilisateurs à tirer parti d’[Auth0 Model Context Protocol (MCP) Server](/docs/fr-ca/get-started/auth0-mcp-server) en l’installant et en l’intégrant à plusieurs [clients MCP](https://modelcontextprotocol.io/clients) couramment utilisés.

## Installation et configuration {#installation-and-configuration}

Installez Auth0 MCP Server en exécutant l’une de ces commandes dans votre terminal :

### Pour Claude Desktop (par défaut) {#for-claude-desktop-default}

```bash lines
npx @auth0/auth0-mcp-server init
```

### Pour Cursor {#for-cursor}

```bash lines
npx @auth0/auth0-mcp-server init --client cursor
```

### Pour Windsurf {#for-windsurf}

```bash lines
npx @auth0/auth0-mcp-server init --client windsurf
```

### Autres clients MCP {#other-mcp-clients}

Pour utiliser Auth0 MCP Server avec n’importe quel autre client MCP, vous pouvez ajouter manuellement cette configuration dans le client, puis le redémarrer pour que les modifications prennent effet :

```json lines
{
  "mcpServers": {
    "auth0": {
      "command": "npx",
      "args": ["-y", "@auth0/auth0-mcp-server", "run"],
      "capabilities": ["tools"],
      "env": {
        "DEBUG": "auth0-mcp"
      }
    }
  }
}
```

## Authentifiez-vous avec Auth0 {#authenticate-with-auth0}

Votre navigateur s’ouvrira automatiquement pour lancer le <Tooltip tip="OAuth 2.0 : cadre d’autorisation qui définit les protocoles et les flux de travail d’autorisation." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=OAuth+2.0">OAuth 2.0</Tooltip> flux sur appareil d’<Tooltip tip="OAuth 2.0 : cadre d’autorisation qui définit les protocoles et les flux de travail d’autorisation." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=authorization+flow">autorisation</Tooltip>. Connectez-vous à votre compte Auth0 et accordez les autorisations demandées.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Les identifiants sont stockés de façon sécurisée dans le trousseau de clés de votre système. Vous pouvez aussi le vérifier à l’aide de votre outil de gestion du trousseau de clés.
</Callout>

## Vérifier votre intégration {#verify-your-integration}

### Claude Desktop {#claude-desktop}

1. Redémarrez Claude Desktop pour vous assurer qu’il reconnaît l’Auth0 MCP Server nouvellement installé.
2. Dans Claude Desktop, cliquez sur l’icône **Outils** et vérifiez que les outils Auth0 (par exemple, `auth0_create_action` ou `auth0_delete_application`) s’affichent dans la liste des **outils MCP disponibles**.
3. Lancez une conversation avec Claude Desktop et demandez de l’aide pour gérer votre tenant Auth0.

### Cursor {#cursor}

1. Redémarrez Cursor pour vous assurer qu’il reconnaît le Auth0 MCP Server nouvellement installé.
2. Dans Cursor, ouvrez **Settings &gt; MCP** et vérifiez que **Auth0** figure dans la liste des **MCP Servers**.
3. Lancez une conversation avec Cursor et demandez de l’aide pour gérer votre tenant Auth0.

### Windsurf {#windsurf}

1. Redémarrez Windsurf pour vous assurer qu&#39;il reconnaît l’Auth0 MCP Server nouvellement installé.
2. Dans Windsurf, ouvrez **Paramètres de Windsurf &gt; Cascade** et vérifiez que **Auth0** apparaît dans la liste **des serveurs MCP (Model Context Protocol)**.
3. Lancez une conversation avec Windsurf et demandez-lui de vous aider à gérer votre tenant Auth0.

## Étapes de dépannage courantes {#common-troubleshooting-steps}

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  La plupart des problèmes de connexion peuvent être réglés en configurant le Auth0 MCP Server et en redémarrant le client MCP.
</Callout>

#### Obtenir de l’aide sur la ligne de commande : {#get-command-line-help}

Consultez la liste des commandes prises en charge et des exemples d’utilisation avec :

```bash lines
npx @auth0/auth0-mcp-server help
```

#### Problèmes d’authentification {#authentication-issues}

Assurez-vous que les autorisations de votre tenant Auth0 sont correctes, puis essayez de réinitialiser avec :

```bash lines
npx @auth0/auth0-mcp-server init
```

#### Échecs de connexion : {#connection-failures}

1. Assurez-vous que le serveur MCP est bien en cours d’exécution avec :

   ```ps lines
   ps aux | grep auth0-mcp
   ```

2. Redémarrez votre client d’IA après avoir vérifié que le serveur est en cours d’exécution.

#### Erreur : Claude ne peut pas se connecter au serveur {#claude-cant-connect-to-the-server-error}

1. Redémarrez Claude Desktop après l’installation.
2. Vérifiez que le serveur est en cours d’exécution avec :

   ```ps lines
   ps aux | grep auth0-mcp
   ```

#### Erreurs d’API : {#api-errors}

Vérifiez les autorisations et la date d’expiration de votre token Auth0. Activez le mode de débogage (voir ci-dessous) pour consulter des logs détaillés.

## Résoudre les problèmes de configuration {#debug-configuration-issues}

#### Activer le mode de débogage {#enable-debug-mode}

Activez le mode de débogage pour consulter des journaux détaillés :

```bash lines
export DEBUG=auth0-mcp
```

#### Déboguer les journaux du client {#debug-client-logs}

Accédez aux journaux détaillés du client MCP dans Claude Desktop :

```bash lines
# Suivre les journaux en temps réel
tail -n 20 -F ~/Library/Logs/Claude/mcp*.log
```

Obtenez des logs détaillés du MCP Server en exécutant Auth0 MCP Server en mode de débogage :

```bash lines
DEBUG=auth0-mcp npx @auth0/auth0-mcp-server run
```

#### Débogage avancé à l’aide du MCP Inspector {#advanced-debugging-using-mcp-inspector}

Pour effectuer un dépannage avancé, utilisez le MCP Inspector :

```bash wrap lines
npx @modelcontextprotocol/inspector -e DEBUG='auth0-mcp' @auth0/auth0-mcp-server run__text in bold__
```
