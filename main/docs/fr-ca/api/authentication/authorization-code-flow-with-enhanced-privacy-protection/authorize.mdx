## Point de terminaison {#endpoint}

`GET /authorize`

Après avoir appelé le point de terminaison `/oauth/par`, redirigez l’utilisateur final vers le point de terminaison `/authorize` au moyen d’une requête `GET`.

<Note>
  Le point de terminaison `/authorize` répondra selon les paramètres transmis au point de terminaison `/oauth/par`. Si vous demandez un `response_type`, vous devriez recevoir un code d’autorisation à utiliser au point de terminaison `/oauth/token`.
</Note>

## Paramètres de requête {#query-parameters}

<ParamField query="client_id" type="string" required>
  Le `client_id` de votre application. Obligatoire.
</ParamField>

<ParamField query="request_uri" type="string" required>
  La valeur `request_uri` reçue à partir du point de terminaison `/oauth/par`. Obligatoire.
</ParamField>

## Messages de réponse {#response-messages}

| Statut | Description                                  |
| ------ | -------------------------------------------- |
| 302    | Redirige vers l’URI de redirection indiquée. |
