<div id="endpoint">
  ## Endpoint
</div>

`POST /oauth/token`

Utilisez cet endpoint pour actualiser un jeton d’accès à l’aide du jeton d’actualisation obtenu lors de l’autorisation.

<div id="learn-more">
  ## En savoir plus
</div>

* [Refresh Tokens](https://auth0.com/docs/secure/tokens/refresh-tokens)

<div id="headers">
  ## En-têtes
</div>

<ParamField header="DPoP" type="string">
  Une preuve DPoP pour la requête. Ce paramètre est facultatif et n’est requis que si votre application utilise Demonstrating Proof-of-Possession.
</ParamField>

<div id="body-parameters">
  ## Paramètres du corps
</div>

<div className="prose-sm prose-gray dark:prose-invert">
  <span data-as="p">Le corps de la requête est au format `application/x-www-form-urlencoded`.</span>
</div>

<ParamField body="grant_type" type="string" required>
  Indique le flux utilisé. Pour actualiser un jeton d’accès, cette valeur doit être définie sur `refresh_token`.

  Valeurs autorisées : `refresh_token`
</ParamField>

<ParamField body="client_id" type="string" required>
  Le Client ID de votre application, qui identifie l’application qui effectue la requête.
</ParamField>

<ParamField body="client_secret" type="string">
  Le Client Secret de votre application. Obligatoire lorsque la méthode d’authentification du endpoint de jeton est définie sur `Post` ou `Basic`.
</ParamField>

<ParamField body="refresh_token" type="string" required>
  Le jeton d’actualisation précédemment émis au client. Ce jeton sert à obtenir un nouveau jeton d’accès.
</ParamField>

<ParamField body="scope" type="string">
  Une liste de portées demandées, séparées par des espaces. S’il est omis, les portées d’origine seront utilisées; sinon, vous pouvez demander un ensemble plus restreint de portées. Notez que cette valeur doit être encodée dans l’URL.
</ParamField>

<div id="response-schema">
  ## Schéma de réponse
</div>

<ResponseSchema>
  <ResponseField name="access_token" type="string">
    Le jeton d’accès nouvellement émis.
  </ResponseField>

  <ResponseField name="refresh_token" type="string">
    Le jeton d’actualisation.
  </ResponseField>

  <ResponseField name="id_token" type="string">
    Le jeton ID, le cas échéant.
  </ResponseField>

  <ResponseField name="token_type" type="string">
    Le type de jeton. Généralement `Bearer`.
  </ResponseField>

  <ResponseField name="expires_in" type="integer">
    La durée de validité du jeton d’accès, en secondes.
  </ResponseField>

  <ResponseField name="scope" type="string">
    Les portées du jeton d’accès.
  </ResponseField>
</ResponseSchema>

<div id="response-messages">
  ## Messages de réponse
</div>

| Statut | Description                                                                                                |
| ------ | ---------------------------------------------------------------------------------------------------------- |
| 200    | Jeton d’accès actualisé avec succès.                                                                       |
| 400    | Requête incorrecte. Il manque des paramètres requis à la requête ou celle-ci est mal formée.               |
| 401    | Non autorisé. Les identifiants du client ne sont pas valides ou le jeton d’actualisation n’est pas valide. |
| 403    | Interdit. Le jeton d’actualisation n’est pas valide ou a expiré.                                           |
