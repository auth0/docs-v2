Lorsqu’un jeton est émis dans le cadre d’une interaction agentique, Auth0 inclut `agent_id` et `external_agent_id`, s’il est défini, dans l’entrée de journal du tenant qui en résulte.

<div id="supported-grant-types">
  ## Types d’autorisations pris en charge
</div>

Auth0 consigne l’identité de l’agent dans les journaux pour les types d’autorisations suivants :

* Autorisations `client_credentials` de clients liés à un agent
* Autorisations `refresh_token` pour les clients liés à un agent
* Autorisations d’échange de jetons OBO
* Autorisations de connexion standard lorsque le client est lié à un agent

<div id="query-logs">
  ## Interroger les journaux
</div>

Vous pouvez rechercher l’`agent_id` dans les endpoints de journaux de la Management API afin d’effectuer des audits par agent et de détecter les anomalies :

```http
GET /api/v2/logs?q=agent_id:agt_72jbvv7LfRKYp59gtRLtkn
```

Pour en savoir plus sur l’interrogation et la diffusion des journaux du tenant, consultez [Syntaxe des requêtes de recherche de journaux](/docs/fr-ca/deploy-monitor/logs/log-search-query-syntax) et [Flux de journaux](/docs/fr-ca/customize/log-streams).
