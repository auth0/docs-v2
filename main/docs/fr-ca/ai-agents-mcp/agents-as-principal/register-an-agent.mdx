<ReleaseStageNotice feature="Agents en tant que principal" stage="ea" contact="Auth0 Support" terms="true" />

Enregistrez un agent en tant qu’identité à part entière dans Auth0 à l’aide de l’Auth0 Dashboard ou de la Management API. Une fois enregistré, vous pouvez gérer l’agent au moyen de la [Management API](https://auth0.com/docs/api/management/v2) et des opérations CRUD standard.

<div id="create-and-register-a-new-agent">
  ## Créer et enregistrer un nouvel agent
</div>

Créez et enregistrez un nouvel agent dans l’Auth0 Dashboard et à l’aide de la Management API.

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à **Dashboard &gt; Agents**, puis sélectionnez **Create New Agent**.
    2. Entrez un nom pour l’agent.
    3. Sélectionnez **Create**.

    Une fois créé, l’agent doit avoir un `agent_id` unique commençant par le préfixe `agt_`. Pour afficher les détails de l’agent, sélectionnez **View Details**.
  </Tab>

  <Tab title="Management API">
    Assurez-vous d’abord que votre jeton d’accès de la Management API possède l’autorisation `create:agents`.

    Ensuite, envoyez une requête `POST` à `/api/v2/agents` avec les paramètres suivants :

    <Tabs>
      <Tab title="Auth0 CLI">
        <Callout icon="file-lines" color="#0EA5E9" iconType="regular">Vous utilisez l’Auth0 CLI? Si ce n’est pas déjà fait, [configurez et authentifiez votre session CLI](/docs/fr-ca/deploy-monitor/auth0-cli) avant d’exécuter cette commande.</Callout>

        ```bash
        auth0 api post "agents" \
          --data '{
            "name": "recommendation-agent-prod",
            "external_agent_id": "my-org-agent-042",
            "metadata": {
              "env": "prod",
              "team": "personalization"
            }
          }'
        ```
      </Tab>

      <Tab title="cURL">
        ```bash
        curl --request POST \
          --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents' \
          --header 'Content-Type: application/json' \
          --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN' \
          --data '{
            "name": "recommendation-agent-prod",
            "external_agent_id": "my-org-agent-042",
            "metadata": {
              "env": "prod",
              "team": "personalization"
            }
          }'
        ```
      </Tab>
    </Tabs>

    | Champ               | Obligatoire | Description                                                                                                                                                          |
    | ------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `name`              | Oui         | 1 à 255 caractères.                                                                                                                                                  |
    | `client_id`         | Non         | [Associez un client existant](/docs/fr-ca/ai-agents-mcp/agents-as-principal/associate-agent-client) lors de la création de l’agent.                                        |
    | `external_agent_id` | Non         | Ne peut être défini qu’au moment de la création. Il ne peut pas être modifié par la suite. Pour en savoir plus, consultez [`external_agent_id`](#external_agent_id). |
    | `metadata`          | Non         | JSON, limite de 10 Ko.                                                                                                                                               |

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">
      N’incluez pas de renseignements personnels identifiables (PII) dans les champs `name` ou `metadata`. Ces valeurs sont consignées dans les journaux et peuvent être visibles par les administrateurs et les destinations de diffusion des journaux.
    </Callout>

    En cas de réussite, Auth0 renvoie un objet agent comme celui-ci :

    ```json
    {
        "agent_id": "agt_sJsP2T4rLopMQMWz2eEGmW",
        "name": "recommendation-agent-prod",
        "metadata": {
            "env": "prod",
            "team": "personalization"
        },
        "created_at": "2026-07-28T21:40:01.395Z",
        "updated_at": "2026-07-28T21:40:01.395Z",
        "external_agent_id": "my-org-agent-042"
    }
    ```
  </Tab>
</Tabs>

<div id="agent-object">
  ## Objet agent
</div>

Une fois enregistré, Auth0 stocke l’agent selon le schéma d’objet suivant :

| Champ               | Type   | Description                                                                                                                                                                                                                  |
| ------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent_id`          | chaîne | Généré par le serveur. Format : `agt_` + 22 caractères base58. Non modifiable. Toujours utilisé pour identifier l’agent via la Management API, même lorsque `external_agent_id` est défini.                                  |
| `external_agent_id` | chaîne | Facultatif. Identifiant fourni par le client. Doit être défini à la création; il ne peut ensuite être ni ajouté ni modifié. Lorsqu’il est défini, il remplace `agent_id` dans les claims de jeton et les journaux du tenant. |
| `name`              | chaîne | De 1 à 255 caractères. Obligatoire à la création.                                                                                                                                                                            |
| `metadata`          | objet  | JSON, limite de 10 Ko.                                                                                                                                                                                                       |
| `created_at`        | chaîne | Horodatage ISO 8601.                                                                                                                                                                                                         |
| `updated_at`        | chaîne | Horodatage ISO 8601.                                                                                                                                                                                                         |

L’objet agent est renvoyé par tous les endpoints `/api/v2/agents`.

<div id="external_agent_id">
  ## `external_agent_id`
</div>

Vous pouvez utiliser votre propre identifiant pour un agent au moyen de `external_agent_id`, afin que l’identité de l’agent affichée dans les jetons et les journaux corresponde à un ID déjà utilisé dans vos systèmes. Vous devez spécifier `external_agent_id` lors de la création de l’agent; il est impossible de l’ajouter ou de le modifier par la suite.

Lorsqu’il est défini, `external_agent_id` remplace `agent_id` partout où l’identité de l’agent apparaît dans les jetons émis (`sub`, `act.sub`) et les journaux du tenant. L’`agent_id` interne demeure l’identifiant utilisé pour gérer l’agent au moyen de la Management API, que vous ayez défini ou non un `external_agent_id`.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  N’incluez pas de renseignements personnels identifiables (PII) dans `external_agent_id`. Cette valeur est enregistrée dans les journaux et peut être visible par les administrateurs et les destinations de diffusion des journaux.
</Callout>
