## Configurer une Organization {#configure-an-organization}

Si vous souhaitez qu’un client d’entreprise utilise Organizations, [créez une Organization](/docs/fr-ca/manage-users/organizations/configure-organizations/create-organizations) et [activez la connexion Enterprise configurée pour XAA](/docs/fr-ca/manage-users/organizations/configure-organizations/enable-connections) pour cette Organization. Les jetons d’accès générés à l’aide de XAA dans la portée de cette connexion sont alors automatiquement associés à l’`org_id` correspondant si l’utilisateur cible est membre de l’Organization.

<Frame>![](/docs/images/xaa/xaa_enable_connection.png)</Frame>

Vous pouvez également configurer le [comportement de l’Organization](/docs/fr-ca/manage-users/organizations/configure-organizations/define-organization-behavior) de la Requesting App afin de définir si l’utilisation d’Organizations est obligatoire ou autorisée. Nous vous recommandons de commencer les tests avec **Both**, qui permet aux utilisateurs de se connecter en tant que membres d’une Organization ou de s’inscrire avec un compte personnel.

<Frame>![](/docs/images/xaa/xaa_organizations_both.png)</Frame>

Si la Requesting App est une application tierce, [activez l’accès des applications tierces à une Organization](/docs/fr-ca/manage-users/organizations/configure-organizations/enable-third-party-application-access).
