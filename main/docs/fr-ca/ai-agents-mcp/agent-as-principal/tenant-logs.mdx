Lorsqu&#39;un jeton est émis pour une interaction agentique, Auth0 inclut à la fois `agent_id` et `external_agent_id`, s&#39;ils sont définis, dans l&#39;entrée de journal du locataire ainsi générée.

## Types d&#39;autorisation pris en charge {#supported-grant-types}

Auth0 consigne l&#39;identité de l&#39;agent dans les journaux pour les types d&#39;autorisation suivants :

* les autorisations `client_credentials` provenant de clients liés à un agent;
* les autorisations `refresh_token` pour les clients liés à un agent;
* les autorisations d&#39;échange de jetons OBO;
* les autorisations de connexion standard lorsque le client est lié à un agent.

## Interroger les journaux {#query-logs}

Vous pouvez interroger l&#39;`agent_id` à partir des terminaux de journaux de la Management API, ce qui permet la vérification et la détection d&#39;anomalies par agent :

```http
GET /api/v2/logs?q=agent_id:agt_72jbvv7LfRKYp59gtRLtkn
```

Pour en savoir plus sur l&#39;interrogation et la diffusion des journaux de locataires, consultez [Syntaxe des requêtes de recherche de journaux](/docs/fr-ca/deploy-monitor/logs/log-search-query-syntax) et [Flux de journaux](/docs/fr-ca/customize/log-streams).
