Enregistrez un agent comme identité de premier ordre dans Auth0 à l&#39;aide du Auth0 Dashboard ou de la Management API. Une fois l&#39;agent enregistré, vous pouvez le gérer avec la [Management API](https://auth0.com/docs/api/management/v2) au moyen des opérations CRUD standards.

## Créer et enregistrer un nouvel agent {#create-and-register-a-new-agent}

Créez et enregistrez un nouvel agent avec le Auth0 Dashboard et la Management API.

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à **Dashboard &gt; Agents** et sélectionnez **Créer un nouvel agent**.
    2. Saisissez un nom pour l&#39;agent.
    3. Sélectionnez **Créer**.

    Une fois l&#39;agent créé, il devrait avoir un `agent_id` unique portant le préfixe `agt_`. Pour afficher les détails de l&#39;agent, sélectionnez **Afficher les détails**.
  </Tab>

  <Tab title="Management API">
    D&#39;abord, assurez-vous que votre jeton d&#39;accès de la Management API possède l&#39;autorisation `create:agents`.

    Ensuite, effectuez une requête `POST` à `/api/v2/agents` avec les paramètres suivants :

    <Tabs>
      <Tab title="Auth0 CLI">
        <Callout icon="file-lines" color="#0EA5E9" iconType="regular">Vous utilisez l&#39;Auth0 CLI? Si ce n&#39;est pas déjà fait, [configurez et authentifiez votre session CLI](/docs/fr-ca/deploy-monitor/auth0-cli) avant d&#39;exécuter cette commande.</Callout>

        ```bash
        auth0 api post "agents" \
          --data '{
            "name": "recommendation-agent-prod",
            "external_agent_id": "my-org-agent-042",
            "metadata": {
              "env": "prod",
              "team": "personalization"
            }
          }'
        ```
      </Tab>

      <Tab title="cURL">
        ```bash
        curl --request POST \
          --url 'https://YOUR_AUTH0_DOMAIN/api/v2/agents' \
          --header 'Content-Type: application/json' \
          --header 'Authorization: Bearer YOUR_MGMT_API_TOKEN' \
          --data '{
            "name": "recommendation-agent-prod",
            "external_agent_id": "my-org-agent-042",
            "metadata": {
              "env": "prod",
              "team": "personalization"
            }
          }'
        ```
      </Tab>
    </Tabs>

    | Champ               | Obligatoire | Description                                                                                                                                                                   |
    | ------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `name`              | Oui         | 1 à 255 caractères.                                                                                                                                                           |
    | `client_id`         | Non         | [Associer un client existant](/docs/fr-ca/ai-agents-mcp/agent-as-principal/associate-agent-client) lors de la création de l&#39;agent.                                              |
    | `external_agent_id` | Non         | Ne peut être défini qu&#39;au moment de la création. Il est impossible de le modifier par la suite. Pour en savoir plus, consultez [`external_agent_id`](#external_agent_id). |
    | `metadata`          | Non         | JSON, limite de 10 Ko.                                                                                                                                                        |

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">
      N&#39;incluez pas de renseignements personnels identifiables (RPI) dans les champs `name` ou `metadata`. Ces valeurs sont consignées dans les journaux et peuvent être visibles par les administrateurs et les destinations d&#39;exportation des journaux.
    </Callout>

    Si l&#39;opération réussit, Auth0 renvoie un objet agent semblable à celui-ci :

    ```json
    {
        "agent_id": "agt_sJsP2T4rLopMQMWz2eEGmW",
        "name": "recommendation-agent-prod",
        "metadata": {
            "env": "prod",
            "team": "personalization"
        },
        "created_at": "2026-07-28T21:40:01.395Z",
        "updated_at": "2026-07-28T21:40:01.395Z",
        "external_agent_id": "my-org-agent-042"
    }
    ```
  </Tab>
</Tabs>

## Objet agent {#agent-object}

Une fois l&#39;enregistrement effectué, Auth0 stocke l&#39;agent selon le schéma d&#39;objet suivant :

| Champ               | Type   | Description                                                                                                                                                                                                                             |
| ------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent_id`          | chaîne | Généré par le serveur. Format : `agt_` + 22 caractères base58. Non modifiable. Toujours utilisé pour désigner l&#39;agent dans la Management API, même lorsque `external_agent_id` est défini.                                          |
| `external_agent_id` | chaîne | Facultatif. Identifiant fourni par le client. Doit être défini à la création; il ne peut être ajouté ni modifié par la suite. Lorsqu&#39;il est défini, il remplace `agent_id` dans les demandes du jeton et les journaux du locataire. |
| `name`              | chaîne | De 1 à 255 caractères. Obligatoire à la création.                                                                                                                                                                                       |
| `metadata`          | objet  | JSON, limite de 10 Ko.                                                                                                                                                                                                                  |
| `created_at`        | chaîne | Horodatage ISO 8601.                                                                                                                                                                                                                    |
| `updated_at`        | chaîne | Horodatage ISO 8601.                                                                                                                                                                                                                    |

L&#39;objet agent est retourné par tous les terminaux `/api/v2/agents`.

## `external_agent_id` {#external_agent_id}

Vous pouvez fournir votre propre identifiant pour un agent au moyen de `external_agent_id`, afin que l&#39;identité de l&#39;agent affichée dans les jetons et les journaux corresponde à un ID déjà utilisé dans vos propres systèmes. Vous devez préciser le `external_agent_id` au moment de la création de l&#39;agent; il est impossible de l&#39;ajouter ou de le modifier par la suite.

Lorsqu&#39;il est défini, le `external_agent_id` remplace `agent_id` partout où l&#39;identité de l&#39;agent apparaît dans les jetons émis (`sub`, `act.sub`) ainsi que dans les journaux du locataire. Le `agent_id` interne demeure l&#39;identifiant servant à gérer l&#39;agent au moyen de la Management API, que vous ayez défini un `external_agent_id` ou non.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  N&#39;incluez aucun renseignement personnel identifiable (RPI) dans `external_agent_id`. Cette valeur est consignée dans les journaux et peut être visible par les administrateurs et les destinations d&#39;exportation des journaux.
</Callout>
