title: Personnaliser les messages téléphoniques

validatedOn: 2026-03-19
---

Le flux de messages téléphoniques par défaut d’Auth0 répond aux besoins de la plupart des applications. Vous pourriez vouloir personnaliser votre flux de messages téléphoniques, notamment dans les cas d’utilisation suivants :

* Localisez vos messages téléphoniques pour répondre aux besoins de différents marchés cibles.
* Définissez un numéro d’envoi personnalisé ou sélectionnez un autre fournisseur de messages téléphoniques en fonction du domaine personnalisé ou de la région.
* Activez différents modèles de messages téléphoniques selon l’application, le tenant ou le domaine personnalisé.

L’[Auth0 Management API](https://auth0.com/docs/api/management/v2) fournit des endpoints pour vous aider à gérer votre flux de messages téléphoniques afin de contrôler quand et comment les messages téléphoniques sont envoyés. Vous pouvez également implémenter et gérer vos propres endpoints téléphoniques personnalisés à l’aide de l’Auth0 <Tooltip tip="Management API : Un produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>.
