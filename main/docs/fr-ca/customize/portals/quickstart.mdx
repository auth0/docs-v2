Vous pouvez créer un portail à l’aide de :

* [Auth0 CLI](/docs/fr-ca/deploy-monitor/auth0-cli#auth0-cli) pour provisionner et configurer une application et un portail avec une seule commande.
* [Auth0 Agent Skills](https://github.com/auth0/agent-skills) pour demander à votre assistant IA préféré de provisionner et configurer une application et un portail.

{/*- L’[Auth0 Dashboard](/docs/get-started/auth0-overview/dashboard#auth0-dashboard) en suivant des instructions étape par étape pour créer une application et un portail.   */}

<div id="prerequisites">
  ## Prérequis
</div>

* Un tenant Auth0 de [développement](/docs/fr-ca/get-started/tenant-settings#environment-tag) configuré avec l’accès à la version bêta de Universal Portals.

<Tabs>
  <Tab title="Auth0 CLI">
    <div id="step-1-install-the-auth0-cli-beta">
      ## Étape 1 : Installez la bêta d’Auth0 CLI
    </div>

    Suivez les [instructions d’installation](https://github.com/auth0/auth0-cli/#linux-and-macos-1) correspondant à votre plateforme, puis authentifiez-vous auprès de votre tenant :

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">
      Utilisateurs de Homebrew ayant déjà installé la version stable de l’CLI `auth0` : le binaire bêta est masqué par votre installation existante. Ajoutez l’alias suivant à la configuration de votre shell pour que les commandes de ce guide fonctionnent telles qu’elles sont écrites :

      ```bash
      alias auth0-beta="$(brew --prefix auth0-beta)/bin/auth0"
      ```
    </Callout>

    ```bash
    auth0-beta login
    ```

    <div id="step-2-run-the-setup-command">
      ## Étape 2 : Exécutez la commande de configuration
    </div>

    ```bash
    auth0-beta universal-portals setup
    ```

    Vous pouvez aussi utiliser l’alias `auth0-beta up setup`. La commande Auth0 CLI crée :

    * **My Account API** : un serveur de ressources pour les opérations liées aux comptes d’utilisateur
    * **My Organization API** : un serveur de ressources pour les opérations de gestion des organisations
    * **A Regular Web App** : l’application liée à votre portail
    * **Three client grants** : un accès limité par portée aux opérations de My Account API, My Organization API et Management API
    * **A portal** : préconfiguré avec un modèle par défaut pour vous permettre de commencer les tests immédiatement

    Une fois la commande exécutée, elle affiche l’URL de votre portail. Ouvrez-la dans votre navigateur pour tester le portail.
  </Tab>

  <Tab title="Auth0 Agent Skills">
    <div id="step-1-install-auth0-agent-skills">
      ## Étape 1 : Installer Auth0 Agent Skills
    </div>

    ```bash
    npx skills add auth0/agent-skills
    ```

    <div id="step-2-ask-your-ai-agent-to-configure-universal-portals">
      ## Étape 2 : Demandez à votre agent d’IA de configurer les portails Universal
    </div>

    ```bash
    configure universal portals on my auth0 tenant
    ```

    L’agent IA crée :

    * **My Account API** : serveur de ressources pour les opérations liées aux comptes d’utilisateur
    * **My Organization API** : serveur de ressources pour les opérations de gestion des organisations
    * **Une application Web classique** : l’application liée à votre portail
    * **Trois autorisations client** : accès limité par portée aux opérations de My Account, My Organization et de la Management API
    * **Un portail** : préconfiguré avec un modèle par défaut pour vous permettre de commencer les tests immédiatement

    Lorsque la commande se termine, elle affiche l’URL de votre portail. Ouvrez-la dans votre navigateur pour tester le portail.

    Pour en savoir plus, consultez [Auth0 Agent Skills](https://github.com/auth0/agent-skills).
  </Tab>
