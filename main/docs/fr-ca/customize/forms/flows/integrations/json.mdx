Cette liste d’actions JSON vous permet de créer, d’analyser et de convertir du JSON en chaîne de caractères.

## Créer un objet JSON {#create-json-object}

Crée un objet JSON. C’est particulièrement utile pour réutiliser son contenu dans d’autres actions du flux.

<Frame>![](/docs/images/cdy7uua7fh8z/1zJEENRPI2uONuCApPY98p/f1fce88a42fb13fb9856c95c562bd506/createjsonobject.png)</Frame>

### Paramètres d’entrée {#input-settings}

| Paramètre | Description   |
| --------- | ------------- |
| Corps     | L’objet JSON. |

### Objet de sortie {#output-object}

| Propriété | Type  | Description   |
| --------- | ----- | ------------- |
| `result`  | Objet | L’objet JSON. |

### Exemple d’objet de sortie {#output-object-example}

```json lines
{
	"result": {
		"name": "John Doe"
	}
}
```

## Analyser un objet JSON {#parse-json}

Analyse un objet JSON contenu dans une chaîne de caractères pour le convertir en objet JSON.

<Frame>![](/docs/images/cdy7uua7fh8z/5HjIGbBiWik1XozAZczxg5/fe2b0c6f7c657c4209921f1a0978e54b/parsejson.png)</Frame>

### Paramètres d’entrée {#input-settings-2}

| Paramètre                 | Description     |
| ------------------------- | --------------- |
| Chaîne JSON (obligatoire) | La chaîne de caractères JSON. |

### Objet de sortie {#output-object-2}

| Propriété | Type  | Description           |
| --------- | ----- | --------------------- |
| `object`  | Objet | L’objet JSON analysé. |

### Exemple d’objet de sortie {#output-object-example-2}

```json lines
{
  "object": {
    "name": "John Doe"
  }
}
```

## Convertir un objet JSON en chaîne de caractères {#convert-json-to-string}

Convertit un objet JSON en chaîne de caractères.

<Frame>![](/docs/images/cdy7uua7fh8z/45acWYMlTGc5ZWMzK5Cqqr/6974ea640a76d2d9cc5814225e52734a/convertjsontostring.png)</Frame>

### Paramètres d’entrée {#input-settings-3}

| Paramètre                | Description                                              |
| ------------------------ | -------------------------------------------------------- |
| objet JSON (obligatoire) | L’objet JSON qui sera sérialisé en chaîne de caractères. |

### Objet de sortie {#output-object-3}

| Propriété | Type   | Description             |
| --------- | ------ | ----------------------- |
| `json`    | String | L’objet JSON sérialisé. |

### Exemple d’objet de sortie {#output-object-example-3}

```json lines
{
  "json": "{\"name\":\"John Doe\"}"
}
```
