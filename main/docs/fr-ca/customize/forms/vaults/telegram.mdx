## Obtenez votre token Telegram {#get-your-telegram-token}

Découvrez comment générer un token avec l’[API bot de Telegram](https://core.telegram.org/#bot-api).

## Configurez votre Telegram Vault Connection {#configure-your-telegram-vault-connection}

Pour configurer une Telegram Vault Connection pour vos Telegram Flow Actions, vous devez renseigner les paramètres requis.

<Frame>![Dashboard > Actions > Forms > Vault > SendGrid](/docs/images/customize/forms/vaults/telegram-vault-connection.png)</Frame>

### Paramètres d’entrée {#input-settings}

| Paramètre | Description                                         |
| --------- | --------------------------------------------------- |
| Token     | Token généré pour l’autorisation de l’API Telegram. |
