## Action {#action}

L&#39;action Post Login suivante importe un module personnalisé pour récupérer les rôles de l&#39;utilisateur auprès d&#39;un service externe et les ajoute au jeton d&#39;accès sous forme de demande personnalisée, en refusant l&#39;accès si l&#39;appel au module échoue.

## Test unitaire {#unit-test}

Les tests unitaires chargent l&#39;action avec le module personnalisé et simulent `fetch` afin de vérifier que les rôles sont bien attribués en cas de succès et que l&#39;accès est refusé lorsque le service externe renvoie un statut d&#39;erreur ou que la requête échoue en raison d&#39;une erreur réseau.
