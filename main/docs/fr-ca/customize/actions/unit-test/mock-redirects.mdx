## Action {#action}

L&#39;action Password Reset Post Challenge suivante redirige l&#39;utilisateur vers une page externe de vérification d&#39;identité lorsque son pointage de risque dépasse un seuil donné, puis valide le jeton de session renvoyé ainsi que le résultat de la vérification avant de laisser la réinitialisation du mot de passe se poursuivre.

## Unit Test {#unit-test}

Les tests unitaires simulent les objets `event` et `api`, ainsi que l&#39;encodage et la validation du jeton de redirection, afin de vérifier que la redirection ne se déclenche qu&#39;au-delà du seuil de risque et que l&#39;accès est refusé dans le cas de jetons invalides, d&#39;utilisateurs non concordants ou d&#39;une vérification incomplète.
