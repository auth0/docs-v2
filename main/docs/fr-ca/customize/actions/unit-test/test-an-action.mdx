## Action {#action}

L&#39;action Post Login suivante vérifie les rôles de l&#39;utilisateur à partir de `event.authorization` et les ajoute comme demande personnalisée au jeton d&#39;ID; l&#39;accès est refusé si aucun rôle n&#39;est présent.

## Test unitaire {#unit-test}

Les tests unitaires simulent les objets `event` et `api` afin de vérifier que les utilisateurs administrateurs obtiennent bien la demande personnalisée, tandis que les utilisateurs sans rôle ou dont l&#39;objet `authorization` est absent se voient refuser l&#39;accès.
