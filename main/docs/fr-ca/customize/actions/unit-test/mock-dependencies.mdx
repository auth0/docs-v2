## Action {#action}

L&#39;action Pre User Registration suivante refuse les inscriptions provenant d&#39;un domaine de courriel interdit, exige la saisie d&#39;un nom complet et, le cas échéant, enregistre ce nom dans `user_metadata` ainsi qu&#39;un identifiant généré aléatoirement dans `app_metadata`.

## Test unitaire {#unit-test}

Les tests unitaires simulent les objets `event` et `api` afin de vérifier que le domaine interdit est refusé, qu&#39;un nom complet manquant déclenche une erreur de validation et qu&#39;une soumission valide enregistre le nom complet ainsi qu&#39;un UUID correctement formaté.
