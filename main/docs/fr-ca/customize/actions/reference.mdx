title: Présentation de la référence des Actions
sidebarTitle: Présentation
description: Consultez les objets d’événement et api disponibles pour chaque déclencheur des Actions Auth0, ainsi que les données de transaction que vous pouvez lire et les méthodes que vous pouvez appeler depuis votre code personnalisé.
---

Chaque Action Auth0 reçoit deux objets lorsque son déclencheur se déclenche :

* L’**objet d’événement** contient le contexte de la transaction en lecture seule : des renseignements sur l’utilisateur, la requête, le client, le tenant et la connexion au moment où le déclencheur se déclenche.
* L’**objet api** expose les méthodes que votre Action peut appeler pour modifier le résultat de la transaction, notamment pour rejeter l’accès, ajouter des claims au jeton, lancer des défis ou mettre des données en cache.

Les objets disponibles varient selon le déclencheur. Sélectionnez un déclencheur ci-dessous pour consulter la référence de ses objets d’événement et api. Pour savoir quand chaque déclencheur se déclenche et comment y associer des Actions, consultez [Explorer les déclencheurs](/docs/fr-ca/customize/actions/explore-triggers).
