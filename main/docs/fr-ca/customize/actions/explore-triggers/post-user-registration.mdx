---
title: "Post-inscription d’un utilisateur"
description: Découvrez les Actions de post-inscription d’un utilisateur, qui s’exécutent après la création d’un utilisateur dans une connexion Database ou Passwordless. Elles permettent d’aviser un autre système qu’un utilisateur s’est inscrit.
---

Le déclencheur `post-user-registration` s’exécute après l’ajout d’un utilisateur à une connexion Database ou <Tooltip tip="Passwordless : méthode d’authentification qui ne repose pas sur un mot de passe comme premier facteur." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Passwordless">Passwordless</Tooltip>. Utilisez ce déclencheur pour aviser un autre système qu’un utilisateur s’est inscrit à votre application. Plusieurs Actions peuvent être associées à ce déclencheur et s’exécutent dans l’ordre.

<Frame>![Diagramme du flux de post-inscription d’un utilisateur des Actions.](/docs/images/cdy7uua7fh8z/4bqF9YEPYQshnJGCx39pws/079798c354f4a83355a756a6a02650d5/post-user-registration-flow.png)</Frame>

Les Actions de ce flux ne bloquent pas l’exécution (elles sont asynchrones) : le pipeline Auth0 continue de s’exécuter sans attendre que l’Action se termine; le résultat de l’Action n’a donc aucune incidence sur la transaction Auth0.

<div id="notify-slack-when-a-new-user-registers">
  ### Notifier Slack lorsqu’un nouvel utilisateur s’inscrit
</div>

Une Action post-user-registration peut servir à aviser un canal Slack de chaque nouvel enregistrement :

```javascript lines
/**
 * @param {Event} event - Détails sur le contexte et l’utilisateur qui s’est inscrit.
 * @param {PostUserRegistrationAPI} api - Interface dont les méthodes permettent de modifier le comportement après l’inscription d’un utilisateur.
 */
exports.onExecutePostUserRegistration = async (event, api) => {
  const { IncomingWebhook } = require("@slack/webhook");
  const webhook = new IncomingWebhook(event.secrets.SLACK_WEBHOOK_URL);

  const text = `New User: ${event.user.email}`;
  const channel = '#some_channel';

  webhook.send({ text, channel });
};
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Pour que cette Action s’exécute correctement, elle doit contenir un Secret nommé `SLACK_WEBHOOK_URL` et dépendre du package `@slack/webhook` de `npm`.
</Callout>

<div id="store-the-auth0-user-id-in-a-remote-system">
  ### Stocker l’ID utilisateur Auth0 dans un système distant
</div>

Une Action post-user-registration permet de stocker l’ID utilisateur Auth0 dans un système distant :

```javascript lines
const axios = require("axios");

/**
 * @param {Event} event - Détails sur le contexte et l’utilisateur qui s’est inscrit.
 * @param {PostUserRegistrationAPI} api - Interface dont les méthodes permettent de modifier le comportement de post-inscription d’un utilisateur.
 */
exports.onExecutePostUserRegistration = async (event, api) => {
  await axios.post("https://my-api.exampleco.com/users", { params: { email: event.user.email }});
};
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Pour utiliser une bibliothèque `npm` comme `axios`, vous devez l’ajouter comme dépendance à l’action. Pour en savoir plus, consultez la section &quot;Ajouter une dépendance&quot; de [Write Your First Action](/docs/fr-ca/customize/actions/write-your-first-action).
</Callout>
