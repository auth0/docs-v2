---
title: "Event Stream"
description: Découvrez les Actions Event Stream, qui s’exécutent de façon asynchrone lorsque les types d’événements abonnés surviennent dans votre tenant Auth0. Elles permettent de transmettre des événements à des systèmes externes sans affecter la transaction de l’utilisateur.
---

Le trigger `event-stream` s’exécute lorsque des événements précis surviennent dans votre tenant Auth0. Chaque Action Event Stream est associée à un Event Stream et écoute un ensemble prédéfini de [types d’événements](/docs/fr-ca/events) (par exemple, des connexions réussies, des changements de mot de passe ou des suppressions d’utilisateurs). Lorsqu’un événement abonné survient, l’Action est déclenchée. Contrairement aux Actions Login ou Pre-Registration, les Actions Event Stream s’exécutent en arrière-plan et n’affectent pas la transaction principale de l’utilisateur.

<Frame>![Diagramme montrant comment les Actions Event Stream s’abonnent aux événements du tenant et les traitent.](/docs/images/customize/actions/event-stream-triggers.svg)</Frame>

Les Actions de ce flux ne sont pas bloquantes (asynchrones) : le pipeline Auth0 continue de s’exécuter sans attendre que l’Action se termine. Le résultat de l’Action n’affecte donc pas la transaction Auth0 et n’a aucune incidence sur la latence de l’expérience utilisateur.

<div id="synchronize-events-to-an-external-service">
  ### Synchroniser des événements vers un service externe
</div>

Une Action event-stream peut servir à transmettre un événement particulier à un service externe selon une logique personnalisée. L’Action suivante montre comment transmettre de manière sécurisée un message d’événement à un service externe à l’aide d’une clé API enregistrée :

```javascript lines
/**
 * @param {Event} event - Détails sur l'événement entrant.
 * @param {EventStreamAPI} api - Méthodes et utilitaires permettant de définir le traitement du flux d'événements.
 */
exports.onExecuteEventStream = async (event, api) => {
  const message = event.message;

  try {
    await fetch(event.secrets.URL, {
      method: 'POST',
      headers: {
        'X-API-Key': event.secrets.API_KEY,
      },
      body: JSON.stringify(message),
    });
  } catch (err) {
    throw new Error('External service failure');
  }

  return;
};
```
