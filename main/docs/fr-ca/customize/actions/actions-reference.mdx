La référence des Actions documente l’**objet event** (contexte de transaction en lecture seule) et l’**objet api** (méthodes permettant de modifier le comportement de la transaction) accessibles à votre code personnalisé pour chaque déclencheur Actions.

La référence se trouve maintenant dans son propre catalogue sous **Outils de développement**, aux côtés des références des API, des SDK et du catalogue Events.
