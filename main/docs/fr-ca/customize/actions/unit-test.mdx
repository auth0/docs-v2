Grâce au paquet NPM [`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions), vous pouvez écrire des tests unitaires pour vos Actions et les exécuter localement, dans votre système de contrôle de version ou dans un processus CI/CD, ce qui permet de détecter les problèmes avant qu&#39;ils n&#39;atteignent votre locataire Auth0.

## Fonctionnement {#how-it-works}

Suivez les consignes d&#39;installation et d&#39;importation décrites à la page : [Fonctionnement des Actions NPM](/docs/fr-ca/customize/actions/npm/write-your-action-using-your-code-editor).

Pour effectuer un unit test d&#39;une Action, vous devez simuler les objets `event` et `api` que reçoit votre fonction d&#39;Action. Vous pouvez créer ces simulations à l&#39;aide des définitions TypeScript incluses dans `auth0/actions`, ce qui garantit que vos tests reflètent fidèlement l&#39;environnement de production. Les cadres d&#39;applications de test comme Jest sont tout indiqués pour gérer la simulation et les fonctionnalités.
