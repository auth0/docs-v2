Le paquet NPM [`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions) est la bibliothèque officielle de définitions TypeScript et JavaScript pour Auth0 Actions. Il vous offre la prise en charge par votre IDE, la vérification des types et une structure pour écrire des Actions dans votre propre éditeur de code, en dehors du Auth0 Dashboard.

## Avantages {#benefits}

* **Assistance dans l&#39;IDE ou l&#39;éditeur de code** : profitez de l&#39;autocomplétion, de la documentation intégrée et des indications de type pour les objets `event` et `api` dans vos Actions.
* **Développement en TypeScript** : écrivez vos Actions en TypeScript en profitant d&#39;un typage entièrement sécurisé, ce qui permet de détecter les erreurs avant le déploiement.
* **Tests unitaires améliorés** : utilisez les définitions de types incluses pour créer des simulacres fidèles des objets `event` et `api` dans vos tests.
* **Génération d&#39;Actions par IA** : fournissez un meilleur contexte aux assistants de codage par IA, ce qui améliore la qualité du code d&#39;Action généré.

## Fonctionnement {#how-it-works}

Installez [`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions) comme dépendance de développement dans votre projet, puis importez ses types pour écrire du code d&#39;Actions en dehors du Auth0 Dashboard. Le paquet fournit les définitions de types des objets `event` et `api` qu&#39;Auth0 transmet à votre Action à l&#39;exécution, ce qui permet à votre éditeur de valider la structure de ces données à mesure que vous écrivez.

Comme les types correspondent à ce que fournit le runtime du Dashboard, une Action écrite et vérifiée localement se comporte exactement de la même façon une fois déployée.
