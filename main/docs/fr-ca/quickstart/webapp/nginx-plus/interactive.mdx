  <Content>
    Ce tutoriel montre comment utiliser le module nginx-openid-connect pour ajouter l’authentification et l’autorisation à
    votre serveur NGINX. Nous vous recommandons de vous connecter pour suivre ce Quickstart avec des exemples configurés pour votre compte.

    <Section id={sections[0].id} title={sections[0].title} stepNumber="1">
      Ce tutoriel et ce projet de départ ont été testés avec les éléments suivants :

      * NGINX Plus R24
    </Section>

    <Section id={sections[1].id} title={sections[1].title} stepNumber="2">
      Vous devez d’abord installer le module `nginx-plus-module-njs` pour NGINX Plus.

      Suivez le guide d’installation des modules dynamiques pour installer les packages sur le système d’exploitation hôte.

      Pour les distributions Linux qui utilisent le gestionnaire de packages `yum`, vous pouvez installer le module comme suit :

      ```sh lines
      sudo yum install nginx-plus-module-njs jq
      ```

      Une fois l’installation terminée, vous devez l’activer pour NGINX en ajoutant la ligne suivante au début de votre fichier
      `/etc/nginx/nginx.conf` :

      ```sh lines
      load_module modules/ngx_http_js_module.so;
      ```
    </Section>

    <Section id={sections[2].id} title={sections[2].title} stepNumber="3">
      Clonez le repository `nginx-openid-connect`. Ce repository comprend un modèle de configuration.

      ```sh lines
      git clone https://github.com/nginxinc/nginx-openid-connect
      ```
    </Section>

    <Section id={sections[3].id} title={sections[3].title} stepNumber="4">
      Exécutez le script configure.sh dans le dossier nginx-openid-connect pour remplir le modèle de configuration de
      votre application Auth0 :

      ```sh lines
      ./configure.sh --auth_jwt_key request \
      --client_id {yourClientId} \
      --pkce_enable \
      https://{yourDomain}/.well-known/openid-configuration
      ```

      Ensuite, ajoutez l’[URL de logout de votre tenant](https://auth0.com/docs/api/authentication#auth0-logout) à votre
      fichier `openid_connect_configuration.conf`.
    </Section>

    <Section id={sections[4].id} title={sections[4].title} stepNumber="5">
      Ajoutez l’en-tête `Accept-Encoding` et définissez sa valeur à `gzip` dans votre
      fichier `openid_connect.server_conf`.
    </Section>

    <Section id={sections[5].id} title={sections[5].title} stepNumber="6">
      Copiez vos quatre fichiers de configuration dans le dossier `conf.d`.

      ```sh lines
      sudo cp openid_connect.js \ 
      frontend.conf \
      openid_connect_configuration.conf \
      openid_connect.server_conf /etc/nginx/conf.d
      ```
    </Section>

    <Section id={sections[6].id} title={sections[6].title} stepNumber="7">
      Dans le Auth0 Dashboard :

      1. Accédez à **Applications** &gt; **Applications**, puis sélectionnez votre application dans la liste.
      2. Passez à la vue **Settings**.
      3. Dans la section **Application URIs**, ajoutez `https://{yourDomain}/_codexch`
         à **Allowed Callback URLs**.
      4. Passez à la vue **Credentials**.

      Dans la section **Application Authentication**, définissez **Authentication Method** sur None.
    </Section>

    <Section id={sections[7].id} title={sections[7].title} stepNumber="8">
      Ajoutez des en-têtes supplémentaires provenant de l’ID token (JWT) à la cible upstream dans votre
      fichier `/etc/nginx/conf.d/frontend.conf`.
    </Section>
