---
title: Universal Login vs. Classic Login
description: Compare les fonctionnalités offertes par Universal Login et Classic Login
---

[Auth0 Universal Login](/docs/fr-ca/authenticate/login/auth0-universal-login) offre une fonctionnalité essentielle d’un <Tooltip tip="Authorization Server : Serveur centralisé qui aide à définir les limites de l’accès d’un utilisateur. Par exemple, votre serveur d’autorisation peut contrôler les données, les tâches et les fonctionnalités auxquelles un utilisateur a accès." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=authorization+server">serveur d’autorisation</Tooltip> : le flux de connexion. Lorsqu’un utilisateur doit prouver son identité pour accéder à votre application, vous pouvez le rediriger vers <Tooltip tip="Authorization Server : Serveur centralisé qui aide à définir les limites de l’accès d’un utilisateur. Par exemple, votre serveur d’autorisation peut contrôler les données, les tâches et les fonctionnalités auxquelles un utilisateur a accès." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Universal+Login">Universal Login</Tooltip> et laisser Auth0 gérer le processus d’authentification.

Universal Login est la principale solution de connexion hébergée d’Auth0. [Universal Login](/docs/fr-ca/authenticate/login/auth0-universal-login/universal-login-vs-classic-login/universal-experience) offre des outils de personnalisation faciles à utiliser et propose une expérience plus simple et plus rapide aux utilisateurs finaux. Auth0 prend également en charge [Classic Login](/docs/fr-ca/authenticate/login/auth0-universal-login/universal-login-vs-classic-login/classic-experience), une expérience de connexion hébergée qui utilise des contrôles JavaScript pour la personnalisation.

<Warning>
  À l’heure actuelle, les efforts de développement d’Auth0 sont axés sur Universal Login, et Classic Login ne reçoit plus de mises à jour. À moins que votre cas d’utilisation ne nécessite précisément l’expérience Classic, il est recommandé d’adopter Universal Login.
</Warning>
