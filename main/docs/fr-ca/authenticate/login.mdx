Auth0 propose deux façons de mettre en œuvre l’authentification de connexion pour vos applications :

* **<Tooltip tip="Universal Login : votre application redirige vers Universal Login, hébergé sur le serveur d’autorisation d’Auth0, afin de vérifier l’identité d’un utilisateur." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Universal+Login">Universal Login</Tooltip>**, où les utilisateurs se connectent à votre application à partir d’une page hébergée par Auth0.

* **Embedded Login**, où les utilisateurs se connectent à votre application à partir d’une page que vous hébergez.

Au moment de choisir une méthode de connexion, nous recommandons Universal Login dans la plupart des cas d’utilisation. Cette solution est sécuritaire et facile à mettre en œuvre. Bien que la connexion intégrée vous donne davantage de contrôle sur l’UI, les risques accrus et les exigences de maintenance l’emportent sur ses avantages.
