description: Le script Delete s’exécute lorsque vous devez supprimer un utilisateur donné de votre magasin d’utilisateurs externe et il est requis si vous souhaitez également supprimer l’utilisateur d’Auth0 dans la même opération.
---

Le script Delete implémente la fonction définie pour supprimer un utilisateur donné d’une base de données externe. Nous recommandons de nommer cette fonction `deleteUser`.

Ce script n’est utilisé que dans un [scénario d’authentification héritée](/docs/fr-ca/authenticate/database-connections/custom-db/overview-custom-db-connections) et il est requis si vous souhaitez supprimer un utilisateur d’Auth0 et de votre base de données externe dans la même opération.

<div id="deleteuser-function">
  ## Fonction DeleteUser
</div>

La fonction `deleteUser` doit :

* Supprimer l’utilisateur spécifié de la base de données externe.
* Retourner une valeur `null` si la suppression a réussi.
* Retourner une erreur si la suppression a échoué.

<div id="definition">
  ### Définition
</div>

La fonction `deleteUser` accepte deux paramètres et renvoie une fonction de rappel :

```js lines
deleteUser(id, callback): function
```

| Paramètre  | Type     | Description                                                                   |
| ---------- | -------- | ----------------------------------------------------------------------------- |
| `id`       | String   | L’identity `user_id` de l’utilisateur. Ne commence pas par `auth0`.           |
| `callback` | Function | Utilisé pour transmettre une erreur ou des données de profil via le pipeline. |

Voici un pseudo-exemple en Javascript illustrant comment vous pourriez implémenter la fonction `deleteUser` :

```javascript lines
function deleteUser(id, callback) {
  // Envoyer l'identifiant de l'utilisateur à l'API de base de données externe
  let options = {
    url: "https://example.com/api/deleteUser",
    body: {
      id: id
    }
  };

  send(options, (err, profileData) => {
    // Retourner une erreur dans le callback si la suppression a échoué
    if (err) {
      return callback(new Error("My custom error message."));
    }

    // Retourner une valeur null dans le callback si la suppression a réussi
    return callback(null);
  });
}
```

<div id="callback-function">
  ## Fonction de rappel
</div>

La fonction `callback` accepte un paramètre et renvoie une fonction.

<div id="definition-2">
  ### Définition
</div>

```js lines
callback(error): function
```

| Paramètre | Type  | Obligatoire | Description                    |
| --------- | ----- | ----------- | ------------------------------ |
| `error`   | Objet | Obligatoire | Contient les données d’erreur. |

<div id="return-a-success">
  ### Retourner une réussite
</div>

Si l’utilisateur a bien été supprimé de votre base de données externe, appelez la fonction de rappel et transmettez une valeur `null` pour le paramètre `error` :

```js lines
return callback(null);
```

<div id="return-an-error">
  ### Retourner une erreur
</div>

Si une erreur se produit, appelez la fonction de rappel et transmettez au paramètre `error` les renseignements pertinents sur l’erreur :

```js lines
return callback(new Error("My custom error message."));
```

  function remove (id, callback) {
    // Ce script supprime un utilisateur de votre base de données existante.

    //
    // Ce script peut se terminer de deux façons :
    // 1. L'utilisateur a été supprimé avec succès :
    //     callback(null);
    // 2. Un problème est survenu en tentant d'accéder à votre base de données :

    var msg = "Please implement the Delete script for this database " +

    return callback(new Error(msg));
  }

  // Pour ASP.NET Membership Provider (MVC3 - fournisseurs Universal)
  function remove(id, callback) {
    const sqlserver = require('tedious@1.11.0');
    const Connection = sqlserver.Connection;
    const Request = sqlserver.Request;
    const TYPES = sqlserver.TYPES;
    const connection = new Connection({
      userName: 'the username',
      password: 'the password',
      server: 'the server',
      options: {
        database: 'the db name',
        encrypt: true,
        // Requis pour récupérer l'userId nécessaire à la création de l'entité Membership
        rowCollectionOnRequestCompletion: true
      }
    });
    connection.on('debug', function(text) {
      // si vous avez des problèmes de connexion, décommentez ceci pour obtenir des informations plus détaillées
      // console.log(text);
    }).on('errorMessage', function(text) {
      // ceci affichera toutes les erreurs lors de la connexion à la base de données SQL ou avec les instructions SQL
      console.log(JSON.stringify(text));
    });
    connection.on('connect', function(err) {
      if (err) return callback(err);
      executeDelete(['Memberships', 'Users'], function(err) {
        if (err) return callback(err);
        callback(null);
      });
    });
    function executeDelete(tables, callback) {
      const query = tables.map(function(table) {
        return 'DELETE FROM ' + table + ' WHERE UserId = @UserId';
      }).join(';');
      const request = new Request(query, function(err) {
        if (err) return callback(err);
        callback(null);
      });
      request.addParameter('UserId', TYPES.VarChar, id);
      connection.execSql(request);
    }
  }

  function remove(id, callback) {
    const MongoClient = require('mongodb@3.1.4').MongoClient;
    const client = new MongoClient('mongodb://user:pass@mymongoserver.com');
    client.connect(function (err) {

      const users = db.collection('users');
      users.remove({ _id: id }, function (err) {

        callback(null);
