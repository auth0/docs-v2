Pour en savoir plus sur les opérations de gestion SCIM prises en charge et sur la façon de les utiliser, consultez la [documentation de l’Auth0 Management API](/docs/fr-ca/api/management/v2) et développez l’onglet **Connections**. La <Tooltip tip="Management API : Un produit permettant aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=management+API">Management API</Tooltip> permet d’activer, de mettre à jour et de supprimer la configuration SCIM pour une connexion sélectionnée, ainsi que de créer et de supprimer des jetons SCIM.

<div id="register-a-client-app-for-management-api-communication">
  ## Enregistrer une application cliente pour communiquer avec la Management API
</div>

Pour utiliser l’Auth0 Management API, enregistrez une application cliente machine-to-machine qui possède les permissions nécessaires pour gérer votre configuration SCIM.

1. Dans l’[Auth0 Dashboard](https://manage.auth0.com/#/), sélectionnez **Applications**.
2. Sélectionnez **Create Application**.
3. Entrez un nom, sélectionnez **Machine to Machine App**, puis sélectionnez **Create**.
4. Dans votre nouvelle application, sélectionnez l’onglet **APIs**, puis réglez **Auth0 Management API** sur **Authorized**.
5. Sous **Permissions**, sélectionnez `read:scim_config`, `create:scim_config`, `update:scim_config`, `delete:scim_config`, `create:scim_token`, `read:scim_token`, et `delete:scim_token.`
6. Sélectionnez **Update**.
7. Suivez les instructions dans [Management API Access Tokens](/docs/fr-ca/secure/tokens/access-tokens/management-api-access-tokens) pour savoir comment obtenir des jetons et effectuer des requêtes aux endpoints de l’[Auth0 Management API v2](/docs/fr-ca/api/management/v2/connections/post-scim-configuration).
