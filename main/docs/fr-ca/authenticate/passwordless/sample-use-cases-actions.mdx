Les [Actions](/docs/fr-ca/customize/actions/actions-overview) vous permettent d’étendre les [connexions sans mot de passe](/docs/fr-ca/authenticate/passwordless) en acheminant l’envoi d’OTP par SMS et par courriel vers des fournisseurs personnalisés. Les Actions Auth0 vous permettent de choisir les services téléphoniques et de courriel qui gèrent vos messages d’authentification.

<div id="send-passwordless-email-with-a-custom-email-provider">
  ## Envoyer un courriel Passwordless avec un fournisseur de courriel personnalisé
</div>

Lorsqu’un utilisateur [s’authentifie au moyen d’une connexion Passwordless par courriel](/docs/fr-ca/authenticate/passwordless/authentication-methods/email-otp), Auth0 déclenche l’Action `custom-email-provider` pour transmettre l’OTP. Utilisez cette Action pour acheminer les messages par l’intermédiaire de n’importe quel service de courriel.

Pour configurer l’Action, accédez à [**Branding &gt; Email Provider**](https://manage.auth0.com/#/templates/provider), activez la bascule Use my own email provider, puis sélectionnez l’option **Custom Provider**. Ajoutez l’adresse par défaut de votre fournisseur personnalisé dans le champ From. Pour en savoir plus, consultez [configurer un fournisseur de courriel avec une Action personnalisée](/docs/fr-ca/customize/email/smtp-email-providers/custom/configure-action).

Dans l’éditeur Actions, utilisez l’exemple suivant.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Vous devez ajouter le endpoint de service de votre fournisseur de courriel au code Actions et la clé API dans l’onglet Secrets de l’éditeur Actions.
</Callout>

```javascript lines
/**
 * Gestionnaire appelé lorsqu’Auth0 doit envoyer un OTP par courriel Passwordless.
 * @param {Event} event - Détails de la notification.
 * @param {CustomEmailProviderAPI} api - Méthodes permettant de contrôler le comportement de la notification.
 */
exports.onExecuteCustomEmailProvider = async (event, api) => {
  try {
    const response = await fetch('https://api.example.com/send-email', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${event.secrets.API_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        to: event.notification.to,
        from: event.notification.from,
        subject: event.notification.subject,
        html: event.notification.html,
        text: event.notification.text,
      }),
    });

    if (response.status >= 400) {
      api.notification.retry(`Request failed with status: ${response.status}`);
      return;
    }
  } catch (error) {
    api.notification.drop(`Unexpected error: ${error.message}`);
  }
};
```

Sélectionnez **Envoyer un courriel de test** pour tester votre configuration.

Pour en savoir plus sur les propriétés d’événement disponibles, consultez [Déclencheurs Actions : custom-email-provider - Objet d’événement](/docs/fr-ca/customize/email/smtp-email-providers/custom/action-triggers-custom-email-provider-event-object).

<div id="send-passwordless-sms-with-a-custom-phone-provider">
  ## Envoyer des SMS sans mot de passe avec un fournisseur de téléphonie personnalisé
</div>

Lorsqu’un utilisateur [s’authentifie au moyen d’une connexion SMS sans mot de passe](/docs/fr-ca/authenticate/passwordless/authentication-methods/sms-otp), Auth0 déclenche l’Action `custom-phone-provider` pour envoyer l’OTP. Utilisez cette Action pour acheminer les messages par l’intermédiaire de n’importe quel fournisseur de SMS.

Pour configurer l’Action, accédez à [**Branding &gt; Phone Provider**](https://manage.auth0.com/dashboard/#/phone/templates/phone/provider). Activez Phone Message Provider et sélectionnez l’option **Custom**. Choisissez Text, Voice ou les deux comme méthode de livraison. Pour en savoir plus, consultez [Configurer un fournisseur de téléphonie personnalisé](/docs/fr-ca/customize/phone-messages/configure-phone-messaging-providers/configure-a-custom-phone-provider).

Dans l’éditeur Actions, utilisez l’exemple suivant.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Vous devez ajouter l’endpoint de service de votre fournisseur de téléphonie au code Actions, ainsi que la clé API dans l’onglet Secrets de l’éditeur Actions.
</Callout>

```javascript lines
/**
 * Gestionnaire appelé lorsque Auth0 doit transmettre un OTP par SMS sans mot de passe.
 * @param {Event} event - Détails de la notification.
 * @param {CustomPhoneProviderAPI} api - Méthodes permettant de contrôler le comportement de la notification.
 */
exports.onExecuteCustomPhoneProvider = async (event, api) => {
  const response = await fetch('https://api.example.com/messages', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${event.secrets.API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      to: event.notification.recipient,
      from: event.notification.from,
      body: event.notification.as_text,
    }),
  });

  if (response.status >= 400) {
    api.notification.retry(`La requête a échoué avec le statut : ${response.status}`);
  }
};
```

Choisissez **Envoyer un message texte** pour tester votre configuration.

Pour en savoir plus sur les propriétés d’événement disponibles, consultez [Déclencheurs Actions : custom-phone-provider - objet d’événement](/docs/fr-ca/customize/phone-messages/configure-phone-messaging-providers/configure-a-custom-phone-provider/actions-triggers-custom-phone-provider-event-object).
