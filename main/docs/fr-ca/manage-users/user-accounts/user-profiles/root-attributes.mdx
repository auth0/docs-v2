---
title: Modifier les attributs du profil utilisateur
description: Découvrez les attributs disponibles pour le profil d'utilisateur normalisé d’Auth0 et les méthodes pour les mettre à jour.
---

Le [profil d&#39;utilisateur normalisé](/docs/fr-ca/manage-users/user-accounts/user-profiles/user-profile-structure) d’Auth0 contient un certain nombre d’attributs racines (attributs stockés au premier niveau, ou niveau racine, de l’objet), dont certains peuvent être mis à jour. La méthode pour définir et mettre à jour les attributs varie selon que vous utilisez une connexion avec Auth0 comme <Tooltip tip="Fournisseur d'identité (IdP) : service qui stocke et gère les identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Identity+Provider">fournisseur d&#39;identité</Tooltip> (IdP) ou avec un IdP en amont.

* Lorsqu’Auth0 est l’IdP, vous pouvez :

  * Définir les attributs lors de l’inscription de l’utilisateur (au moyen de Management API ou de l’inscription publique)
  * Définir les attributs lors de l’importation d’utilisateurs
  * Modifier les attributs au moyen de Management API

  Auth0 est l’IdP pour les [connexions de base de données](/docs/fr-ca/authenticate/database-connections) (standards et personnalisées avec le mode d’importation activé) et les [connexions sans mot de passe](/docs/fr-ca/authenticate/passwordless).

* Lorsque vous utilisez un IdP en amont, deux options s’offrent à vous :

  * Utiliser le comportement par défaut. L’IdP en amont définit les attributs à la création des utilisateurs, puis les met à jour automatiquement à chaque connexion subséquente. Ces attributs ne peuvent pas être modifiés directement, car l’IdP les met à jour chaque fois que l’utilisateur se connecte.

  * Configurer la synchronisation de la connexion avec Auth0. L’IdP en amont définit les attributs uniquement à la création des utilisateurs, sans les mettre à jour lors des connexions subséquentes; vous pouvez donc modifier ces attributs directement avec Management API.

  Les IdP en amont gèrent les [connexions sociales](/docs/fr-ca/authenticate/identity-providers#social), les [connexions d’entreprise](/docs/fr-ca/authenticate/identity-providers#enterprise) et les [connexions d’identité légale](/docs/fr-ca/authenticate/identity-providers#legal-identities).
