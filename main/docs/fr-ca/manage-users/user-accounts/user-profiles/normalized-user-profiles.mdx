---
title: Profils utilisateur normalisés
description: Découvrez comment Auth0 normalise les propriétés utilisateur courantes dans le profil utilisateur.
---

Le profil utilisateur normalisé est une façon propre à Auth0 de standardiser et de stocker les renseignements liés aux utilisateurs. Comme chaque <Tooltip tip="Fournisseur d’identité (IdP) : service qui stocke et gère les identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Identity+Provider">fournisseur d’identité</Tooltip> (IdP) fournit un ensemble différent de renseignements sur un utilisateur, Auth0 normalise les propriétés de profil courantes dans une représentation de l’utilisateur indépendante du protocole au moment de stocker les claims liés à l’utilisateur. Par exemple, `family_name` dans le profil utilisateur normalisé contient des renseignements qui peuvent être renvoyés par un IdP sous la forme de `surname` ou `last_name`.

Par conséquent, les claims Auth0 inclus dans le profil utilisateur normalisé diffèrent de l’ensemble standard de claims pouvant être renvoyés dans les <Tooltip tip="ID Token : identifiant destiné au client lui-même, plutôt qu’à l’accès à une ressource." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=ID+Tokens">ID Tokens</Tooltip> à partir du [point de terminaison `oauth/token` de l’Authentication API](https://auth0.com/docs/api/authentication#get-token) ou dans la réponse du [point de terminaison `/userinfo`](https://auth0.com/docs/api/authentication#user-profile) (qui suivent tous deux les exigences décrites dans la spécification OIDC).

Pour en savoir plus sur les attributs inclus dans le profil utilisateur normalisé et comprendre comment les utiliser, consultez [Structure du profil utilisateur](/docs/fr-ca/manage-users/user-accounts/user-profiles/user-profile-structure).

<div id="normalized-user-profile-schema">
  ## Schéma de profil utilisateur normalisé
</div>

Les attributs qu’Auth0 mappe vers un schéma commun sont énumérés ci-dessous.

Champs toujours générés :

* `name` : le nom complet de l’utilisateur.
* `nickname` : par défaut, la partie locale de l’adresse courriel de l’utilisateur.
* `picture` : l’URL de la [photo de l’utilisateur](/docs/fr-ca/manage-users/user-accounts/change-user-picture). Si elle n’est pas disponible, Auth0 utilise l’image Gravatar associée à l’adresse courriel de l’utilisateur.
* `user_id` : l’identifiant unique de l’utilisateur. Il est unique pour chaque connexion, mais identique pour toutes les applications qui s’authentifient au moyen de cette connexion.

Par défaut, les attributs `name`, `nickname` et `picture` d’un utilisateur fournis par des <Tooltip tip="Fournisseur d’identité (IdP) : service qui stocke et gère les identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=identity+providers">fournisseurs d’identité</Tooltip> autres qu’Auth0 (comme Google, Facebook ou X) ne sont pas directement modifiables, car ils sont mis à jour à partir du fournisseur d’identité chaque fois qu’un utilisateur ouvre une session. Si vous souhaitez pouvoir modifier ces attributs, vous devez [configurer la synchronisation de votre connexion avec Auth0](/docs/fr-ca/manage-users/user-accounts/user-profiles/configure-connection-sync-with-auth0) afin que les attributs utilisateur ne soient mis à jour à partir du fournisseur d’identité qu’à la création du profil utilisateur. Les attributs racine pourront alors être [modifiés individuellement](https://auth0.com/docs/api/management/guides/users/update-root-attributes-users) ou [par importation en bloc](https://auth0.com/docs/api/management/guides/users/update-root-attributes-users) à l’aide de la <Tooltip tip="Management API : produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>.

Champs générés lorsque les renseignements sont disponibles :

* `email` : l’adresse courriel de l’utilisateur.
* `email_verified` : une valeur booléenne indiquant si l’adresse courriel de l’utilisateur a été vérifiée.
* `given_name` : le prénom de l’utilisateur.
* `family_name` : le nom de famille de l’utilisateur.

Lors de la création d’un utilisateur à l’aide du [point de terminaison Create a User de la Management API](https://auth0.com/docs/api/management/v2#!/Users/post_users), vous pouvez fournir les valeurs `given_name` et `family_name`. Par défaut, les attributs `given_name` et `family_name` d’un utilisateur fournis par des fournisseurs d’identité autres qu’Auth0 (comme Google, Facebook ou X) ne sont pas directement modifiables, car ils sont mis à jour à partir du fournisseur d’identité chaque fois qu’un utilisateur ouvre une session. Si vous souhaitez pouvoir modifier ces attributs, vous devez [configurer la synchronisation de votre connexion avec Auth0](/docs/fr-ca/manage-users/user-accounts/user-profiles/configure-connection-sync-with-auth0) afin que les attributs utilisateur ne soient mis à jour à partir du fournisseur d’identité qu’à la création du profil utilisateur. Les attributs racine pourront alors être [modifiés individuellement](https://auth0.com/docs/api/management/guides/users/update-root-attributes-users) ou [par importation en bloc](https://auth0.com/docs/api/management/guides/users/update-root-attributes-users) à l’aide de la Management API

Si vous écrivez un script de connexion pour une [base de données personnalisée](/docs/fr-ca/authenticate/database-connections/custom-db), vous devez retourner les renseignements du profil utilisateur. Une propriété `user_id` unique et immuable est obligatoire pour identifier correctement l’utilisateur (voir [Identifier les utilisateurs de façon unique](/docs/fr-ca/manage-users/user-accounts/identify-users)).

<div id="additional-attributes">
  ## Attributs supplémentaires
</div>

Le profil utilisateur comprend un tableau d’identités. Dans le cas le plus courant (lorsqu’un seul fournisseur est utilisé pour la connexion), le tableau ne contient qu’un seul élément. Si l’utilisateur possède plusieurs comptes liés, le tableau contient un élément pour chaque compte associé. Consultez [Liaison de comptes d’utilisateur](/docs/fr-ca/manage-users/user-accounts/user-account-linking) pour en savoir plus.

Le tableau `identities` contient les attributs suivants :

* `connection` : le nom de la connexion.
* `isSocial` : indique si le fournisseur est un fournisseur Social.
* `provider` : le fournisseur de la connexion.
* `user_id` : l’identifiant unique de l’utilisateur pour cette connexion.

Auth0 transmet à votre application toutes les autres propriétés fournies par le fournisseur d’identité, même si elles ne sont pas mappées aux attributs standard énumérés ci-dessus.
