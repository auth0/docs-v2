Les profils utilisateur Auth0 contiennent deux catégories de métadonnées :

* `user_metadata` stocke des informations utilisateur, comme les préférences, qui n’ont pas d’incidence sur le fonctionnement de base d’un utilisateur.

  Ces données **peuvent** être modifiées par les utilisateurs connectés si vous créez un formulaire à l’aide de la Management API et **ne doivent pas** être utilisées comme stockage de données sécurisé.

* `app_metadata` stocke des informations d’accès, comme les permissions, le forfait Auth0 et des ID externes qui peuvent avoir une incidence sur l’accès de l’utilisateur aux fonctionnalités.

  Ces données **ne peuvent pas** être modifiées par les utilisateurs, et il existe des restrictions quant à ce qui peut être stocké dans ce champ.

Les métadonnées peuvent être modifiées dans le cadre du flux de connexion d’un utilisateur. Vous pouvez utiliser les métadonnées pour :

* Stocker des données propres à l’application dans le profil utilisateur.
* Indiquer si certaines opérations ont été effectuées ou non pour un utilisateur.
* Mettre en cache dans le profil utilisateur les résultats d’opérations coûteuses afin de pouvoir les réutiliser lors de connexions ultérieures.
* Stocker des informations qui ne proviennent pas d’un <Tooltip tip="Fournisseur d’identité (IdP) : service qui stocke et gère des identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=identity+provider">fournisseur d’identité</Tooltip> ou qui remplacent celles fournies par un fournisseur d’identité.
* Stocker des informations que vous souhaitez utiliser pour [personnaliser les courriels Auth0](/docs/fr-ca/customize/email/email-templates). Par exemple, utilisez `user_metadata.lang` si vous voulez que l’utilisateur puisse modifier la valeur du champ, puis servez-vous de cette information pour personnaliser la langue d’un courriel.

Les [applications Auth0](/docs/fr-ca/get-started/applications) (ou *clients*, dans la terminologie OIDC OAuth0) disposent également de leurs propres [`client_metadata`](/docs/fr-ca/get-started/applications/configure-application-metadata), distinctes des métadonnées du profil utilisateur.
