---
title: Identifier les utilisateurs
description: Découvrez comment identifier vos utilisateurs de façon unique.
---

Il existe plusieurs options pour identifier vos utilisateurs de façon unique :

1. À l’aide de la propriété `user_id`. Son unicité est garantie (au sein d’un tenant) pour chaque utilisateur (par exemple `{identity provider id}|{unique id in the provider}` ou `facebook|1234567890`). Un utilisateur peut avoir la même propriété `user_id` dans plusieurs tenants Auth0, mais cette cohérence n’est pas garantie.

   Pour les connexions de base de données [standard](/docs/fr-ca/authenticate/database-connections/auth0-user-store) et [personnalisées](/docs/fr-ca/authenticate/database-connections/custom-db), évitez de créer des `user_id` en double dans un tenant pour différentes connexions de base de données. Si vous prévoyez des collisions possibles entre des IDs provenant de différentes connexions, utilisez un préfixe qui identifie la connexion.

2. À l’aide d’une clé naturelle, comme la propriété `email`. Nous vous recommandons d’utiliser un IdP qui exige que les utilisateurs vérifient leur adresse courriel, puis d’[activer la vérification du courriel dans Auth0](/docs/fr-ca/manage-users/user-accounts/verify-emails).

   Certains IdP, comme Azure AD, ne peuvent pas garantir que les adresses courriel sont vérifiées. Dans ce cas, vous pouvez [configurer la vérification du courriel pour Azure AD et ADFS](/docs/fr-ca/authenticate/identity-providers/enterprise-identity-providers/azuread-adfs-email-verification) ou [mettre en œuvre la vérification externe des utilisateurs avec Auth0 Forms](https://auth0.com/blog/external-user-verification-with-forms/).
