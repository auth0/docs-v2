En plus d’utiliser le Dashboard, vous pouvez récupérer, créer, mettre à jour ou supprimer des utilisateurs à l’aide de la [Management API](https://auth0.com/docs/api/management/v2#!/Users/get_users). Pour envoyer une requête directement à la <Tooltip tip="Management API : un produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>, générez d’abord le <Tooltip tip="Management API : un produit qui permet aux clients d’effectuer des tâches administratives." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=access+token">jeton d’accès</Tooltip> approprié. Pour en savoir plus, consultez [Jetons d’accès pour la Management API](/docs/fr-ca/secure/tokens/access-tokens/management-api-access-tokens). Vous pouvez aussi utiliser un SDK pour implémenter la fonctionnalité nécessaire afin d’effectuer des requêtes à la Management API depuis votre application. Pour obtenir la liste des SDKs offerts, consultez [la section SDKs de notre matrice de soutien](/docs/fr-ca/troubleshoot/customer-support/product-support-matrix).

Pour savoir comment gérer l’accès à <Tooltip tip="Auth0 Dashboard : le principal produit d’Auth0 pour configurer vos services." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Auth0+Dashboard">Auth0 Dashboard</Tooltip> pour les membres de votre équipe, consultez [Manage Dashboard Access](/docs/fr-ca/get-started/manage-dashboard-access).

<div id="permissions">
  ## Autorisations
</div>

Utilisez les autorisations suivantes pour obtenir un jeton d’accès pour les applications machine à machine. Pour en savoir plus, consultez [Register Machine-to-Machine Applications.](/docs/fr-ca/get-started/auth0-overview/create-applications/machine-to-machine-apps)

| Autorisations               | Descriptions                                                                                                                                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `read:users`                | Les applications peuvent rechercher et récupérer tous les dossiers d’utilisateurs stockés dans un tenant Auth0. Cela comprend la lecture au moyen des points de terminaison `/api/v2/users`, `/api/v2/users-by-email` et `/api/v2/jobs/users-export`.        |
| `create:users`              | Les applications peuvent créer des utilisateurs dans n’importe quelle connexion de base de données ou connexion Passwordless d’un tenant Auth0. Cela comprend la création au moyen des points de terminaison `/api/v2/users` et `/api/v2/jobs/users-import`. |
| `update:users`              | Les applications peuvent mettre à jour n’importe quel utilisateur stocké dans un tenant Auth0. Cela comprend les mises à jour au moyen du point de terminaison `/api/v2/users`.                                                                              |
| `update:users_app_metadata` | Les applications peuvent uniquement mettre à jour l’attribut `user.app_metadata` pour n’importe quel utilisateur stocké dans un tenant Auth0. Cela comprend les mises à jour au moyen du point de terminaison `/api/v2/users`.                               |
| `delete:users`              | Les applications peuvent supprimer n’importe quel utilisateur stocké dans un tenant Auth0. Cela comprend la suppression au moyen du point de terminaison `/api/v2/users`.                                                                                    |

<div id="limitations">
  ## Limitations
</div>

Par défaut, les attributs du profil utilisateur fournis par des <Tooltip tip="Fournisseur d’identité (IdP) : service qui stocke et gère les identités numériques." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=identity+providers">fournisseurs d’identité</Tooltip> autres qu’Auth0 (comme Google, Facebook ou X) ne peuvent pas être modifiés directement, puisqu’ils sont mis à jour par le fournisseur d’identité chaque fois que l’utilisateur ouvre une session. Pour en savoir plus sur les attributs provenant des fournisseurs d’identité, consultez [Configurer la connexion du fournisseur d’identité pour les mises à jour du profil utilisateur](/docs/fr-ca/manage-users/user-accounts/user-profiles/configure-connection-sync-with-auth0).

<div id="edit-user-profile-root-attributes">
  ### Modifier les attributs racine du profil utilisateur
</div>

Pour pouvoir modifier les attributs racine `name`, `nickname`, `given_name`, `family_name` ou `picture` du profil utilisateur normalisé, vous devez [configurer la synchronisation de votre connexion avec Auth0](/docs/fr-ca/manage-users/user-accounts/user-profiles/configure-connection-sync-with-auth0) afin que les attributs utilisateur soient mis à jour par le fournisseur d’identité uniquement lors de la création du profil utilisateur. Ces attributs racine pourront ensuite être modifiés individuellement ou par importations en bloc.

<div id="unable-to-view-passwords">
  ### Impossible d’afficher les mots de passe
</div>

Vous pouvez définir des mots de passe à l’aide des points de terminaison `create` ou `update`, mais, pour des raisons de sécurité, les mots de passe ne peuvent pas être affichés avec les commandes `get` ou `list user`. Le côté droit de l’API Explorer fournit des indications sur les attributs du profil utilisateur qui peuvent être affichés ou modifiés pour une requête donnée.

<div id="endpoints">
  ## Points de terminaison
</div>

| **Type de point de terminaison**                                                       | **Utilisation**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[`/users`](https://auth0.com/docs/api/management/v2/users/get-users)**               | [Obtenir des renseignements sur tous les utilisateurs](https://auth0.com/docs/api/management/v2/users/get-users). Vous pouvez aussi inclure des critères de recherche pour trouver des utilisateurs précis.                                                                                                                                                                                                                                                                                     |
| **[`/user_id`](https://auth0.com/docs/api/management/v2/users/get-users-by-id)**       | [Obtenir des renseignements sur un utilisateur](https://auth0.com/docs/api/management/v2/users/get-users-by-id) en fonction du `user_id`. Le `user_id` est un identifiant interne qui se compose d’un nom de connexion et d’un identifiant unique pour l’utilisateur. Le `user_id` est différent du <Tooltip tip="ID Token : justificatif destiné au client lui-même plutôt que pour accéder à une ressource." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=ID+token">ID token</Tooltip>. |
| **[`/userinfo`](https://auth0.com/docs/api/authentication/reference#get-user-info)**   | Prend le jeton d’accès Auth0 et [renvoie des renseignements du profil utilisateur](https://auth0.com/docs/api/authentication/reference#get-user-info). Inclut les résultats de toute règle ayant modifié le profil utilisateur pendant la transaction d’authentification, mais le profil obtenu ne sera filtré par aucune [portée](/docs/fr-ca/get-started/apis/scopes/api-scopes).                                                                                                                   |
| **[`/tokeninfo`](https://auth0.com/docs/api/authentication/reference#get-token-info)** | Prend le ID token Auth0 et [renvoie des renseignements du profil utilisateur](https://auth0.com/docs/api/authentication/reference#get-token-info). N’inclut pas les résultats des règles qui modifient le profil utilisateur.                                                                                                                                                                                                                                                                   |
