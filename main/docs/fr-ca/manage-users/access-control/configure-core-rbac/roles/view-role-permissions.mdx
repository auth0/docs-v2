Vous pouvez consulter les [permissions](/docs/fr-ca/manage-users/access-control/rbac) ajoutées à un rôle à l’aide du <Tooltip tip="Auth0 Dashboard : le principal produit d’Auth0 pour configurer vos services." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Auth0+Dashboard">Auth0 Dashboard</Tooltip> ou de la <Tooltip tip="Auth0 Dashboard : le principal produit d’Auth0 pour configurer vos services." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=Management+API">Management API</Tooltip>. Les permissions et les rôles attribués sont utilisés avec le jeu de fonctionnalités Authorization Core de l’API.

<div id="prerequisites">
  ## Prérequis
</div>

Pour que le contrôle d’accès basé sur les rôles (RBAC) fonctionne correctement, vous devez l’activer pour votre API à l’aide du Dashboard ou de la Management API. La fonctionnalité Authorization Core est différente de l’Authorization Extension. Pour les comparer, consultez [Authorization Core vs. Authorization Extension](/docs/fr-ca/manage-users/access-control/authorization-core-vs-authorization-extension).

<div id="dashboard">
  ## Dashboard
</div>

1. Accédez à [Dashboard &gt; User Management &gt; Roles](https://manage.auth0.com/#/roles), puis cliquez sur le nom du rôle à consulter.
2. Cliquez sur l’onglet **Permissions**.

Les informations suivantes s’affichent pour chaque permission :

| Colonne     | Description                                                                            |
| ----------- | -------------------------------------------------------------------------------------- |
| Nom         | Nom de la permission tel qu’il figure dans la définition de la permission.             |
| Description | Description de la permission telle qu’elle figure dans la définition de la permission. |
| API         | Nom de l’API à laquelle la permission est associée.                                    |

<div id="management-api">
  ## Management API
</div>

Effectuez une requête `GET` vers le [point de terminaison Get Role Permissions](https://auth0.com/docs/api/management/v2#!/Roles/get_role_permission). Assurez-vous de remplacer les valeurs de l’espace réservé `ROLE_ID` et `MGMT_API_ACCESS_TOKEN` par l’ID de votre rôle et votre <Tooltip tip="Jeton d’accès : identifiant d’autorisation, sous la forme d’une chaîne opaque ou d’un JWT, utilisé pour accéder à une API." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=access+token">jeton d’accès</Tooltip> de la Management API, respectivement.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">Vous utilisez Auth0 CLI ? Si ce n’est pas déjà fait, [configurez et authentifiez votre session CLI](/docs/fr-ca/deploy-monitor/auth0-cli) avant d’exécuter cette commande.</Callout>

  auth0 api get "roles/ROLE_ID/permissions"

  curl --request GET \

  package main

  import (

</AuthCodeGroup>

| Valeur                  | Description                                                                                                          |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `ROLE_ID`               | L’ID du rôle dont vous souhaitez récupérer les permissions.                                                          |
| `MGMT_API_ACCESS_TOKEN` | [Jeton d’accès pour la Management API](https://auth0.com/docs/api/management/v2/tokens) avec la portée `read:roles`. |
