Pour configurer les sessions anonymes, vous pouvez utiliser l’[API de gestion Auth0](/docs/fr-ca/api/management/v2).

<div id="prerequisites">
  ## Prérequis
</div>

Pour utiliser les sessions anonymes :

* Vous devez [avoir un compte Auth0](https://auth0.com/).
* [Enregistrez votre application Auth0](/docs/fr-ca/get-started/auth0-overview/create-applications). Si vous n’avez pas d’application Auth0, consultez les [Quickstarts](https://auth0.com/docs/quickstart/spa/react) Auth0 pour React ou Next.js.
* [Enregistrez une API (serveur de ressources)](/docs/fr-ca/get-started/auth0-overview/set-up-apis).

<div id="auth0-management-api">
  ## API de gestion Auth0
</div>

<div id="configure-anonymous-sessions-in-your-auth0-tenant">
  ### Configurer les sessions anonymes dans votre tenant Auth0
</div>

Pour définir la durée de vie des sessions anonymes, envoyez une requête `PATCH` au point de terminaison [`/api/v2/tenants/settings`](/docs/fr-ca/api/management/v2/tenants/patch-settings) :

```json
{
  "sessions": {
    "anonymous": {
      "lifetime_in_minutes": 1440
    }
  }
}  
```

<div id="enable-anonymous-sessions-in-your-application">
  ### Activer les sessions anonymes dans votre application
</div>

Pour activer les sessions anonymes dans votre application Auth0, envoyez une requête `PATCH` au point de terminaison [`/api/v2/clients/{id}`](/docs/fr-ca/api/management/v2/clients/patch-clients-by-id) :

```json
{
  "anonymous_sessions": {
    "active": true
  }
}
```

<div id="enable-anonymous-access-in-your-api">
  ### Activer l’accès anonyme dans votre API
</div>

Pour activer les sessions anonymes dans votre API, envoyez une requête `PATCH` au point de terminaison [`/api/v2/resource-servers/{id}`](/docs/fr-ca/api/management/v2/resource-servers/patch-resource-servers-by-id) :

```json
{
  "allow_anonymous_access": true,
  "token_lifetime_for_anonymous_access_tokens": 86400,
  "subject_type_authorization": {
    "user":           { "policy": "allow_all" },
    "client":         { "policy": "deny_all" },
    "anonymous_user": { "policy": "require_client_grant" }
  }
}
```

<div id="create-an-api-access-policy-for-anonymous-users">
  ### Créer une politique d’accès à l’API pour les utilisateurs anonymes
</div>

Une fois les sessions anonymes activées dans votre API, envoyez une requête `POST` au point de terminaison [`/api/v2/client-grants`](/docs/fr-ca/api/management/v2/client-grants/post-client-grants) :

```json
{
  "audience": "{{anon_sessions_audience_identifier}}",
  "client_id": "{{anon_sessions_clientid}}",
  "scope": [ "read", "write", "delete" ],
  "subject_type": "anonymous_user"
}
```

<div id="create-an-anonymous-session">
  ## Créer une session anonyme
</div>

Une fois les sessions anonymes configurées dans votre tenant, votre application et votre API, vous pouvez créer une session anonyme en envoyant une requête `POST` au point de terminaison `/anonymous/token` :

```json
{
  "client_id": "YOUR_CLIENT_ID",
  "audience": "YOUR_AUDIENCE",
  "scope": "anon"
}
```

La réponse contient un `session_token` et un `access_token` :

```json
{
  "session_token": "eyJhbGciOiJkaXIiLCJlbmMiOiJBMjU2R0NNIn0...",
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 86400
}
```
