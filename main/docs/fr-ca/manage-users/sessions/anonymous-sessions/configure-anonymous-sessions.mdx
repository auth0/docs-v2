Pour configurer les Anonymous Sessions, vous pouvez utiliser le [Auth0 Dashboard](/docs/fr-ca/get-started/auth0-overview/dashboard) ou la [Management API](/docs/fr-ca/api/management/v2).

## Prérequis {#prerequisites}

Pour utiliser les sessions anonymes :

* Vous devez [avoir un compte Auth0](https://auth0.com/).
* [Enregistrez votre application Auth0](/docs/fr-ca/get-started/auth0-overview/create-applications). Si vous n’avez pas d’application Auth0, consultez les [Quickstarts](https://auth0.com/docs/quickstart/spa/react) Auth0 pour React ou Next.js.
* [Enregistrez une API (serveur de ressources)](/docs/fr-ca/get-started/auth0-overview/set-up-apis).

## Configurer les sessions anonymes {#configure-anonymous-sessions}

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à [**Dashboard &gt; Tenant Settings &gt; Advanced**](https://manage.auth0.com/#/tenant/advanced), puis faites défiler jusqu&#39;aux paramètres de session.

       ![La page des paramètres du locataire dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions.png)

    2. Saisissez une valeur en minutes pour **Anonymous Session Lifetime**.

    3. Activez ou désactivez l&#39;interrupteur **Anonymous Session Cookie** pour déterminer si les requêtes de session anonyme renvoient le témoin `auth0_anon`.
  </Tab>

  <Tab title="Management API">
    Pour configurer la durée de vie de la session anonyme et le comportement du témoin, envoyez une requête `PATCH` au terminal [`/api/v2/tenants/settings`](/docs/fr-ca/api/management/v2/tenants/patch-settings) :

    ```json
    {
      "sessions": {
        "anonymous": {
          "lifetime_in_minutes": 144000,
          "activate_cookie": true
        }
      }
    }
    ```

    * `lifetime_in_minutes` définit la durée de validité d&#39;une session.
    * `activate_cookie` détermine si le témoin `auth0_anon` est émis dans les flux anonymes. Réglez ce paramètre à `false` si vous prévoyez plutôt utiliser le [mécanisme de billet de transfert sans témoin](/docs/fr-ca/manage-users/sessions/anonymous-sessions#transfer-a-session-through-a-transfer-ticket).
  </Tab>
</Tabs>

## Activer les sessions anonymes dans votre application {#enable-anonymous-sessions-in-your-application}

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à [**Dashboard &gt; Applications &gt; Applications**](https://manage.auth0.com/#/applications), puis sélectionnez l&#39;application que vous souhaitez configurer.

    2. Faites défiler jusqu&#39;aux paramètres **Anonymous Sessions**.

       ![La page des paramètres des applications dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions_application.png)

    3. Activez l&#39;interrupteur **Allow Anonymous Sessions**.
  </Tab>

  <Tab title="Management API">
    Pour activer les sessions anonymes dans votre application Auth0, envoyez une requête `PATCH` au terminal [`/api/v2/clients/{id}`](/docs/fr-ca/api/management/v2/clients/patch-clients-by-id) :

    ```json
    {
      "anonymous_sessions": {
        "active": true
      }
    }
    ```
  </Tab>
</Tabs>

## Activer l&#39;accès anonyme dans votre API {#enable-anonymous-access-in-your-api}

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à [**Dashboard &gt; Applications &gt; APIs**](https://manage.auth0.com/#/apis), puis sélectionnez l&#39;API que vous souhaitez configurer.

    2. Dans la section **Access token expiration**, définissez la valeur **Anonymous Access Token Lifetime** en secondes. Le minimum est d&#39;une journée (86400 secondes) et le maximum, de 30 jours (2592000 secondes).

       ![La page des paramètres de l'API dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions_api.png)

    3. Sous **Application Access Policy**, réglez la politique **Anonymous Access** à **Per-app authorization** afin d&#39;activer les sessions anonymes qui utilisent ce public pour leurs jetons d&#39;accès.

       ![La page des paramètres de la politique d'accès des applications dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions_api_policy.png)
  </Tab>

  <Tab title="Management API">
    Pour activer les sessions anonymes dans votre API, envoyez une requête `PATCH` au terminal [`/api/v2/resource-servers/{id}`](/docs/fr-ca/api/management/v2/resource-servers/patch-resource-servers-by-id) :

    ```json
    {
      "token_lifetime_for_anonymous_access_tokens": 86400,
      "subject_type_authorization": {
        "user":           { "policy": "allow_all" },
        "client":         { "policy": "deny_all" },
        "anonymous_user": { "policy": "require_client_grant" }
      }
    }
    ```

    * `token_lifetime_for_anonymous_access_tokens` définit le délai d&#39;expiration, en secondes, des jetons d&#39;accès que cette API émet dans un contexte de session anonyme.
    * `subject_type_authorization.anonymous_user` détermine si certaines applications peuvent utiliser cette API dans des sessions anonymes (selon les politiques) ou si cette API interdit totalement l&#39;émission de jetons d&#39;accès anonymes.
  </Tab>
</Tabs>

## Créer une politique d&#39;accès à l&#39;API pour les utilisateurs anonymes {#create-an-api-access-policy-for-anonymous-users}

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Accédez à [**Dashboard &gt; Applications &gt; APIs**](https://manage.auth0.com/#/apis), puis sélectionnez l&#39;API à configurer.

    2. Sélectionnez l&#39;onglet **Application Access**.

    3. Pour chaque application à laquelle cette API doit émettre des jetons d&#39;accès dans un contexte anonyme, sélectionnez **Edit**.

       ![La page des paramètres d'accès des applications à l'API dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions_api_application_access.png)

    4. Sélectionnez **Anonymous Access**, puis cliquez sur **Configure** pour définir les permissions à accorder aux utilisateurs anonymes qui utilisent cette application.

       ![La page des paramètres des applications dans le Auth0 Dashboard](/docs/images/sessions/anonymous_sessions/anonymous_sessions_api_anonymous_access_drawer.png)

    5. Sélectionnez **Save**.
  </Tab>

  <Tab title="Management API">
    Une fois les sessions anonymes activées dans votre API, envoyez une requête `POST` au terminal [`/api/v2/client-grants`](/docs/fr-ca/api/management/v2/client-grants/post-client-grants) :

    ```json
    {
      "audience": "YOUR_AUDIENCE",
      "client_id": "YOUR_CLIENT_ID",
      "scope": [ "read", "write", "delete" ],
      "subject_type": "anonymous_user"
    }
    ```
  </Tab>
</Tabs>

## Créer une session anonyme {#create-an-anonymous-session}

Une fois les sessions anonymes configurées dans votre tenant, votre application et votre API, vous pouvez créer une session anonyme en envoyant une requête `POST` au point de terminaison `/anonymous/token` :

```json
{
  "client_id": "YOUR_CLIENT_ID",
  "audience": "YOUR_AUDIENCE",
  "scope": "anon"
}
```

La réponse contient un `session_token` et un `access_token` :

```json
{
  "session_token": "eyJhbGciOiJkaXIiLCJlbmMiOiJBMjU2R0NNIn0...",
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 86400
}
```

## Configurer des demandes personnalisées {#configure-custom-claims}

Vous pouvez configurer des demandes personnalisées afin d&#39;associer les métadonnées de session anonyme directement aux jetons d&#39;accès émis pour un public donné.

Cela s&#39;avère utile, car aucune Action [`post-login`](/docs/fr-ca/customize/actions/explore-triggers/post-login) ne s&#39;exécute avec les sessions anonymes : `api.accessToken.setCustomClaim()` n&#39;est donc pas disponible pour enrichir les jetons d&#39;accès anonymes, comme c&#39;est le cas pour les jetons authentifiés. Pour en savoir plus, lisez [Configurer des demandes personnalisées pour Anonymous Sessions](/docs/fr-ca/manage-users/sessions/anonymous-sessions/configure-custom-claims-for-anonymous-sessions).
