title: Vue d’ensemble des sessions et des témoins
sidebarTitle: Vue d’ensemble
description: Les sessions et les témoins stockent temporairement des données sur vos utilisateurs, que vous pouvez utiliser pour gérer leur statut d’authentification. 
mode: wide
---

* Une session est un ensemble d’interactions entre un utilisateur et une application pendant une période donnée. Une même session peut comprendre plusieurs activités (comme des affichages de pages, des événements, des interactions sociales et des transactions de commerce électronique) et stocker temporairement ces informations tant que l’utilisateur est connecté.

  Dans une mise en œuvre standard de l’en-tête Set-Cookie, une session prend fin lorsqu’un utilisateur quitte un site Web ou ferme son navigateur. Pour éviter que les utilisateurs aient à se connecter chaque fois, les applications peuvent prolonger les sessions en définissant une durée de vie maximale pour le <Tooltip tip="Cookie de session : entité qui, lorsqu’elle est présente, permet de considérer l’utilisateur comme authentifié." cta="Voir le glossaire" href="/docs/fr-ca/glossary?term=session+cookie">témoin de session</Tooltip>. Les sessions prennent fin lorsqu’un utilisateur se déconnecte ou que la limite de durée de vie de la session est atteinte.

* Les témoins sont des chaînes de données qu’un serveur Web envoie au navigateur. Lorsque le navigateur envoie par la suite une requête à ce serveur Web, il lui renvoie cette même chaîne avec la requête.

Les sites Web utilisent généralement les témoins pour reconnaître les utilisateurs lorsqu’ils passent d’une page à l’autre, afin de ne pas leur demander de se reconnecter chaque fois. Les sites Web utilisent aussi les témoins pour mémoriser les informations saisies par les utilisateurs. Par exemple, les sites de commerce électronique s’en servent pour mémoriser les articles ajoutés au panier d’achat.
