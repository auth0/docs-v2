---

Organizations permet aux clients interentreprises (B2B) de mieux gérer leurs partenaires et leurs clients, ainsi que de personnaliser la façon dont les utilisateurs finaux accèdent à leurs applications et à leurs API. Les clients Auth0 peuvent utiliser Organizations pour :

* Représenter leurs clients d’affaires et leurs partenaires dans Auth0 et gérer leurs membres.
* Configurer des flux de connexion fédérés aux couleurs de chaque entreprise.
* Offrir un accès pour la communication entre machines à leurs clients d’affaires et à leurs partenaires pour consommer leurs API B2B.
* Intégrer des fonctions d’administration à leurs produits à l’aide des API Organizations, afin que ces entreprises puissent gérer leurs propres organisations.
