Vous pouvez récupérer des profils utilisateur précis à l’aide de l’adresse courriel ou de l’ID utilisateur dans le Auth0 Dashboard ou au moyen de la Management API.

<Tabs>
  <Tab title="Auth0 Dashboard">
    Pour trouver un utilisateur précis à l’aide de son adresse courriel ou de son ID utilisateur dans le Auth0 Dashboard :

    1. Accédez à [Dashboard &gt; User Management &gt; Users](https://manage.auth0.com/#/users).

       ![La page Users dans le Auth0 Dashboard](/docs/images/user-management/users.png)

    2. Dans le menu déroulant **Search by**, sélectionnez **User** pour rechercher par ID utilisateur ou **Email** pour rechercher par adresse courriel.

    3. Dans le champ de recherche, entrez l’ID utilisateur ou l’adresse courriel à rechercher.

    4. Dans les résultats, ouvrez le menu **...** de l’utilisateur et sélectionnez **View details** pour accéder à son profil complet.
  </Tab>

  <Tab title="Management API">
    La Management API propose deux endpoints permettant de récupérer des utilisateurs précis :

    * Le [endpoint Get a user](/docs/fr-ca/api/management/v2/users/get-users-by-id) (`GET /users/{id}`) récupère les détails d’un utilisateur précis à l’aide de son ID utilisateur.

    * Le [endpoint Search Users by Email](/docs/fr-ca/api/management/v2/users-by-email/get-users-by-email) (`GET /users-by-email`) récupère les détails des utilisateurs correspondant à l’adresse courriel fournie.

    Ces points de terminaison de la Management API sont immédiatement cohérents : les résultats reflètent donc toutes les opérations d&#39;écriture réussies, y compris celles effectuées peu avant la requête. Vous pouvez ainsi utiliser ces points de terminaison pour les recherches d&#39;utilisateurs pendant l&#39;authentification ou la liaison de comptes.

    Pour obtenir un utilisateur précis à partir de son ID utilisateur, appelez le [terminal Get a User](/docs/fr-ca/api/management/v2/users/get-users-by-id) (`GET /users/{id}`) et transmettez l’ID utilisateur encodé en URL dans le [paramètre de chemin `id`](/docs/fr-ca/api/management/v2/users/get-users-by-id#parameter-id) :

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">Vous utilisez le Auth0 CLI? Si ce n’est pas déjà fait, [configurez et authentifiez votre session CLI](/docs/fr-ca/deploy-monitor/auth0-cli) avant d’exécuter cette commande.</Callout>

    <AuthCodeGroup>
      ```bash Auth0 CLI
      auth0 api get "users/%7BuserId%7D"
      ```

      ```bash curl
      curl --request GET \
        --url 'https://{yourDomain}/api/v2/users/%7BuserId%7D' \
        --header 'authorization: Bearer {yourMgmtApiAccessToken}'
      ```

      ```csharp C#
      var client = new RestClient("https://{yourDomain}/api/v2/users/%7BuserId%7D");
      var request = new RestRequest(Method.GET);
      request.AddHeader("authorization", "Bearer {yourMgmtApiAccessToken}");
      IRestResponse response = client.Execute(request);
      ```

      ```go Go
      package main

      import (
      	"fmt"
      	"net/http"
      	"io/ioutil"
      )

      func main() {
      	url := "https://{yourDomain}/api/v2/users/%7BuserId%7D"
      	req, _ := http.NewRequest("GET", url, nil)
      	req.Header.Add("authorization", "Bearer {yourMgmtApiAccessToken}")

      	res, _ := http.DefaultClient.Do(req)
      	defer res.Body.Close()
      	body, _ := ioutil.ReadAll(res.Body)

      	fmt.Println(res)
      	fmt.Println(string(body))
      }
      ```

      ```java Java
      HttpResponse<String> response = Unirest.get("https://{yourDomain}/api/v2/users/%7BuserId%7D")
        .header("authorization", "Bearer {yourMgmtApiAccessToken}")
        .asString();
      ```

      ```javascript Node.JS
      var axios = require("axios").default;

      var options = {
        method: 'GET',
        url: 'https://{yourDomain}/api/v2/users/%7BuserId%7D',
        headers: {authorization: 'Bearer {yourMgmtApiAccessToken}'}
      };

      axios.request(options).then(function (response) {
        console.log(response.data);
      }).catch(function (error) {
        console.error(error);
      });
      ```

      ```php PHP
      $curl = curl_init();

      curl_setopt_array($curl, [
        CURLOPT_URL => "https://{yourDomain}/api/v2/users/%7BuserId%7D",
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_ENCODING => "",
        CURLOPT_MAXREDIRS => 10,
        CURLOPT_TIMEOUT => 30,
        CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
        CURLOPT_CUSTOMREQUEST => "GET",
        CURLOPT_HTTPHEADER => [
          "authorization: Bearer {yourMgmtApiAccessToken}"
        ],
      ]);

      $response = curl_exec($curl);
      $err = curl_error($curl);

      curl_close($curl);

      if ($err) {
        echo "curl Error #:" . $err;
      } else {
        echo $response;
      }
      ```

      ```python Python
      import http.client

      conn = http.client.HTTPSConnection("")
      headers = { 'authorization': "Bearer {yourMgmtApiAccessToken}" }
      conn.request("GET", "/{yourDomain}/api/v2/users/%7BuserId%7D", headers=headers)

      res = conn.getresponse()
      data = res.read()

      print(data.decode("utf-8"))
      ```

      ```ruby Ruby
      require 'uri'
      require 'net/http'
      require 'openssl'

      url = URI("https://{yourDomain}/api/v2/users/%7BuserId%7D")

      http = Net::HTTP.new(url.host, url.port)
      http.use_ssl = true
      http.verify_mode = OpenSSL::SSL::VERIFY_PEER

      request = Net::HTTP::Get.new(url)
      request["authorization"] = 'Bearer {yourMgmtApiAccessToken}'

      response = http.request(request)
      puts response.read_body
      ```

    Pour obtenir un utilisateur précis à partir de son adresse courriel, envoyez une requête à l’[endpoint Search Users by Email](/docs/fr-ca/api/management/v2/users-by-email/get-users-by-email) (`GET /users-by-email`) et transmettez l’adresse courriel dans le [query parameter `email`](/docs/fr-ca/api/management/v2/users-by-email/get-users-by-email#parameter-email) :

      auth0 api get "users-by-email" \
