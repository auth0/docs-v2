---
title: Vue d’ensemble du catalogue des Events
sidebarTitle: Vue d’ensemble
description: Les Events offrent une méthode fondée sur une API pour synchroniser, corréler ou orchestrer les changements qui surviennent dans Auth0 ou chez des fournisseurs d’identité tiers, puis les acheminer vers des applications externes ou des services tiers.
---

Les Events sont des notifications en temps réel concernant des actions précises — d’abord des changements touchant un utilisateur et les organisations, puis éventuellement d’autres — qui se sont produits dans votre tenant Auth0. Vous pouvez créer des flux d’événements qui surveillent ces Events afin d’orchestrer des changements asynchrones (c.-à-d. des changements apportés à une entité ou à un flux une fois ceux-ci terminés) dans Auth0 et de les transmettre à l’une des nombreuses destinations pour traitement externe. Les Events prennent en charge divers cas d’utilisation, notamment :

* Envoyer des courriels aux nouveaux clients pour leur souhaiter la bienvenue ou leur demander de vérifier leur adresse courriel.
* Surveiller les changements du cycle de vie des utilisateurs afin de mettre à jour les systèmes CRM (gestion de la relation client) ou de facturation.

<div id="event-object-schema">
  ## Schéma de l’objet Event
</div>

Les Events sont publiés selon un schéma conforme à la [spécification CloudEvents](https://cloudevents.io/) :

| Paramètre   | Type          | Obligatoire | Description                                                                               |
| ----------- | ------------- | ----------- | ----------------------------------------------------------------------------------------- |
| id          | string        | Oui         | Identifie l’événement.                                                                    |
| source      | URI-reference | Oui         | Identifie le tenant à l’origine de l’événement, y compris son environnement.              |
| specversion | string        | Oui         | Version de la spécification CloudEvents utilisée par l’événement.                         |
| type        | string        | Oui         | Type d’événement.                                                                         |
| time        | timestamp     | Oui         | Horodatage de l’événement.                                                                |
| dataschema  | URI           | Oui         | Identifie le schéma auquel les données sont conformes.                                    |
| data        | object        | Oui         | Renseignements supplémentaires sur l’événement. Ce champ varie selon le type d’événement. |

```json lines expandable
{
  "id": "evt_<unique-id>",
  "source": "urn:auth0:<your-tenant>:users",
  "specversion": "1.0",
  "type": "com.auth0.user.<event-type>",
  "time": "2025-01-29T14:36:25.794Z",
  "dataschema": "https://<your-tenant>.auth0.com/api/v2/schemas/user.<event-type>",
  "data": {
    "object": {
      "user_id": "<user-id>",
      "email": "<email>",
      "email_verified": <true/false>,
      "family_name": "<family-name>",
      "given_name": "<given-name>",
      "name": "<full-name>",
      "nickname": "<nickname>",
      "phone_number": "<phone-number>",
      "phone_verified": <true/false>,
      "user_metadata": {
        "hobby": "<user-hobby>"
      },
      "app_metadata": {
        "external_user_id": "<external-id>"
      },
      "identities": [
        {
          "connection": "<connection-name>",
          "user_id": "<identity-user-id>",
          "provider": "<identity-provider>",
          "isSocial": <true/false>
        }
      ],
      "created_at": "<user-created-time>",
      "updated_at": "<user-updated-time>",
      "picture": "<profile-picture-url>"
    }
  }
}
```
