    <Card title="User Profiles" icon="circle-user" href="/docs/manage-users/user-accounts">
    To access any of the applications in your tenant, each user must have a profile in the tenant. User profiles are stored in Auth0's hosted cloud database and contain normalized user information sourced from the IdPs for your connections.

    Using the Auth0 Dashboard or Management API, you can create users, view and modify user profiles and metadata, import and export users, link users, and more.
    </Card>

    <Card title="Organizations" icon="users-rectangle" href="/docs/manage-users/organizations">
    Organizations support business-to-business (B2B) implementations that have applications that end-users access.

    You can configure branded, federated login flows for each business, customize the ways that end-users access their applications and APIs, and build self-serve administration capabilities with the Organizations API.
    </Card>

    <Card title="Role-Based Access Control" icon="user-lock" href="/docs/manage-users/access-control">
    Role-based access control (RBAC) is an authorization strategy to assign permissions to users based on defined roles in an organization. You can use it to control users' access to applications and information in a way that is less prone to error than assigning permissions to users individually.
    </Card>

    <Card title="Sessions and Cookies" icon="cookie" href="/docs/manage-users/sessions">
    Sessions define groups of interactions (such as page views, events, social interactions, and e-commerce transactions) between a user and an application that take place within a given timeframe. Cookies are strings of data that a web server sends to the browser. You can use sessions and cookies to track and persist user state, like authentication status.
    </Card>
