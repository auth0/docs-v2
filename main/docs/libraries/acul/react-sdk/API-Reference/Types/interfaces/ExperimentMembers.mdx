---
title: "ExperimentMembers"
---

Interface describing the active [Experiment Center](/docs/customize/experiment-center) experiment assigned to the current screen.

```ts Example
export interface ExperimentMembers {
  experimentId: string;
  variationId: string;
  variationName: string | null;
  variationDescription: string | null;
  config: { [key: string]: unknown };
  isControl: boolean;
}
```

## Properties

<ParamField body='config' type='Record'>

Resolved variation configuration keyed by config name. Each entry arrives wrapped as `{ value: <resolved value> }`; read it via `config['<key>']?.value`. Values are experiment-defined (`unknown`), so narrow before use. Always a non-null object — normalized to `{}` when the server omits or nulls the config.

</ParamField>

<ParamField body='experimentId' type='string'>

Unique identifier of the active experiment.

</ParamField>

<ParamField body='isControl' type='boolean'>

Whether the assigned variation is the control variation.

</ParamField>

<ParamField body='variationDescription' type='string'>

Human-readable description of the assigned variation. `null` for some variations.

</ParamField>

<ParamField body='variationId' type='string'>

Unique identifier of the assigned variation.

</ParamField>

<ParamField body='variationName' type='string'>

Human-readable name of the assigned variation. `null` for some variations.

</ParamField>
