---
title: "メタデータを取得"
description: "Auth0 テナントの SAML 2.0 メタデータを返します。"
---

## エンドポイント {#endpoint}

`GET /samlp/metadata/{clientId}`

このエンドポイントは、SAML 2.0 メタデータを返します。

### 詳細 {#learn-more}

* [SAML](https://auth0.com/docs/authenticate/protocols/saml/saml-configuration)

## パスパラメータ {#path-parameters}

<ParamField path="clientId" type="string" required>
  アプリケーションの client&#95;id。
</ParamField>

## レスポンスメッセージ {#response-messages}

| ステータス | 説明                    |
| ----- | --------------------- |
| 200   | SAML メタデータの取得に成功しました。 |
