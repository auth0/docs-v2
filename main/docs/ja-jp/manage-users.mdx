<Columns cols={2}>
  <Card title="ユーザープロファイル" icon="circle-user" href="/docs/ja-jp/manage-users/user-accounts">
    テナント内のアプリケーションにアクセスするには、各ユーザーがそのテナントにプロファイルを持っている必要があります。ユーザープロファイルはAuth0がホストするクラウドデータベースに保存され、接続のIdPから取得された正規化済みのユーザー情報が含まれます。

    Auth0 DashboardまたはManagement APIを使用すると、ユーザーの作成、ユーザープロファイルとメタデータの表示・変更、ユーザーのインポート・エクスポート、ユーザーのリンクなどを行えます。
  </Card>

  <Card title="Organizations" icon="users-rectangle" href="/docs/ja-jp/manage-users/organizations">
    Organizationsは、エンドユーザーがアクセスするアプリケーションを提供する企業間 (B2B) の実装をサポートします。

    企業ごとにブランディングされたフェデレーションログインフローを構成したり、エンドユーザーがアプリケーションやAPIにアクセスする方法をカスタマイズしたり、Organizations APIを使ってセルフサービス型の管理機能を構築したりできます。
  </Card>

  <Card title="Role-Based Access Control" icon="user-lock" href="/docs/ja-jp/manage-users/access-control">
    Role-based Access Control (RBAC) は、組織内で定義されたロールに基づいてユーザーに権限を割り当てる認可方式です。ユーザーごとに個別に権限を割り当てるよりもミスが起こりにくい方法で、アプリケーションや情報へのユーザーのアクセスを制御できます。
  </Card>

  <Card title="セッションとクッキー" icon="cookie" href="/docs/ja-jp/manage-users/sessions">
    セッションは、一定の時間内に発生するユーザーとアプリケーション間の一連のやり取り (ページビュー、イベント、ソーシャルインタラクション、eコマース取引など) を定義するものです。クッキーは、Webサーバーがブラウザーに送信するデータ文字列です。セッションとクッキーを使用すると、認証状態などのユーザーの状態を追跡・保持できます。
  </Card>
</Columns>
