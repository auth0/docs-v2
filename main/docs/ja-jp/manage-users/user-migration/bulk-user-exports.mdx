Auth0 からユーザーデータを一括エクスポートできます。エクスポート可能なユーザープロファイルのフィールド一覧については、[User Profile Structure](/docs/ja-jp/manage-users/user-accounts/user-profiles/user-profile-structure)をご覧ください。

<div id="supported-file-formats">
  ## サポート対象のファイル形式
</div>

JSON互換形式およびCSV形式でのユーザーデータのエクスポートをサポートしています。

* エクスポートファイルのサイズが大きいため、JSON互換のエクスポートファイルは[NDJSON形式](https://github.com/ndjson/ndjson-spec)です。

* CSVエクスポートファイルでは、CSVインジェクションを防ぐため、OWASP標準に準拠してStringデータ型をエスケープします。

  * 二重引用符 (&quot;) の前には、二重引用符が追加されます。
  * 各文字列の先頭には、一重引用符 (&#39;) が追加されます。
  * 各文字列は二重引用符で囲まれます。

  これは、Auth0が生成するISO 8601形式の日付には適用されません。

<div id="1-submit-export-users-job">
  ## 1. ユーザーエクスポート ジョブ を送信する
</div>

<Tabs>
  <Tab title="Auth0 Dashboard">
    Auth0 Dashboard を使用してユーザーデータをエクスポートするには:

    1. [**Dashboard &gt; User Management &gt; Users**](https://manage.auth0.com/#/users) に移動します。

    2. ページ右上の **Import/Export Users** を選択して、**Import/Export Users** ページに移動します。

    3. **Export Users** を選択して、**Export Users** ページに移動します。

       <Frame>![](/docs/images/cdy7uua7fh8z/2koXwmAu99VfxJIq49yGGq/394be27431b66cfd09866ef91b0e0cd0/exportusers.png)</Frame>

    4. **Export Settings** セクションで:

       * **Connection** のドロップダウンメニューを開き、ユーザーデータのエクスポート元となるデータベース接続を選択します。

       * **Export Format** のドロップダウンメニューを開き、データの形式 (JSON または CSV) を選択します。

    5. **Export Fields** セクションで、エクスポートに含めるフィールドを選択します:

       * **Include default fields** をオンにすると、[Auth0 正規化ユーザープロファイルスキーマ](/docs/ja-jp/manage-users/user-accounts/user-profiles/normalized-user-profiles)のフィールドが追加されます。

       * **Add Fields** を選択し、**User Attribute** と **Field Name** を入力して特定のフィールドを追加します。

    6. 必要に応じて、**Export Fields** セクションで **Export as Sample** をオンにすると、エクスポート対象を10人のユーザーに制限できます。これは、エクスポートファイルの構造を検証する際に役立ちます。

    7. ジョブを送信するには、**Export Users** を選択します。
  </Tab>

  <Tab title="Management API">
    Management API を使用してユーザーデータをエクスポートするには、[ユーザーエクスポートジョブ作成エンドポイント](/docs/ja-jp/api/management/v2/jobs/post-users-exports) (`POST /jobs/users-exports`) を呼び出します。リクエスト本文のパラメータとレスポンススキーマの詳細については、エンドポイントのドキュメントを参照してください。

    `connection_id` を省略した場合、このエンドポイントはテナント内のすべての接続に属するユーザーのデータをエクスポートします。

    <Tip>
      [Auth0 Dashboardでデータベース接続のIDを確認する](/docs/ja-jp/authenticate/identity-providers/locate-the-connection-id)か、Management APIの[すべての接続を取得するエンドポイント](/docs/ja-jp/api/management/v2/connections/get-connections)を使用して取得できます。
    </Tip>

    以下の例を使用するには、プレースホルダー変数を実際の値に置き換えてください。

<div id="2-check-job-status-and-download-the-export">
  ## 2. ジョブのステータスを確認してエクスポートをダウンロードする
</div>

<Tabs>
  <Tab title="Auth0 Dashboard">
    ジョブのステータスを確認するには：

    1. [**Auth0 Dashboard &gt; User Management &gt; Users**](https://manage.auth0.com/#/users)に移動します。

    2. ページ右上の**Import/Export Users**を選択して、**Import/Export Users**ページに移動します。1つ以上のジョブを開始すると、このページに送信済みのジョブが一覧表示されます。

    3. 各ジョブの横で、次の操作を選択できます：

       * **Check Status**：ジョブの進行状況を確認します。

       * **Download export**：結果を取得します。

       * **More info**：エラーまたはジョブのメタデータを確認します。
  </Tab>

  <Tab title="Management API">
    ジョブのステータスを確認するには、ジョブのIDを指定して[Get a job endpoint](/docs/ja-jp/api/management/v2/jobs/get-jobs-by-id) (`GET /jobs`) を呼び出します。エンドポイントのパラメータとレスポンススキーマの詳細については、エンドポイントのドキュメントを参照してください。

    テナント名はファイル名にも使用されます。たとえば、テナント名が`auth0docs`の場合、ファイル名は`auth0docs.csv`または`auth0docs.json`です。

    `location`パラメータの値として提供されるURLを使用して、エクスポートファイルにアクセスできます。URLにアクセスすると、ファイルのダウンロードが自動的に開始されます。
  </Tab>
</Tabs>

ダウンロードリンクの有効期限は60秒です。この期間を過ぎた場合でも、ジョブの有効期限が切れるまでの24時間以内であれば、再度呼び出すことができます。

<div id="limits">
  ## 制限
</div>

* すべてのジョブ関連データは、24時間後に自動的に削除されます。

* CSV形式でエクスポートできるデータは30フィールドまでです。

* CSV形式のデータエクスポートでは、`app_metadata` または `user_metadata` を単一のobjectとして含めることはできません。代わりに、メタデータobjectのフィールドを明示的に指定するか、メタデータを単一のobjectとして扱えるJSON互換形式でデータをエクスポートしてください。

  <Columns>
    <Column>
      ```json JSON互換形式のリクエスト本文
      {
        "format": "json",
        "fields": [
          { "name": "user_metadata.example" }
        ]
      }
      ```
    </Column>

    <Column>
      ```json CSV形式のリクエスト本文
      {
        "format": "csv",
        "fields": [
          { "name": "user_metadata.example.field_one" },
          { "name": "user_metadata.example.field_two" },
          { "name": "user_metadata.example.field_three" }
        ]
      }
      ```
    </Column>
  </Columns>
