Auth0 Dashboard または Management API を使用して、メールアドレスまたはユーザー ID で特定のユーザープロファイルを取得できます。

<Tabs>
  <Tab title="Auth0 Dashboard">
    Auth0 Dashboard を使用して、メールアドレスまたはユーザー ID で特定のユーザーを取得するには、次の手順に従います。

    1. [Dashboard &gt; User Management &gt; Users](https://manage.auth0.com/#/users) に移動します。

       ![Auth0 Dashboard の Users ページ](/docs/images/user-management/users.png)

    2. **Search by** ドロップダウンメニューで、ユーザー ID で検索する場合は **User**、メールアドレスで検索する場合は **Email** を選択します。

    3. 検索フィールドに、検索するユーザー ID またはメールアドレスを入力します。

    4. 検索結果で、対象ユーザーの **...** メニューを開き、**詳細を表示** を選択してユーザーの完全なプロファイルを表示します。
  </Tab>

  <Tab title="Management API">
    Management APIでは、特定のユーザーを取得するためのendpointが2つ提供されています：

    * [Get a User endpoint](/docs/ja-jp/api/management/v2/users/get-users-by-id) (`GET /users/{id}`) は、ユーザー ID を使用して特定のユーザーの詳細を取得します。

    * [Search Users by Email endpoint](/docs/ja-jp/api/management/v2/users-by-email/get-users-by-email) (`GET /users-by-email`) は、指定されたメールアドレスに一致するユーザーの詳細を取得します。

    これらのManagement APIエンドポイントは即時整合性があるため、リクエストの直前に行われたものを含め、成功したすべての書き込み操作が結果に反映されます。したがって、認証時またはアカウントリンク時のユーザー検索にこれらのエンドポイントを使用できます。

    ユーザーIDで特定のユーザーを取得するには、[Get a User エンドポイント](/docs/ja-jp/api/management/v2/users/get-users-by-id) (`GET /users/{id}`) を呼び出し、URLエンコードされたユーザーIDを[`id`パスパラメータ](/docs/ja-jp/api/management/v2/users/get-users-by-id#parameter-id)として渡します。

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">Auth0 CLIをお使いですか？まだの場合は、このコマンドを実行する前に[CLIセッションのセットアップと認証](/docs/ja-jp/deploy-monitor/auth0-cli)を行ってください。</Callout>

    <AuthCodeGroup>
      ```bash Auth0 CLI
      auth0 api get "users/%7BuserId%7D"
      ```

      ```bash curl
      curl --request GET \
        --url 'https://{yourDomain}/api/v2/users/%7BuserId%7D' \
        --header 'authorization: Bearer {yourMgmtApiAccessToken}'
      ```

      ```csharp C#
      var client = new RestClient("https://{yourDomain}/api/v2/users/%7BuserId%7D");
      var request = new RestRequest(Method.GET);
      request.AddHeader("authorization", "Bearer {yourMgmtApiAccessToken}");
      IRestResponse response = client.Execute(request);
      ```

      ```go Go
      package main

      import (
      	"fmt"
      	"net/http"
      	"io/ioutil"
      )

      func main() {
      	url := "https://{yourDomain}/api/v2/users/%7BuserId%7D"
      	req, _ := http.NewRequest("GET", url, nil)
      	req.Header.Add("authorization", "Bearer {yourMgmtApiAccessToken}")

      	res, _ := http.DefaultClient.Do(req)
      	defer res.Body.Close()
      	body, _ := ioutil.ReadAll(res.Body)

      	fmt.Println(res)
      	fmt.Println(string(body))
      }
      ```

      ```java Java
      HttpResponse<String> response = Unirest.get("https://{yourDomain}/api/v2/users/%7BuserId%7D")
        .header("authorization", "Bearer {yourMgmtApiAccessToken}")
        .asString();
      ```

      ```javascript Node.JS
      var axios = require("axios").default;

      var options = {
        method: 'GET',
        url: 'https://{yourDomain}/api/v2/users/%7BuserId%7D',
        headers: {authorization: 'Bearer {yourMgmtApiAccessToken}'}
      };

      axios.request(options).then(function (response) {
        console.log(response.data);
      }).catch(function (error) {
        console.error(error);
      });
      ```

      ```php PHP
      $curl = curl_init();

      curl_setopt_array($curl, [
        CURLOPT_URL => "https://{yourDomain}/api/v2/users/%7BuserId%7D",
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_ENCODING => "",
        CURLOPT_MAXREDIRS => 10,
        CURLOPT_TIMEOUT => 30,
        CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
        CURLOPT_CUSTOMREQUEST => "GET",
        CURLOPT_HTTPHEADER => [
          "authorization: Bearer {yourMgmtApiAccessToken}"
        ],
      ]);

      $response = curl_exec($curl);
      $err = curl_error($curl);

      curl_close($curl);

      if ($err) {
        echo "curl Error #:" . $err;
      } else {
        echo $response;
      }
      ```

      ```python Python
      import http.client

      conn = http.client.HTTPSConnection("")
      headers = { 'authorization': "Bearer {yourMgmtApiAccessToken}" }
      conn.request("GET", "/{yourDomain}/api/v2/users/%7BuserId%7D", headers=headers)

      res = conn.getresponse()
      data = res.read()

      print(data.decode("utf-8"))
      ```

      ```ruby Ruby
      require 'uri'
      require 'net/http'
      require 'openssl'

      url = URI("https://{yourDomain}/api/v2/users/%7BuserId%7D")

      http = Net::HTTP.new(url.host, url.port)
      http.use_ssl = true
      http.verify_mode = OpenSSL::SSL::VERIFY_PEER

      request = Net::HTTP::Get.new(url)
      request["authorization"] = 'Bearer {yourMgmtApiAccessToken}'

      response = http.request(request)
      puts response.read_body
      ```

    メールアドレスから特定のユーザーを取得するには、[Search Users by Email エンドポイント](/docs/ja-jp/api/management/v2/users-by-email/get-users-by-email) (`GET /users-by-email`) を呼び出し、メールアドレスを[`email`クエリパラメーター](/docs/ja-jp/api/management/v2/users-by-email/get-users-by-email#parameter-email)として渡します：

    <AuthCodeGroup>
      ```bash Auth0 CLI
      auth0 api get "users-by-email" \
        -q "email=%7BuserEmailAddress%7D"
      ```

      ```bash curl
      curl --request GET \
        --url 'https://{yourDomain}/api/v2/users-by-email?email=%7BuserEmailAddress%7D' \
        --header 'authorization: Bearer {yourMgmtApiAccessToken}'
      ```

      ```csharp C#
      IRestResponse response = client.Execute(request);
      ```
