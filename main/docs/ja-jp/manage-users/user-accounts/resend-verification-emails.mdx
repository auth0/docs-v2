ユーザーに確認メールを再送する必要がある場合は、Auth0 User Management Dashboard または Auth0 <Tooltip tip="Management API: お客様が管理タスクを実行できるようにするプロダクトです。" cta="用語集を見る" href="/docs/ja-jp/glossary?term=Management+API">Management API</Tooltip> を使用して再送できます。

<Tabs>
  <Tab title="Dashboard">
    Auth0 Dashboard を使用して、ユーザーに確認メールを再送できます。

    1. Auth0 Dashboard で、[**User Management &gt; Users**](https://manage.auth0.com/#/users) に移動します。
    2. ユーザーを選択します。
    3. **Actions** ドロップダウンメニューを開き、**Send Verification Email** を選択します。

    [複数のカスタムドメイン](/docs/ja-jp/customize/custom-domains/multiple-custom-domains) を有効にしている場合は、テナントの通知ドメインを選択する **Domain** オプションを使用できます。
  </Tab>

  <Tab title="Management API">
    Auth0 Management API を使用して、ユーザーに確認メールを再送できます。

    1. `update:users` scope を持つ [Management API access token](/docs/ja-jp/secure/tokens/access-tokens/management-api-access-tokens) を取得します。

    2. ユーザーの `user_id` を指定して、Management API の [Send an email address verification email エンドポイント](/docs/ja-jp/api/management/v2/jobs/post-verification-email) を呼び出します。

       ```json Request example
       {
          "user_id":"auth0|62463410c0242d00699461c8"
       }
       ```

       [複数のカスタムドメイン](/docs/ja-jp/customize/custom-domains/multiple-custom-domains) を有効にしている場合は、[`auth0-custom-domain` HTTP ヘッダーを含める](/docs/ja-jp/customize/custom-domains/multiple-custom-domains#customize-email-handling-using-the-management-api)必要があります。

    レスポンスにはジョブの `id` が含まれます。

    ```json Response example
    {
       "type":"verification_email",
       "status":"pending",
       "created_at":"2022-03-31T23:08:05.612Z",
       "id":"job_PyfpRHlmpkSoDmCv"
    }
    ```

    ジョブの `id` を使用して Management API の [Get a job エンドポイント](/docs/ja-jp/api/management/v2/jobs/get-jobs-by-id) を呼び出すと、ジョブのステータスを確認できます。
  </Tab>
</Tabs>
