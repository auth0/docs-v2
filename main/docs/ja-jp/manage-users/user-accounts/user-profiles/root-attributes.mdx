---
title: ユーザープロファイル属性の変更
description: Auth0の正規化ユーザープロファイルで使用できる属性と、その更新方法について説明します。
---

Auth0の[正規化ユーザープロファイル](/docs/ja-jp/manage-users/user-accounts/user-profiles/user-profile-structure)には、オブジェクトの最上位 (ルートレベル) に保存される属性が複数あり、その一部は更新できます。属性の設定・更新方法は、Auth0を<Tooltip tip="IDプロバイダー（IdP）：デジタルIDを保存・管理するサービス。" cta="用語集を見る" href="/docs/ja-jp/glossary?term=Identity+Provider">IDプロバイダー</Tooltip> (IdP) として使用する接続か、アップストリームのIdPを使用する接続かによって異なります。

* Auth0がIdPの場合、次の操作ができます。

  * ユーザーのサインアップ時に属性を設定する (Management APIまたは公開サインアップを使用)
  * ユーザーのインポート時に属性を設定する
  * Management APIを使用して属性を編集する

  [データベース接続](/docs/ja-jp/authenticate/database-connections) (通常の接続と、インポートモードが有効なカスタム接続) および[パスワードレス接続](/docs/ja-jp/authenticate/passwordless)では、Auth0がIdPになります。

* アップストリームのIdPを使用する場合、次の2つの方法があります。

  * デフォルトの動作を使用する。アップストリームのIdPは、ユーザーの初回作成時に属性を設定し、以降はログインのたびに自動更新します。ログインのたびにIdPによって更新されるため、これらの属性を直接編集することはできません。

  * Auth0との接続の同期を設定する。アップストリームのIdPは、ユーザーの初回作成時にのみ属性を設定し、以降のログイン時には更新しません。そのため、Management APIを使用してこれらの属性を直接編集できます。

  [ソーシャル接続](/docs/ja-jp/authenticate/identity-providers#social)、[エンタープライズ接続](/docs/ja-jp/authenticate/identity-providers#enterprise)、[法的アイデンティティ接続](/docs/ja-jp/authenticate/identity-providers#legal-identities)では、アップストリームのIdPが使用されます。
