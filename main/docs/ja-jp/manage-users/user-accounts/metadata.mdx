Auth0 のユーザープロファイルには 2 種類のメタデータが含まれます。

* `user_metadata` は、ユーザーの中核的な機能に影響しない、設定などのユーザー情報を保存します。

  このデータは、Management API を使用してフォームを作成した場合、ログイン中のユーザーが編集**できます**。そのため、安全なデータストアとして使用するべきでは**ありません**。

* `app_metadata` は、permissions、Auth0 のプラン、外部 ID など、ユーザーの機能へのアクセスに影響するアクセス情報を保存します。

  このデータはユーザーが編集**できません**。また、このフィールドに保存できる内容には制限があります。

メタデータは、ユーザーのログインフローの中で変更できます。メタデータは次のような用途に使用できます。

* アプリケーション固有のデータをユーザープロファイルに保存する。
* ユーザーに対して特定の操作が実行済みかどうかを記録する。
* 負荷の高い処理の結果をユーザープロファイルにキャッシュし、次回以降のログインで再利用する。
* <Tooltip tip="IDプロバイダー (IdP): デジタルIDを保存・管理するサービス。" cta="用語集を表示" href="/docs/ja-jp/glossary?term=identity+provider">IDプロバイダー</Tooltip>に由来しない情報や、IDプロバイダーから提供される情報をオーバーライドする情報を保存する。
* [Auth0 のメールのカスタマイズ](/docs/ja-jp/customize/email/email-templates)に使用する情報を保存する。たとえば、ユーザー自身がフィールドの値を変更できるようにしたい場合は `user_metadata.lang` を使用し、その情報をもとにメールの言語をカスタマイズします。

[Auth0 アプリケーション](/docs/ja-jp/get-started/applications) (OIDC OAuth0 の用語では *クライアント*) にも独自の [`client_metadata`](/docs/ja-jp/get-started/applications/configure-application-metadata) があり、これはユーザープロファイルのメタデータとは別のものです。
