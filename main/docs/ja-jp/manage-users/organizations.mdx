mode: wide
---

Organizations を使用すると、企業間取引 (B2B) のお客様がパートナー企業や顧客企業をより適切に管理し、エンドユーザーによるアプリケーションや API へのアクセス方法を柔軟にカスタマイズできます。Auth0 のお客様は Organizations を使用して、次のことを行えます。

* Auth0 内で顧客企業やパートナー企業を表現し、それらのメンバーシップを管理する。
* 企業ごとにブランド化されたフェデレーションログインフローを設定する。
* 顧客企業やパートナー企業が B2B API を利用できるよう、マシンツーマシン アクセスを提供する。
* Organizations API を使用して自社製品に管理機能を組み込み、それらの企業が自社の組織を管理できるようにする。
