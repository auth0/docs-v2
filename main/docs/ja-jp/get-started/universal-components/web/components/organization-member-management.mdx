## はじめに {#get-started}

    ```tsx wrap lines
    import { OrganizationMemberManagement } from "@auth0/universal-components-react";

    export function MembersPage() {
      return <OrganizationMemberManagement />;
    }
    ```

    管理者が個々のメンバーを表示できるようにするには、`viewMemberDetailsAction` に [`OrganizationMemberDetail`](/docs/ja-jp/get-started/universal-components/web/components/organization-member-detail) を配置したルートへ遷移する処理を設定します。

    ```tsx wrap lines
    import { OrganizationMemberManagement } from "@auth0/universal-components-react";
    import { useNavigate } from "react-router-dom";

    export function MembersPage() {
      const navigate = useNavigate();

      return (
        <OrganizationMemberManagement
          viewMemberDetailsAction={{
            onAfter: ({ userId, tab }) =>
              navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
          }}
        />
      );
    }
    ```

    <Accordion title="統合の完全な例">
      ```tsx lines
      import React from "react";
      import { useNavigate } from "react-router-dom";
      import { OrganizationMemberManagement } from "@auth0/universal-components-react";
      import { Auth0Provider } from "@auth0/auth0-react";
      import { Auth0ComponentProvider } from "@auth0/universal-components-react/spa";
      import { auditLog } from "./lib/audit-log";

      function MembersPage() {
        const navigate = useNavigate();

        return (
          <div className="max-w-5xl mx-auto p-6">
            <OrganizationMemberManagement
              createInvitationAction={{
                onBefore: (input) => {
                  const email = input.invitees[0]?.email ?? "";
                  return email.endsWith("@example.com");
                },
                onAfter: (input, createdInvitation) => {
                  auditLog.record({
                    action: "invitation_created",
                    email: input.invitees[0]?.email,
                    invitationId: createdInvitation.id,
                  });
                },
              }}
              revokeInvitationAction={{
                onBefore: (invitations) =>
                  window.confirm(`Revoke ${invitations.length} invitation(s)?`),
                onAfter: (invitations) => {
                  auditLog.record({
                    action: "invitations_revoked",
                    count: invitations.length,
                  });
                },
              }}
              resendInvitationAction={{
                onAfter: (original, newInvitation) => {
                  auditLog.record({
                    action: "invitation_resent",
                    originalId: original.id,
                    newId: newInvitation.id,
                  });
                },
              }}
              viewMemberDetailsAction={{
                onAfter: ({ userId, tab }) =>
                  navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
              }}
              removeFromOrganizationAction={{
                onBefore: (userId) =>
                  window.confirm(`Remove member ${userId} from the organization?`),
                onAfter: (userId) => {
                  auditLog.record({ action: "member_removed", userId });
                },
              }}
              assignRolesAction={{
                onAfter: ({ userId, roleIds }) => {
                  auditLog.record({ action: "roles_assigned", userId, roleIds });
                },
              }}
              customMessages={{
                header: { title: "Team Members" },
                tabs: { invitations: "Pending Invites" },
              }}
              styling={{
                variables: {
                  light: { "--color-primary": "#4f46e5" },
                  dark: { "--color-primary": "#818cf8" },
                },
              }}
            />
          </div>
        );
      }

      export default function App() {
        const domain = "YOUR_TENANT.auth0.com";
        const clientId = "YOUR_CLIENT_ID";

        return (
          <Auth0Provider
            domain={domain}
            clientId={clientId}
            authorizationParams={{ redirect_uri: window.location.origin }}
          >
            <Auth0ComponentProvider>
              <MembersPage />
            </Auth0ComponentProvider>
          </Auth0Provider>
        );
      }
      ```

## プロップ {#props}

### 表示プロップ {#display-props}

表示プロップは、コンポーネントの動作に影響を与えずに、表示方法を制御します。セクションを非表示にしたり、読み取り専用モードを有効にしたりする場合に使用します。

| プロップ         | 型         | 説明                                                       |
| :----------- | :-------- | :------------------------------------------------------- |
| `hideHeader` | `boolean` | コンポーネントのヘッダーセクション (タイトルと説明) を非表示にします。デフォルト: `false`      |
| `readOnly`   | `boolean` | すべての変更アクション (招待、取り消し、再送信、削除、割り当て) を無効にします。デフォルト: `false` |

***

### アクションプロップ {#action-props}

アクションプロップはユーザー操作を処理し、メンバーや招待に関する操作を行った際の動作を定義します。ライフサイクルフック (`onBefore`、`onAfter`) を使用して、アプリケーションのルーティングや分析と連携できます。

| プロップ                           | 型                                                          | 説明                                                 |
| :----------------------------- | :--------------------------------------------------------- | :------------------------------------------------- |
| `createInvitationAction`       | `ComponentAction<CreateInvitationInput, MemberInvitation>` | メンバーを招待するアクション。                                    |
| `revokeInvitationAction`       | `ComponentAction<MemberInvitation[]>`                      | 招待を取り消すアクション。                                      |
| `resendInvitationAction`       | `ComponentAction<MemberInvitation, MemberInvitation>`      | 招待を再送するアクション。                                      |
| `viewMemberDetailsAction`      | `ComponentAction<ViewMemberDetailsParams>`                 | メンバーの詳細を表示するアクション。                                 |
| `removeFromOrganizationAction` | `ComponentAction<string>`                                  | メンバーを削除するアクション。                                    |
| `assignRolesAction`            | `ComponentAction`                                          | ロールを割り当てるアクション。フックは `{ userId, roleIds }` を受け取ります。 |

**createInvitationAction**

**型:** `ComponentAction<CreateInvitationInput, MemberInvitation>`

招待の作成を制御します (1回のリクエストで最大10人まで招待可能) 。

* `onBefore(input)` は送信前に同期的に実行されます。キャンセルするには `false` を返します。
* `onAfter(input, createdInvitation)` は招待の作成後に実行されます。

```tsx wrap lines
<OrganizationMemberManagement
  createInvitationAction={{
    onBefore: (input) => {
      const email = input.invitees[0]?.email ?? "";
      return email.endsWith("@example.com");
    },
    onAfter: (input, createdInvitation) => {
      auditLog.record({
        action: "invitation_created",
        email: input.invitees[0]?.email,
        invitationId: createdInvitation.id,
      });
    },
  }}
/>
```

**招待の接続ルーティング**

招待ピッカーには、対象となるエンタープライズ SSO IDプロバイダーと、その Organization に設定され有効化されているユーザーストア / ユーザーディレクトリが一覧表示されます。

接続セレクターは、次の両方のソースに問い合わせます。

* `GET /my-org/identity-providers` (対象となるメンバーのアクセスレベルで絞り込み)
* `GET /my-org/user-stores` (`is_enabled: true` で絞り込み)

```ts
type ConnectionOptionType = 'identity_provider' | 'user_store';

interface ConnectionOption {
  id: string;
  name: string;
  type: ConnectionOptionType;
}
```

`createInvitationAction` に送信されるペイロードでは、選択した接続の種類に応じて、該当する識別子が 1 つだけ使用されます。

* **エンタープライズ SSO 接続を選択した場合:** ペイロードに `identity_provider_id` が設定されます。
* **ユーザーストア / Directory 接続を選択した場合:** ペイロードに `user_store_id` が設定されます。

```ts
interface CreateInvitationInput {
  invitees: Array<{
    email: string;
    roles?: string[];
  }>;
  inviter?: {
    name?: string;
  };
  identity_provider_id?: string;
  user_store_id?: string;
  ttl_sec?: number;
}
```

接続のルーティングルール:

* **自動選択:** 組織に対象となる接続が1つしかない場合、その接続が既定で選択されますが、編集は可能です。
* **接続がない場合:** 対象となる接続が存在しない場合、招待のエントリポイントは無効になり、その理由を説明するフィードバックが表示されます。
* **取り消しと再送信:** 取り消しと再送信のフローでは、元の接続ルーティング元 (`user_store_id` または `identity_provider_id`) が保持されます。
* **接続の対象条件:** 招待のピッカーには、メンバーアクセスレベルが `limited` または `full` に設定された接続が表示されます。

**revokeInvitationAction**

**型:** `ComponentAction<MemberInvitation[]>`

招待の取り消しを制御します (単一および一括の取り消しに対応し、1バッチあたり最大10件まで取り消せます) 。

* `onBefore(invitations)` は取り消し前に確認を行います。キャンセルする場合は `false` を返します。
* `onAfter(invitations)` は招待が取り消された後に実行されます。

```tsx wrap lines
<OrganizationMemberManagement
  revokeInvitationAction={{
    onBefore: (invitations) =>
      window.confirm(`Revoke ${invitations.length} invitation(s)?`),
    onAfter: (invitations) => {
      auditLog.record({
        action: "invitations_revoked",
        count: invitations.length,
      });
    },
  }}
/>
```

**resendInvitationAction**

**型:** `ComponentAction<MemberInvitation, MemberInvitation>`

招待の取り消しと再送信のフローを制御します。

* `onBefore(invitation)` は再送信前に確認を行います。中止するには `false` を返します。
* `onAfter(original, newInvitation)` は新しい招待が作成された後に実行されます。

```tsx wrap lines
<OrganizationMemberManagement
  resendInvitationAction={{
    onAfter: (original, newInvitation) => {
      auditLog.record({
        action: "invitation_resent",
        originalId: original.id,
        newId: newInvitation.id,
      });
    },
  }}
/>
```

**viewMemberDetailsAction**

**型:** `ComponentAction<ViewMemberDetailsParams>`

メンバー行またはロールバッジを選択したときに発火します。`{ userId, tab }` を受け取ります。これをフックして `OrganizationMemberDetail` へ遷移させます。

* `onAfter({ userId, tab })` は選択時に実行されます。指定されたタブを直接開けるよう、ルーターの URL に `tab` を保持してください。

```tsx wrap lines
<OrganizationMemberManagement
  viewMemberDetailsAction={{
    onAfter: ({ userId, tab }) =>
      navigate(tab ? `/members/${userId}?tab=${tab}` : `/members/${userId}`),
  }}
/>
```

**removeFromOrganizationAction**

**型:** `ComponentAction<string>`

Organization からのメンバー削除を制御します (対象はメンバーシップのみで、Auth0 のユーザーストアからユーザープロファイルが削除されるわけではありません) 。どちらのフックも `userId` を受け取ります。

* `onBefore(userId)` は削除前に確認を行います。キャンセルするには `false` を返します。
* `onAfter(userId)` は削除後に実行されます。

```tsx wrap lines
<OrganizationMemberManagement
  removeFromOrganizationAction={{
    onBefore: (userId) =>
      window.confirm(`Remove member ${userId} from the organization?`),
    onAfter: (userId) => {
      auditLog.record({ action: "member_removed", userId });
    },
  }}
/>
```

**assignRolesAction**

**型:** `ComponentAction<{ userId: string; roleIds: string[] }>`

行モーダルからロールを割り当てた後に発火します。選択できるロールは1回の割り当てリクエストあたり10個までで、1人のメンバーに割り当てられるロールは合計50個までです。どちらのフックも `{ userId, roleIds }` を受け取ります。

* `onBefore({ userId, roleIds })` は選択内容を検証します。キャンセルするには `false` を返します。
* `onAfter({ userId, roleIds })` はロールの割り当て後に実行されます。

```tsx wrap lines
<OrganizationMemberManagement
  assignRolesAction={{
    onAfter: ({ userId, roleIds }) => {
      auditLog.record({ action: "roles_assigned", userId, roleIds });
    },
  }}
/>
```

**styling**

CSS変数とクラスのオーバーライドで外観をカスタマイズします。変数は `light`、`dark`、`common` のスコープに対応しています。クラスのオーバーライドは、コンポーネントツリー内の名前付きスロットに適用されます。

<Accordion title="利用可能なスタイル設定オプション">
  **Variables**—CSSカスタムプロパティ

  * `common`—すべてのテーマに適用
  * `light`—ライトテーマのみ
  * `dark`—ダークテーマのみ

  **Classes**—対象要素へのクラスのオーバーライド

  * `OrganizationMemberManagement-root`
  * `OrganizationMemberManagement-header`
  * `OrganizationMemberManagement-tabs`
  * `OrganizationInvitationTab-root`
  * `OrganizationInvitationTab-table`
  * `OrganizationInvitationTab-createModal`
  * `OrganizationInvitationTab-detailsModal`
  * `OrganizationInvitationTab-revokeModal`
  * `OrganizationInvitationTab-revokeResendModal`
  * `OrganizationInvitationTab-bulkRevokeModal`
  * `OrganizationInvitationTab-searchInput`
  * `OrganizationInvitationTab-filterDropdown`
  * `OrganizationInvitationTab-pagination`
</Accordion>
