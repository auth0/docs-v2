---
title: mTLS 認証を設定する
description: Auth0 Dashboard または Management API を使用して、Auth0 テナントとアプリケーションの相互 TLS（mTLS）認証を設定します。
---

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Highly Regulated Identity 機能を利用するには、Highly Regulated Identity アドオンを含む Enterprise プランが必要です。詳しくは、[Auth0 Pricing](https://auth0.com/pricing/)を参照してください。
</Callout>

[Auth0 Management API](https://auth0.com/docs/api/management/v2)または[Auth0 Dashboard](https://manage.auth0.com/)を使用して、mTLS 認証を設定できます。Auth0 における mTLS 認証の仕組みについて詳しくは、[Authenticate with mTLS](/docs/ja-jp/get-started/authentication-and-authorization-flow/authenticate-with-mtls)をご覧ください。
