  Auth0 Dashboard Navigation は、すべての Auth0 プランで早期アクセス機能として利用できます。

Auth0 Dashboard のナビゲーションメニューを使うと、必要な項目をよりすばやく見つけられます。整理されたセクションを備えたサイドバー、統一されたパンくずリスト、視覚的な階層を改善したデザインが特徴です。

<div id="enable-auth0-dashboard-navigation">
  ## Auth0 Dashboard のナビゲーションを有効にする
</div>

ナビゲーション機能がお使いのtenantで利用可能になると、初回ログイン時にオプトイン用のポップアップが表示されます。

1. **Try now** を選択して新しいナビゲーションをすぐに有効にするか、**Maybe later** を選択してポップアップを閉じます。

* **Maybe later** を選択した場合、14日後にポップアップが再表示されます。

2. オプトイン後は、ユーザープロファイルメニューからナビゲーション機能を無効にできます。

* Auth0 Dashboard の右上にあるプロファイルアイコンを選択します。
  * 新しいナビゲーションのトグルをクリックすると、以前のナビゲーションUIに戻せます。

設定は保存され、セッションをまたいで維持されます。

<div id="how-it-works">
  ## 仕組み
</div>

Auth0 Dashboard のナビゲーションでは、関連する項目を明確でワークフローに沿った名称の論理的なセクションにまとめ、目的の項目を見つけやすくしています。各ページの上部には、パンくずリスト、タブ、アクション、サイドバーの切り替えボタンを含む固定のページアクションバーが表示され、スクロール中も重要な操作を常に表示します。

一貫したコンテキストナビゲーションを提供するため、パンくずリストはページヘッダー内に分散して表示されるのではなく、アクションバーに表示されるようになりました。新しいナビゲーションでは、使いやすさを向上するため、モダンなレイアウトと構造も刷新されています。

Auth0 Dashboard でセクション間を移動する際は、再設計された左側のサイドバーを使用します。サイドバーは次のセクションで構成されています。

| セクション          | 内容                                                                                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| プライマリ (ラベルなし)  | ホーム: はじめに利用するための Dashboard のランディングページ<br />Agents: AI Agents の設定<br />ユーザー: ユーザー管理<br />Organizations: organization 管理<br />設定: テナントの設定およびアカウント管理                                   |
| 連携             | アプリケーション: アプリケーションの登録と管理<br />API: API の登録と管理<br />認証: 認証の設定 (データベース、パスワードレス) <br />接続: ソーシャル接続の管理<br />Enterprise SSO: エンタープライズ接続およびセルフサービスプロファイルの管理<br />Authorization: ロールの作成と管理 |
| カスタマイズ         | ブランディング: Universal Login テーマ用のビジュアルエディター<br />ページ: Universal Login と Forms ページのカスタマイズ<br />ポータル: ポータルページ用のビジュアルエディター<br />ドメイン: カスタムドメインの管理                                         |
| メッセージング        | メール: メールテンプレートおよび設定<br />電話: 電話メッセージの設定                                                                                                                                             |
| 自動化と拡張         | Actions: Auth0 Actions の作成と管理<br />イベント: 認証イベントを外部サービスにストリーミング<br />Extensions: 公式およびサードパーティのアドオン<br />ルール: レガシールール (既存の設定用) <br />Hooks: レガシーフック (既存の設定用)                          |
| セキュリティとモニタリング  | 攻撃対策: ボット、IP スロットリング、ブルートフォース、Breached Password Protection<br />アクセス制御: アクセス制御リスト<br />セキュリティダッシュボード: セキュリティの概要および脅威メトリクス<br />ログ: アクティビティログの表示<br />分析: 使用状況の分析およびレポート             |

<div id="browser-support">
  ## 対応ブラウザ
</div>

新しいナビゲーションを使用するには、サイドバーの状態を保持するために `localStorage` をサポートする最新のブラウザが必要です。問題が発生した場合は、プロファイルメニューのトグルで、いつでも従来のナビゲーションに戻すことができます。
