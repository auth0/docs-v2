カスタムデータベースからエラーが返されることがあります。トラブルシューティングのために、データベースアクションスクリプトからエラーを返すこともできます。

<div id="custom-database-error-types">
  ## カスタムデータベースのエラータイプ
</div>

データベース接続では、以下のエラーが返されることがあります。

| エラー                                                                                 | アクションスクリプト      | 発生条件                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `new WrongUsernameOrPasswordError(`<br />`  <email or user_id>, <message>`<br />`)` | Login           | ユーザーの資格情報が無効です。[ログイベントタイプコード](/docs/ja-jp/deploy-monitor/logs/log-event-type-codes)は次のとおりです。<ul><li>引数を渡さない場合、または最初の引数にfalseyな値を渡した場合は、`user_id` に空文字列を含む `fu` (無効なユーザー名/メールアドレス) 。</li> <li>最初の引数にtruthyな値を渡した場合は、`user_id` の値が `auth0\|<first_argument>` となる `fp` (ユーザーは存在するがパスワードが無効) 。</li> </ul> |
| `new ValidationError(`<br />`  <user_exists>, <message>`<br />`)`                   | Create          | ユーザーはすでにデータベースに存在します。                                                                                                                                                                                                                                                                           |
| `callback(<null>,<false>)`                                                          | Change Password | ユーザーのパスワードは更新されませんでした。                                                                                                                                                                                                                                                                          |
| `callback(<null>)`                                                                  | Get User        | ユーザーが見つかりません。                                                                                                                                                                                                                                                                                   |
| `new UnauthorizedError(<message>)`                                                  | すべてのLoginスクリプト  | データベースへの接続中に問題が発生しました。カスタムデータベースからフロントエンドにエラーを返す際の推奨方法です。                                                                                                                                                                                                                                       |
| `new Error(<message>)`                                                              | すべてのLoginスクリプト  | データベースへの接続中に問題が発生しました。                                                                                                                                                                                                                                                                          |
| `error code: auth0_idp_error;` `user already exists`                                | Create          | Auth0への自動移行が無効で、外部ユーザーストアまたはAuth0にすでに存在するユーザーを作成しようとしています。                                                                                                                                                                                                                                      |
| `error code: auth0_idp_error;` `user already exists`                                | Delete          | Auth0への自動移行が無効で、カスタムデータベーススクリプトを使用してユーザーを削除しようとしています。<br /><br />エラーは、「Error! There was a problem deleting `user@example.com`」または「Sandbox Error: Please implement the Delete script for this database connection」として表示されることもあります。                                                               |

<div id="return-errors">
  ## エラーを返す
</div>

データベースアクションスクリプトでは、[ `callback` 関数](/docs/ja-jp/authenticate/database-connections/custom-db/custom-database-connections-scripts#callback)を使用してエラーを返すことができます。例:

```js wrap lines
callback(new ValidationError('email-too-long', 'Email is too long.'));
```

Lock を使用している場合は、辞書に追加することで[エラーメッセージをカスタマイズ](/docs/ja-jp/customize/login-pages/classic-login/customize-lock-error-messages)できます。

<div id="troubleshoot-errors">
  ## エラーのトラブルシューティング
</div>

**Try** ボタンを使ってスクリプトをテストします。

期待した結果が得られない場合やエラーが発生した場合は、[Actions Real-time Logs](/docs/ja-jp/customize/actions/actions-real-time-logs) を確認し、スクリプト内で `console.log()` 文を使用して、再度接続を試してください。`console.log()` の出力は Actions Real-time Logs ウィンドウに表示されます。

アクションスクリプトを使用してユーザーのインポート、作成、削除を行う際に、エラーが発生することがあります。エラーの原因がアクションスクリプトの使用にあることを確認するには、`console.logs` を使用してください。
