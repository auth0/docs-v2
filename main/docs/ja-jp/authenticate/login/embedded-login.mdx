title: 埋め込みログイン
---

埋め込みログインを使用すると、ユーザーはアプリケーション内で直接ログインし、認証のために認証情報を Auth0 サーバーに送信できます。このオプションは、Auth0 をアイデンティティプロバイダーとして使用しながら、ログイン UI/UX を完全に制御したいチームに最適です。

埋め込みログインと [Universal Login](/docs/ja-jp/authenticate/login/auth0-universal-login) は、相互に排他的ではありません。たとえば、初回のサインインには Universal Login を使用し、[認証要素の登録](/docs/ja-jp/authenticate/login/embedded-login)またはステップアップ認証には埋め込みフローを使用できます。両者を比較して、ユースケースに適した組み合わせを判断するには、[ホスト型ログインと埋め込みログイン](/docs/ja-jp/authenticate/login/universal-vs-embedded-login)をご覧ください。

Auth0 は、複数のアプリケーションタイプにおいて、<Tooltip tip="Passwordless: 最初の要素としてパスワードに依存しない認証の形式。" cta="用語集を見る" href="/docs/ja-jp/glossary?term=Passwordless">Passwordless</Tooltip> 接続による埋め込みログインをサポートしています。

* [ネイティブアプリケーションでの埋め込み Passwordless ログイン](/docs/ja-jp/authenticate/passwordless/implement-login/embedded-login/native)
* [Regular Web Applications での埋め込み Passwordless ログイン](/docs/ja-jp/authenticate/passwordless/implement-login/embedded-login/webapps)
* [Single-Page Apps 向けの埋め込み Passwordless 認証](/docs/ja-jp/authenticate/passwordless/implement-login/embedded-login/spa)

Auth0 は、**Passkey APIs** を通じて、Web、iOS、Android アプリケーションでのパスキー認証と登録もサポートしています。

* [埋め込みアプリケーション向け Passkey APIs](/docs/ja-jp/authenticate/database-connections/passkeys/passkey-apis) — パスキーのサインアップ、ログイン、登録フローを実装
