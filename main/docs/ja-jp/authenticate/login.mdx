Auth0 では、アプリケーションのログイン認証を実装するための方法を 2 つ提供しています。

* **<Tooltip tip="Universal Login: アプリケーションは、ユーザーのアイデンティティを検証するために、Auth0 の認可サーバーでホストされる Universal Login にリダイレクトします。" cta="用語集を見る" href="/docs/ja-jp/glossary?term=Universal+Login">Universal Login</Tooltip>**：ユーザーは Auth0 がホストするページを通じてアプリケーションにログインします。

* **埋め込みログイン**：ユーザーはお客様がホストするページを通じてアプリケーションにログインします。

ログイン方法を選択する際は、ほとんどのユースケースで Universal Login を推奨します。安全で、実装も簡単です。埋め込みログインでは UI をより細かく制御できますが、リスクの増加やメンテナンスの負担が、その利点を上回ります。
