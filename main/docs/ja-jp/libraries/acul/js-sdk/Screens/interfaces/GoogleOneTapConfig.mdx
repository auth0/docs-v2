---
title: "GoogleOneTapConfig"
---

Google One Tap / FedCM の設定です。サーバーから `screen.data.google_one_tap` で提供されます。

```ts Example
export interface GoogleOneTapConfig {
  client_id: string;
  nonce: string;
  context: string;
  itp_support: boolean;
  auto_select: boolean;
  cancel_on_tap_outside: boolean;
}
```

## プロパティ {#properties}

<ParamField body="auto_select" type="boolean">
  `true` の場合、利用可能な Google セッションが 1 つだけで、かつ以前に同意済みであれば、ユーザー操作なしで自動的にクレデンシャルが返されます。
</ParamField>

<ParamField body="cancel_on_tap_outside" type="boolean">
  `true` の場合、ユーザーがプロンプトの外側をクリックすると One Tap プロンプトが閉じます。明示的に閉じる操作を必須にするには `false` を指定します。
</ParamField>

<ParamField body="client_id" type="string">
  このアプリケーションの Google OAuth 2.0 クライアント ID です。
</ParamField>

<ParamField body="context" type="string">
  One Tap プロンプトに表示されるタイトルとメッセージを変更します。指定できる値: `"signin"` (既定値) 、`"signup"`、`"use"`。
</ParamField>

<ParamField body="itp_support" type="boolean">
  `true` の場合、サードパーティクッキーを制限する Safari/WebKit ブラウザ向けに Intelligent Tracking Prevention (ITP) のサポートを有効にします。
</ParamField>

<ParamField body="nonce" type="string">
  クレデンシャルをこのセッションに紐付け、リプレイ攻撃を防ぐために使用するランダムな値です。
</ParamField>
