---
title: "ExperimentMembers"
---

現在の画面に割り当てられている、アクティブな[Experiment Center](/docs/ja-jp/customize/experiment-center)のエクスペリメントを表すインターフェースです。

```ts Example
export interface ExperimentMembers {
  experimentId: string;
  variationId: string;
  variationName: string | null;
  variationDescription: string | null;
  config: { [key: string]: unknown };
  isControl: boolean;
}
```

## プロパティ {#properties}

<ParamField body="config" type="Record">
  割り当てられたバリエーションについて解決済みの設定です。各キーは、エクスペリメントで定義された設定名 (例：`'show_passkey'`) です。

  各エントリーは `{ value: <resolved value> }` の形式でラップされて渡されます。ラッパーオブジェクトは常に truthy となるため、エントリー自体ではなく `config['<key>']?.value` で値を読み取ってください。

  `config` が存在しない場合や `null` の場合、`Experiment` モデルによって空のオブジェクト (`{}`) に正規化されます。そのため、`config` が `null` になることはありません。
</ParamField>

<ParamField body="experimentId" type="string">
  アクティブなエクスペリメントの一意の識別子です。
</ParamField>

<ParamField body="isControl" type="boolean">
  割り当てられたバリエーションがコントロールバリエーションかどうかを示します。
</ParamField>

<ParamField body="variationDescription" type="string">
  割り当てられたバリエーションの、人間が読める形式の説明です。バリエーションによっては `null` になります。
</ParamField>

<ParamField body="variationId" type="string">
  割り当てられたバリエーションの一意の識別子です。
</ParamField>

<ParamField body="variationName" type="string">
  割り当てられたバリエーションの、人間が読める形式の名前です。バリエーションによっては `null` になります。
</ParamField>
