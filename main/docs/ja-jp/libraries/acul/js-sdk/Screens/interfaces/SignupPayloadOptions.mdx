```ts Example
export interface SignupOptions {
  email?: string;
  username?: string;
  phoneNumber?: string;
  phoneCountryCode?: string;
  password?: string;
  captcha?: string;
  [key: string]: string | number | boolean | undefined;
}
```

<ParamField body="phoneCountryCode?" type="string">
  ユーザーが `phoneNumber` 用に選択した ISO 3166-1 alpha-2 の国コード (例: `'US'`) で、`countryCodes.available` 内の `code` から指定します。送信された国が優先され、サーバーが国番号を先頭に付加するため、`phoneNumber` には国番号を含まない国内番号を指定してください。省略した場合は従来の動作となり、サーバー側が国を判別し、`pickCountryCode()` が別の画面で選択を変更します。
</ParamField>
