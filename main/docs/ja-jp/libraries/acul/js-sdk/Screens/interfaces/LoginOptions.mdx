---
title: "LoginOptions"
---

```ts Example
export interface LoginOptions {
  username?: string;
  identifier?: string;
  identifierType?: IdentifierType;
  phoneCountryCode?: string;
  captcha?: string;
  [key: string]: string | number | boolean | undefined;
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

## プロパティ {#properties}

<ParamField body="captcha?" type="string" />

<ParamField body="identifier?" type="string">
  `identifierType` に応じて、loginに使用するemail、ユーザー名、または電話番号。`username` が指定されている場合は省略可能です。両方が指定されている場合は、`identifier` が優先されます。
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/type-aliases/IdentifierType">IdentifierType</a></span>}>
  `identifier` (または `username`) に格納する値。通常は `screen.data.activeIdentifierType` から読み取ります。型を指定せずに識別子を送信する場合は省略します。
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  電話番号の識別子に対応するISO 3166-1 alpha-2の国コード。`countryCodes.available` の `code` を指定します。`identifierType` が `phone` の場合は必須です。国内番号を渡してください。ダイヤルコードはサーバー側で先頭に付加されます。
</ParamField>

<ParamField body="username?" type="string">
  元のスペルで指定するユーザーの識別子。`identifier` が指定されている場合は省略可能です。それ以外の場合は必須です。
</ParamField>
