```ts Example
export interface CountryCodesMembers {
  available: AvailableCountryCode[] | null;
  recommended: string | null;
}
```

## プロパティ {#properties}

<ParamField body="available" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/AvailableCountryCode">AvailableCountryCode</a>[]</span>}>
  電話番号の入力に使用できる国の一覧で、ローカライズされた `label` 順に並びます。画面のレンダリング構成で要求されていない場合は `null` です。
</ParamField>

<ParamField body="recommended" type="string">
  あらかじめ選択する ISO 3166-1 alpha-2 コード。`available` 内のインデックスではありません。解決できない場合は `null` です。
</ParamField>
