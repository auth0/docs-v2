---
title: "LoginPayloadOptions"
---

login 操作を実行するためのオプション

```ts Example
export interface LoginOptions {
  /** ユーザーの識別子（元の表記）。`identifier` が指定されている場合は省略可能です。 */
  username?: string;
  /** ログインに使用する識別子。`username` が指定されている場合は省略可能です。両方が指定された場合は `identifier` が優先されます。 */
  identifier?: string;
  /** `identifier`（または `username`）に設定する値。通常は `screen.data.activeIdentifierType` から取得します。 */
  identifierType?: IdentifierType;
  /** 認証用のパスワード */
  password: string;
  /** 電話番号の識別子に使用する ISO 3166-1 alpha-2 の国コード。`countryCodes.available` の `code` から取得します。 */
  phoneCountryCode?: string;
  /** 必要な場合に指定する任意の CAPTCHA 値 */
  captcha?: string;
  /** その他のカスタムオプション */
  [key: string]: string | number | boolean | undefined;
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

その他のカスタムオプション

## プロパティ {#properties}

<ParamField body="captcha?" type="string">
  必要な場合に指定する任意のCAPTCHA値
</ParamField>

<ParamField body="identifier?" type="string">
  `identifierType`に応じて、email、ユーザー名、または電話番号を使用してloginするための識別子。`username`が指定されている場合は省略可能です。両方が指定されている場合は、`identifier`が優先されます。
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/type-aliases/IdentifierType">IdentifierType</a></span>}>
  `identifier` (または`username`) に格納される値。通常は`screen.data.activeIdentifierType`から読み取ります。識別子の種類を指定せずに送信する場合は省略します。
</ParamField>

<ParamField body="password" type="string">
  認証用のパスワード
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  電話番号の識別子に使用するISO 3166-1 alpha-2の国コード。`countryCodes.available`の`code`から指定します。`identifierType`が`phone`の場合は必須です。国内電話番号を渡してください。ダイヤルコードはサーバー側で先頭に付加されます。
</ParamField>

<ParamField body="username?" type="string">
  元の表記のままのユーザー識別子。`identifier`が指定されている場合は省略可能で、それ以外の場合は必須です。
</ParamField>
