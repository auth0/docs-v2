---
title: "サインアップ"
description: "Universal Login の `signup` 画面をカスタマイズするために使用できる、すべてのプロパティとメソッドについて説明します。"
---

Signup クラスは、`signup` 画面の機能を提供します。この画面では、新しいアカウントを作成するためにユーザーの資格情報を収集します。テナントによっては、識別子としてメールアドレス、電話番号、またはユーザー名を使用できます。また、ソーシャルまたはエンタープライズ接続を介したフェデレーションサインアップと Google One Tap もサポートしています。

<div id="constructors">
  ## コンストラクター
</div>

サインアップ画面マネージャーのインスタンスを作成します:

```typescript Example
import Signup from '@auth0/auth0-acul-js/signup';
const signupManager = new Signup();
signupManager.signup({
  email: 'test@example.com',
  password: 'P@$wOrd123!',
});
```

<div id="methods">
  ## メソッド
</div>

<ParamField body="changeLanguage" type="Promise<void>">
  このメソッドは、Universal Login ページの表示言語を変更します。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  signupManager.changeLanguage({
    language: 'fr',
  });
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="options">
      [LanguageChangeOptions](/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/LanguageChangeOptions)。
    </ParamField>

    <ParamField body="language" type="string" required>
      使用する言語のロケールコードです (例: `'en'`、`'fr'`、`'es'`) 。
    </ParamField>

    <ParamField body="persist?" type="&#x22;session&#x22;">
      `'session'` に設定すると、選択した言語はセッション中保持されます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="federatedSignup" type="Promise<void>">
  このメソッドは、サインアップのためにユーザーを [ソーシャル](/docs/ja-jp/authenticate/identity-providers/social-identity-providers) または [Enterprise Identity Provider](/docs/ja-jp/authenticate/identity-providers/enterprise-identity-providers) (IdP) にリダイレクトします。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  signupManager.federatedSignup({
    connection: 'google-oauth2',
  });
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="options">
      [FederatedSignupPayloadOptions](/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/FederatedSignupPayloadOptions)。
    </ParamField>

    <ParamField body="connection" type="string" required>
      ソーシャル または Enterprise Identity Provider の接続名です。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="getErrors" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/Error">Error</a>[]</span>}>
  このメソッドは、コンテキストから トランザクション エラーの配列を取得します。存在しない場合は空の配列を返します。トランザクション コンテキスト内の error object の配列です。
</ParamField>

<ParamField body="getSignupIdentifiers" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/Identifier">Identifier</a>[] | null</span>}>
  このメソッドは、サインアップ フォームで有効な 識別子 の一覧を返し、トランザクション の設定に基づいて各項目が必須か任意かを示します。識別子 object の配列です (例: email、phone、username) 。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  const identifiers = signupManager.getSignupIdentifiers();
  // [{ type: 'email', required: true }, { type: 'username', required: false }]
  ```
</ParamField>

<ParamField body="googleOneTap" type="Promise<void>">
  このメソッドは、Google One Tap の認証情報を使用して新しいユーザーを登録し、別のページへのリダイレクトなしでワンクリックによるサインアップを可能にします。

  Google One Tap のプロンプトをレンダリングする前に、`screen.googleOneTapConfig` を確認してください。この機能がサーバー側で有効になっていない場合、値は `null` です。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  signupManager.googleOneTap({ one_tap_credential: credential });
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="one_tap_credential" type="string" required>
      Google Identity Services のプロンプトから返される Google One Tap の認証情報トークンです。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="pickCountryCode" type="Promise<void>">
  このメソッドは、ユーザーを国番号の選択リストにリダイレクトし、電話番号の国番号プレフィックスを変更できるようにします。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  signupManager.pickCountryCode();
  ```
</ParamField>

<ParamField body="signup" type="Promise<void>">
  このメソッドは、サインアップフォームの送信を処理します。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  signupManager.signup({
    email: 'test@example.com',
    password: 'P@$wOrd123!',
  });
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="options">
      [SignupPayloadOptions](/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/SignupPayloadOptions)。
    </ParamField>

    <ParamField body="email?" type="string">
      ユーザーのメールアドレス。
    </ParamField>

    <ParamField body="username?" type="string">
      ユーザーの識別子。
    </ParamField>

    <ParamField body="phoneNumber?" type="string">
      ユーザーの電話番号。
    </ParamField>

    <ParamField body="password?" type="string">
      ユーザーのパスワード。
    </ParamField>

    <ParamField body="captcha?" type="string">
      CAPTCHA コードまたは CAPTCHA プロバイダーからの応答。Auth0 テナントで [ボット検出](/docs/ja-jp/secure/attack-protection/bot-detection)が有効になっている場合、このプロパティは必須です。
    </ParamField>

    <ParamField body="[`key`: `string`]" type="&#x22;string&#x22; | &#x22;number&#x22; | &#x22;boolean&#x22; | &#x22;undefined&#x22;">
      `ulp-` で始まる追加のカスタムフィールド (例: `'ulp-custom-field'`) 。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="validatePassword" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/PasswordValidationResult">PasswordValidationResult</a></span>}>
  このメソッドは、パスワードが有効かどうかと、その理由を示す [PasswordValidationResult](/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/PasswordValidationResult) 型のオブジェクトを返します。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  const result = signupManager.validatePassword('P@$wOrd123!');
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="password" type="string" required>
      ユーザーのパスワード。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="validateUsername" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/UsernameValidationResult">UsernameValidationResult</a></span>}>
  このメソッドは、指定されたユーザー名を、トランザクションコンテキストで定義された現在のユーザー名ポリシーに対して検証します。ユーザー名が有効かどうかと、その理由を示すオブジェクトを返します。

  ```typescript Example
  import Signup from '@auth0/auth0-acul-js/signup';
  const signupManager = new Signup();
  const result = signupManager.validateUsername('myusername');
  // result => { valid: true, errors: [] }
  ```

  **メソッドのパラメーター**

  <Expandable title="パラメーター">
    <ParamField body="username" type="string" required>
      バリデーション対象のユーザー名文字列。
    </ParamField>
  </Expandable>
</ParamField>
