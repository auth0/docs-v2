---
title: "確認"
description: "Universal Login の `confirmation` 画面をカスタマイズするために利用可能なすべてのプロパティとメソッドについて説明します。"
---

Confirmation クラスは、`confirmation` 画面の機能を実装します。この画面は、Auth0 が自動サインアップの可能性を検出した場合に、OTP の検証後に表示されます。ユーザーはアカウントを作成するかどうかを確認できます。

<Frame>
  <img style={{maxHeight:"400px"}} src="/docs/images/cdy7uua7fh8z/ACUL/confirmation.png" alt="確認画面" />
</Frame>

<div id="constructors">
  ## コンストラクター
</div>

Confirmation画面マネージャーのインスタンスを作成します。

```typescript Example
import Confirmation from '@auth0/auth0-acul-js/confirmation';
const confirmationManager = new Confirmation();
await confirmationManager.proceedToSignup();
```

<div id="methods">
  ## メソッド
</div>

<ParamField body="proceedToSignup" type="Promise<void>">
  このメソッドは自動サインアップを確定し、OTP検証後にアカウントの作成を続行します。

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  await confirmationManager.proceedToSignup();
  ```
</ParamField>

<ParamField body="goBack" type="Promise<void>">
  このメソッドは自動サインアップを拒否し、アカウントを作成せずにユーザーをログイン画面に戻します。

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  await confirmationManager.goBack();
  ```
</ParamField>

<ParamField body="changeLanguage" type="Promise<void>">
  このメソッドはUniversal Loginページの表示言語を変更します。

  ```typescript Example
  import Confirmation from '@auth0/auth0-acul-js/confirmation';
  const confirmationManager = new Confirmation();
  confirmationManager.changeLanguage({
    language: 'fr',
  });
  ```

  **メソッドパラメータ**

  <Expandable title="パラメータ">
    <ParamField body="options">
      [LanguageChangeOptions](/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/LanguageChangeOptions)。
    </ParamField>

    <ParamField body="language" type="string" required>
      使用する言語のロケールコード (例：`'en'`、`'fr'`、`'es'`) 。
    </ParamField>

    <ParamField body="persist?" type="&#x22;session&#x22;">
      `'session'`に設定すると、選択した言語はセッション中保持されます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="getErrors" type={<span><a href="/docs/ja-jp/libraries/acul/js-sdk/Screens/interfaces/Error">Error</a>[]</span>}>
  このメソッドは、コンテキストからトランザクションエラーの配列を取得します。エラーがない場合は空の配列を返します。
</ParamField>
