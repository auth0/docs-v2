TryAnotherMethodOptions

```ts Example
export interface TryAnotherMethodOptions extends CustomOptions {
  /**
   * 現在の画面で最初に表示または選択された配信方法。
   * 'pick-authenticator' アクションを正しく処理するために、APIエンドポイントで必要とされます。
   * - `sms`: 現在の画面がSMSチャレンジ用であることを示します。
   * - `voice`: 現在の画面がVoiceチャレンジ用であることを示します。
   * @type {'sms' | 'voice'}
   */
  type: 'sms' | 'voice';
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

## プロパティ {#properties}

<ParamField body="type" type="&#x22;sms&#x22; | &#x22;voice&#x22;">
  現在の画面で最初に表示または選択された配信方法です。
  これは、APIエンドポイント が `pick-authenticator` アクションを正しく処理するために必要です。

  * `sms`: 現在の画面が SMS challenge 用であることを示します。
  * `voice`: 現在の画面が Voiceチャレンジ 用であることを示します。
</ParamField>
