```ts Example
export interface CountryCodesMembers {
  available: AvailableCountryCode[] | null;
  recommended: string | null;
}
```

## プロパティ {#properties}

<ParamField body="available" type={<span><a href="/docs/ja-jp/libraries/acul/react-sdk/API-Reference/Types/interfaces/AvailableCountryCode">AvailableCountryCode</a>[]</span>}>
  電話番号入力で利用可能な国。ローカライズされた`ラベル`でソートされます。画面のレンダリング設定で要求された場合にのみ使用でき、それ以外は`null`です。
</ParamField>

<ParamField body="recommended" type="string">
  事前選択する ISO 3166-1 alpha-2 コード。`available`内のインデックスではありません。解決できない場合は`null`です。
</ParamField>
