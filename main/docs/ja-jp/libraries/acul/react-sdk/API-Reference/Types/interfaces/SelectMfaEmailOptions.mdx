メールアドレスを選択する際のオプション

```ts Example
export interface SelectMfaEmailOptions {
  /**
   * @param {number} index - 選択する電話番号のインデックス。
   *
   */
  index: number;
  /** カスタムオプション */
  [key: string]: string | number | boolean | undefined;
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

その他のカスタムオプション

## プロパティ {#properties}

<ParamField body="index" type="number">
  選択する電話番号のインデックスです。
</ParamField>
