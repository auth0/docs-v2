```ts Example
export interface SignupOptions {
  email?: string;
  username?: string;
  phone?: string;
  phoneCountryCode?: string;
  captcha?: string;
  [key: string]: string | number | boolean | undefined;
}
```

## 添字アクセス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

<ParamField body="phoneCountryCode?" type="string">
  ユーザーが `phone` 用に選択した ISO 3166-1 alpha-2 の国 (例: `'US'`) であり、`countryCodes.available` の `code` から指定します。送信された国が優先されます。サーバーがダイヤルコードを付加するため、`phone` にはダイヤルコードを含まない国内電話番号を指定してください。省略すると、サーバーが国を自動的に判定し、`pickCountryCode()` が別画面で選択を変更する従来の動作が維持されます。
</ParamField>
