ログイン画面用の拡張画面メンバーインターフェース

```ts Example
export interface ScreenMembersOnLogin extends ScreenMembers {
  signupLink: string | null;
  resetPasswordLink: string | null;
  data: {
    username?: string;
    activeIdentifierType?: IdentifierType;
  } | null;
}
```
