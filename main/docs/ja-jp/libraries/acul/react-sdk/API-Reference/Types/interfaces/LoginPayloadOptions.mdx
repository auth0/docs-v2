ログイン操作のオプション

```ts Example
export interface LoginPayloadOptions {
  /** ユーザーの識別子（元の表記）。`identifier` が指定されている場合は省略可能。 */
  username?: string;
  /** login に使用する識別子。`username` が指定されている場合は省略可能。両方が指定されている場合は `identifier` が優先されます。 */
  identifier?: string;
  /** `identifier`（または `username`）に格納される値。通常は `screen.data.activeIdentifierType` から取得します。 */
  identifierType?: IdentifierType;
  /** 認証用のパスワード */
  password: string;
  /** 電話番号の識別子に使用する ISO 3166-1 alpha-2 国コード。`countryCodes.available` 内の `code` から取得します。 */
  phoneCountryCode?: string;
  /** 必要な場合に指定する任意の CAPTCHA 値 */
  captcha?: string;
  /** その他のカスタムオプション */
  [key: string]: string | number | boolean | undefined;
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

その他のカスタムオプション

## プロパティ {#properties}

<ParamField body="captcha?" type="string">
  必要に応じて指定する任意のCAPTCHA値
</ParamField>

<ParamField body="identifier?" type="string">
  ログインに使用する識別子。`identifierType` に応じて、email、ユーザー名、または電話番号を指定します。`username` が指定されている場合は省略可能です。両方が指定されている場合は、`identifier` が優先されます。
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/ja-jp/libraries/acul/react-sdk/API-Reference/Types/type-aliases/IdentifierType">IdentifierType</a></span>}>
  `identifier` (または `username`) に格納される値の種類。通常は `screen.data.activeIdentifierType` から読み取ります。型を指定せずに識別子を送信する場合は省略します。
</ParamField>

<ParamField body="password" type="string">
  認証用のパスワード
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  電話番号の識別子に使用するISO 3166-1 alpha-2国コード。`countryCodes.available` の `code` を指定します。`identifierType` が `phone` の場合は必須です。国内番号を渡してください。ダイヤルコードはサーバー側で先頭に付加されます。
</ParamField>

<ParamField body="username?" type="string">
  元の表記のままのユーザー識別子。`identifier` が指定されている場合は省略可能で、それ以外の場合は必須です。
</ParamField>
