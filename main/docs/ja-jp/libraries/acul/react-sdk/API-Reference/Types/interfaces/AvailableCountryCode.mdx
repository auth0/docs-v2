---
title: "利用可能な国コード"
---

```ts Example
export interface AvailableCountryCode {
  code: string;
  label: string;
  dialCode: string;
}
```

## プロパティ {#properties}

<ParamField body="code" type="string">
  ISO 3166-1 alpha-2の国コード (例：`"US"`) 。`phoneCountryCode` として送信されます。リスト内で一意ではなく、複数のダイヤルコードを持つ国はコードごとに1件ずつ含まれます。
</ParamField>

<ParamField body="dialCode" type="string">
  先頭にプラス記号が付いたダイヤルコード (例：`"+1"`) 。表示専用です。
</ParamField>

<ParamField body="label" type="string">
  レンダリングロケールに合わせてローカライズされた国名。
</ParamField>
