title: "UserMembers"
---

```ts Example
export interface UserMembers {
  id: string | null;
  email: string | null;
  username: string | null;
  phoneNumber: string | null;
  picture: string | null;
  enrolledFactors: Array<string> | null;
  enrolledEmails: Array<EnrolledEmail> | null;
  enrolledPhoneNumbers: Array<EnrolledPhoneNumber> | null;
  enrolledDevices: Array<EnrolledDevice> | null;
  organizations: Organizations[] | null; // OPT-IN 
  userMetadata: { [key: string]: string } | null; // OPT-IN
}
```

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  * OPT-IN: これらのプロパティを画面で使用できるようにするには、明示的に設定する必要があります。詳細については、[ACUL を設定する](/docs/ja-jp/customize/login-pages/advanced-customizations/configure)を参照してください。

  * Auth0 サーバーが現在のユーザーを認識していない場合、以下の画面では `user` プロパティを使用できません。

  | 画面       | 画面              | 画面           | 画面                     |
  | -------- | --------------- | ------------ | ---------------------- |
  | Login 画面 | MFA OTP 画面      | 招待を承諾する画面    | InterstitialCaptcha 画面 |
  | サインアップ画面 | MFA Phone 画面    | デバイスコード画面    | パスワードリセット画面            |
  | パスキー画面   | MFA プッシュ画面      | メール認証画面      | MFA 国番号画面              |
  | チャレンジ画面  | MFA リカバリーコード画面  | ログアウト中止画面    | MFA ブラウザー機能検出画面        |
  | メール識別子画面 | MFA WebAuthn 画面 | ログアウト完了画面    | MFA 登録画面               |
  | 電話識別子画面  | 招待を承諾する画面       | ブルートフォース対策画面 |                        |
</Callout>
