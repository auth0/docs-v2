---
title: "ログインオプション"
---

```ts Example
export interface LoginOptions {
  username?: string;
  identifier?: string;
  identifierType?: IdentifierType;
  phoneCountryCode?: string;
  captcha?: string;
  [key: string]: string | number | boolean | undefined;
}
```

## インデックス可能 {#indexable}

[`key`: `string`]: `string` | `number` | `boolean` | `undefined`

## プロパティ {#properties}

<ParamField body="captcha?" type="string" />

<ParamField body="identifier?" type="string">
  ログインに使用する識別子です。`identifierType` に応じて、email、ユーザー名、または電話番号になります。`username` が指定されている場合は省略可能で、両方が指定された場合は `identifier` が優先されます。
</ParamField>

<ParamField body="identifierType?" type={<span><a href="/docs/ja-jp/libraries/acul/react-sdk/API-Reference/Types/type-aliases/IdentifierType">IdentifierType</a></span>}>
  `identifier`(または `username`)が保持する値の種類です。通常は `screen.data.activeIdentifierType` から読み取ります。省略すると、種類を指定せずに識別子を送信します。
</ParamField>

<ParamField body="phoneCountryCode?" type="string">
  電話番号の識別子に使用する ISO 3166-1 alpha-2 の国コードで、`countryCodes.available` 内の `code` から指定します。`identifierType` が `phone` の場合は必須です。国内番号を渡してください。国番号はサーバー側で付加されます。
</ParamField>

<ParamField body="username?" type="string">
  ユーザーの識別子を、元の表記のまま指定します。`identifier` が指定されている場合は省略可能で、指定されていない場合は必須です。
</ParamField>
