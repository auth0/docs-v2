エージェントによる操作に対してトークンが発行されると、Auth0は生成されるテナントログのエントリに、`agent_id`と、設定されている場合は`external_agent_id`の両方を含めます。

## サポートされる付与タイプ {#supported-grant-types}

Auth0は、次の付与タイプについてエージェントのアイデンティティをログに記録します：

* エージェントに紐付けられたクライアントからの`client_credentials`付与
* エージェントに紐付けられたクライアントに対する`refresh_token`付与
* OBOトークン交換の付与
* クライアントがエージェントに紐付けられている場合の標準的なログインの付与

## ログのクエリ {#query-logs}

Management API のログエンドポイントから `agent_id` をクエリできるため、エージェント単位の監査や異常検知が可能になります。

```http
GET /api/v2/logs?q=agent_id:agt_72jbvv7LfRKYp59gtRLtkn
```

テナントログのクエリとストリーミングについて詳しくは、[ログ検索クエリ構文](/docs/ja-jp/deploy-monitor/logs/log-search-query-syntax)と[ログストリーム](/docs/ja-jp/customize/log-streams)をご覧ください。
