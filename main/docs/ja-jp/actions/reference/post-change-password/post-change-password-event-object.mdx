      接続の種類。ソーシャル接続の場合、`event.connection.strategy === event.connection.name` となります。エンタープライズ接続の場合、strategy には `waad` (Windows Azure AD) 、`ad` (Active Directory/LDAP) 、`auth0` (データベース接続) などがあります。
    </ResponseField>
  </Expandable>
</ResponseField>
