  <Accordion title="My Account API: Free サブスクリプションの My Account API エンドポイントに対するレート制限。">
    各 My Account API エンドポイントには、2 つのレート制限ポリシーが適用されます。主要なガードとなるテナント単位のポリシー (スコープ: tenant、間隔: second) と、補助的なガードとなるユーザー単位のポリシー (スコープ: tenant + user、間隔: minute) です。一部のポリシーは endpoint&#95;params に分類され、特定のクエリパラメーター (例: ?type=) が指定された場合にのみ適用され、物理的なエンドポイントを同系のポリシーと共有します。

    テナントレベル:

    | リソース                                                                            | バースト上限 | 継続上限 | 更新レート  | スコープ   |
    | ------------------------------------------------------------------------------- | ------ | ---- | ------ | ------ |
    | My Account API Rate Limit – Authentication Methods Read (Tenant Scope)          | 2      | 2    | second | Tenant |
    | My Account API Rate Limit – Authentication Methods Read Filtered (Tenant Scope) | 5      | 5    | second | Tenant |
    | My Account API Rate Limit – Authentication Methods Write (Tenant Scope)         | 2      | 2    | second | Tenant |
    | My Account API Rate Limit – Connected Accounts Create Flow (Tenant Scope)       | 1      | 1    | second | Tenant |
    | My Account API Rate Limit – Connected Accounts Read Accounts (Tenant Scope)     | 1      | 1    | second | Tenant |
    | My Account API Rate Limit – Connected Accounts Read Connections (Tenant Scope)  | 1      | 1    | second | Tenant |
    | My Account API Rate Limit – Connected Accounts Write (Tenant Scope)             | 1      | 1    | second | Tenant |
    | My Account API Rate Limit – Factors Read (Tenant Scope)                         | 25     | 25   | second | Tenant |
    | My Account API Rate Limit – Organizations Read (Tenant Scope)                   | 5      | 5    | second | Tenant |

    テナント、ユーザーレベル:

    | リソース                                                                          | バースト上限 | 継続上限 | 更新レート  | スコープ         |
    | ----------------------------------------------------------------------------- | ------ | ---- | ------ | ------------ |
    | My Account API Rate Limit – Authentication Methods Read (User Scope)          | 2      | 2    | minute | Tenant, User |
    | My Account API Rate Limit – Authentication Methods Read Filtered (User Scope) | 5      | 5    | minute | Tenant, User |
    | My Account API Rate Limit – Authentication Methods Write (User Scope)         | 2      | 2    | minute | Tenant, User |
    | My Account API Rate Limit – Connected Accounts Create Flow (User Scope)       | 10     | 10   | minute | Tenant, User |
    | My Account API Rate Limit – Connected Accounts Read Accounts (User Scope)     | 5      | 5    | minute | Tenant, User |
    | My Account API Rate Limit – Connected Accounts Read Connections (User Scope)  | 5      | 5    | minute | Tenant, User |
    | My Account API Rate Limit – Connected Accounts Write (User Scope)             | 5      | 5    | minute | Tenant, User |
    | My Account API Rate Limit – Factors Read (User Scope)                         | 5      | 5    | minute | Tenant, User |
    | My Account API Rate Limit – Organizations Read (User Scope)                   | 1      | 1    | minute | Tenant, User |
  </Accordion>

  <Accordion title="SCIM API: エンタープライズ接続を含むパブリッククラウドのサブスクリプションにおける、Inbound SCIM API エンドポイントのレート制限。">
    接続とテナントの制限は、すべてのリクエストで順に評価されます。まず接続の制限が確認され、接続の制限を超えていない場合にのみテナントの制限が確認されます。

    接続、テナントレベル:

    | リソース | バースト制限 | 継続制限 | 更新レート | スコープ |
    | ---- | ------ | ---- | ----- | ---- |

    テナントレベル:

    | リソース                                             | バースト制限 | 継続制限 | 更新レート | スコープ |
    | ------------------------------------------------ | ------ | ---- | ----- | ---- |
    | SCIM API レート制限 – テナントスコープ (すべての SCIM エンドポイントに適用) | 5      | 5    | 秒     | テナント |
  </Accordion>

  <Accordion title="My Organization API: FreeサブスクリプションにおけるMy Organization APIのレート制限。">
    2 段構成のレート制限: org バケット (主となるもので、レスポンスヘッダーに反映されます) + テナントバケット (テナント内のすべての org を通じた副次的な上限)。

    テナントレベル:

    | リソース                                          | バースト上限 | 継続上限 | 更新レート | スコープ   |
    | --------------------------------------------- | ------ | ---- | ----- | ------ |
    | My Org API のレート制限 – 読み取りエンドポイント (Tenant スコープ) | 8      | 4    | 秒     | Tenant |
    | My Org API のレート制限 – 書き込みエンドポイント (Tenant スコープ) | 4      | 2    | 秒     | Tenant |

    Organization レベル:

    | リソース                                                | バースト上限 | 継続上限 | 更新レート | スコープ         |
    | --------------------------------------------------- | ------ | ---- | ----- | ------------ |
    | My Org API のレート制限 – 読み取りエンドポイント (Organization スコープ) | 8      | 4    | 秒     | Organization |
    | My Org API のレート制限 – 書き込みエンドポイント (Organization スコープ) | 4      | 2    | 秒     | Organization |
  </Accordion>
