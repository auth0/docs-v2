以下に、Private Cloud Performance 3000 RPS (30x) および 3000 RPS (30x) Burst の各サブスクリプションタイプにおけるレート制限を示します。これらの制限は、Private Cloud 環境で作成する各テナントに適用されます。

そのため、リスク軽減の観点から、Private Cloud 環境ごとに 1 つのテナントをデプロイすることを推奨します。
