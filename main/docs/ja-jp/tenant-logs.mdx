---
title: テナントログカタログ
sidebarTitle: 概要
description: すべての Auth0 テナントログのイベントタイプ（スキーマとフィールド定義を含む）を参照・検索します。
---

テナントログカタログは、すべての Auth0 テナントログのイベントタイプを検索できるリファレンスです。各エントリには、完全なスキーマ、フィールド定義、説明が含まれており、Auth0 が生成するデータの理解や、信頼性の高い連携の構築に役立ちます。

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  ログの保持期間はサブスクリプションレベルによって異なります。詳細については、[ログデータの保持](/docs/ja-jp/deploy-monitor/logs/log-data-retention)をご覧ください。
</Callout>

<div id="use-cases">
  ## ユースケース
</div>

Auth0 では、ビジネスニーズに応じて分析できるログを提供しています。以下のことが可能です。

* テナント管理者が実行した操作を表示する。
* <Tooltip tip="Management API: 顧客が管理タスクを実行できるようにする製品。" cta="用語集を表示" href="/docs/ja-jp/glossary?term=Management+API">Management API</Tooltip> を介して実行された操作を表示する。
* ユーザーによる認証を表示する。
* 品質保証テストでは見つけにくい断続的なエラーを表示する。
* セキュリティ上の調査や異常検出トリガーの特定に役立つデータを収集する。
* 使用傾向のパターンを特定する。
* 認証エラーや Management API 呼び出しエラーを確認する。
* レート制限に達するアクティビティがユーザーに影響を及ぼす前に事前に対処できるよう、レート制限エラーを確認するための自動ログスキャンを設定する。
* `X-Correlation-ID` ヘッダーの値を照合して、Management API イベントを開始元のリクエストに関連付ける。
