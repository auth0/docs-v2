## WhatsAppのトークンを取得する {#get-your-whatsapp-token}

[WhatsApp](https://developers.facebook.com/blog/post/2022/12/05/auth-tokens/)でtokenを生成する方法をご確認ください。

## WhatsApp Vault 接続を設定する {#configure-your-whatsapp-vault-connection}

WhatsApp Flow Actions 用の WhatsApp Vault 接続を設定するには、必要なパラメータを設定します。

<Frame>![Auth0 Dashboard > Actions > フォーム > Vault > WhatsApp](/docs/images/customize/forms/vaults/whatsapp-vault-connection.png)</Frame>

### 入力設定 {#input-settings}

| パラメータ | 説明                           |
| ----- | ---------------------------- |
| Token | WhatsApp API の認証用に生成されたトークン。 |
