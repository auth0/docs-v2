この XML Actions の一覧では、JSON オブジェクトを XML 文字列に、XML 文字列を JSON オブジェクトに変換できます。

## JSONをXMLに変換 {#convert-json-to-xml}

JSON オブジェクトをXML 文字列に変換します。

<Frame>![](/docs/images/cdy7uua7fh8z/3GW2EhBMIX3YDPaqc3rXrZ/7706a863700df51376d645a7d9292a27/convertjsontoxml.png)</Frame>

### 入力設定 {#input-settings}

| パラメータ     | 説明                     |
| --------- | ---------------------- |
| JSON (必須) | XML文字列に変換するJSONオブジェクト。 |

### 出力オブジェクト {#output-object}

| プロパティ | 型      | 説明           |
| ----- | ------ | ------------ |
| `xml` | String | 変換されたXML文字列。 |

### 出力オブジェクトの例 {#output-object-example}

```json lines
{
  "xml": "<?xml version=\"1.0\" encoding=\"UTF-8\" standalone=\"yes\"?>\n<name>John Doe</name>"
}
```

## XMLをJSONに変換 {#convert-xml-to-json}

XML文字列をJSONオブジェクトに変換します。

<Frame>![](/docs/images/cdy7uua7fh8z/42fO7BelEN4bnlUj70WhV8/e53ada552f7cc05c192466db4777471a/covertxmltojson.png)</Frame>

### 入力設定 {#input-settings-2}

| パラメータ    | 説明                                |
| -------- | --------------------------------- |
| XML (必須) | JSONオブジェクト に変換される XML文字列 です。 |

### 出力オブジェクト {#output-object-2}

| プロパティ    | 型      | 説明              |
| -------- | ------ | --------------- |
| `object` | オブジェクト | 変換後のJSONオブジェクト。 |

### 出力オブジェクトの例 {#output-object-example-2}

```json lines
{
  "object": {
    "name": "John Doe"
  }
}
```
