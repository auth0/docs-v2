この JSON アクションの一覧では、JSON オブジェクトの作成、JSON の解析、JSON の文字列への変換を行えます。

## JSON オブジェクトを作成 {#create-json-object}

JSON オブジェクトを作成します。これは特に、フロー内の他の Actions でその内容を再利用する場合に便利です。

<Frame>![](/docs/images/cdy7uua7fh8z/1zJEENRPI2uONuCApPY98p/f1fce88a42fb13fb9856c95c562bd506/createjsonobject.png)</Frame>

### 入力設定 {#input-settings}

| パラメーター | 説明           |
| ------ | ------------ |
| Body   | JSON オブジェクト。 |

### 出力オブジェクト {#output-object}

| プロパティ    | 型      | 説明           |
| -------- | ------ | ------------ |
| `result` | オブジェクト | JSON オブジェクト。 |

### 出力オブジェクトの例 {#output-object-example}

```json lines
{
	"result": {
		"name": "John Doe"
	}
}
```

## JSONを解析 {#parse-json}

テキスト文字列に含まれるJSONオブジェクトを、JSONオブジェクトとして解析します。

<Frame>![](/docs/images/cdy7uua7fh8z/5HjIGbBiWik1XozAZczxg5/fe2b0c6f7c657c4209921f1a0978e54b/parsejson.png)</Frame>

### 入力設定 {#input-settings-2}

| パラメータ             | 説明       |
| ----------------- | -------- |
| JSON string (必須)  | JSON文字列。 |

### 出力オブジェクト {#output-object-2}

| プロパティ    | 型      | 説明                |
| -------- | ------ | ----------------- |
| `object` | オブジェクト | パースされたJSONオブジェクト。 |

### 出力オブジェクトの例 {#output-object-example-2}

```json lines
{
  "object": {
    "name": "John Doe"
  }
}
```

## JSONを文字列に変換 {#convert-json-to-string}

JSONオブジェクトを文字列に変換します。

<Frame>![](/docs/images/cdy7uua7fh8z/45acWYMlTGc5ZWMzK5Cqqr/6974ea640a76d2d9cc5814225e52734a/convertjsontostring.png)</Frame>

### 入力設定 {#input-settings-3}

| パラメータ             | 説明                           |
| ----------------- | ---------------------------- |
| JSON オブジェクト (必須)  | 文字列にシリアライズされる JSON オブジェクトです。 |

### 出力オブジェクト {#output-object-3}

| プロパティ  | 型      | 説明                      |
| ------ | ------ | ----------------------- |
| `json` | String | シリアル化された JSON オブジェクトです。 |

### 出力オブジェクトの例 {#output-object-example-3}

```json lines
{
  "json": "{\"name\":\"John Doe\"}"
}
```
