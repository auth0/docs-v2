## アクション {#action}

次の Pre User Registration アクションは、禁止されたメールドメインからのサインアップを拒否し、氏名の入力を必須としたうえで、その氏名を `user_metadata` に、ランダムに生成した識別子を `app_metadata` に保存します。

## ユニットテスト {#unit-test}

ユニットテストでは `event` と `api` オブジェクトをモックし、禁止されたドメインが拒否されること、氏名が未入力の場合に検証エラーが発生すること、有効な送信では氏名と正しい形式のUUIDが保存されることを検証します。
