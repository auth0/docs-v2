## プロジェクト {#project}

各サンプルでは、アクションのソースコードを `src/` 配下、ユニットテストを `test/` 配下に分けており、JavaScript プロジェクトと TypeScript プロジェクトのいずれも同じ構成になっています。

## アクション {#action}

次の Post Login アクションは、`event.authorization` からユーザーのロールを取得し、IDトークンのカスタム claim として設定します。ロールが存在しない場合はアクセスを拒否します。

  </Tab>

  </Tab>
</Tabs>

## ユニットテスト {#unit-test}

ユニットテストでは `event` と `api` オブジェクトをモックし、管理者ユーザーにはカスタム claim が設定される一方、ロールを持たないユーザーや `authorization` オブジェクトがないユーザーはアクセスが拒否されることを検証します。
