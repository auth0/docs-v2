各サンプルでは、アクションのソースコードを `src/` に、そのユニットテストを `test/` に分けて配置しており、JavaScript プロジェクトと TypeScript プロジェクトのいずれも同じ構造になっています。

## アクション {#action}

次の Post Login アクションは、マーケティング同意フォームにまだ回答していないユーザーに対してそのフォームを表示し、次回の login 試行時に送信された回答を処理します。フォームがスキップされた場合はアクセスを拒否し、それ以外の場合は同意の選択内容を `user_metadata` に保存します。

## ユニットテスト {#unit-test}

ユニットテストでは `event` と `api` オブジェクトをモックし、同意が未回答の場合にのみフォームが表示されること、承諾・拒否いずれの同意の送信も正しく保存され、送信内容が欠けている場合は拒否されることを検証します。
