[`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions) NPM パッケージを使用すると、Actions のユニットテストを記述し、ローカル環境やバージョン管理、CI/CD プロセス上で実行できます。これにより、問題が Auth0 テナントに及ぶ前に検出できます。

## 仕組み {#how-it-works}

インストールとインポートについては、[Actions NPMの仕組み](/docs/ja-jp/customize/actions/npm/write-your-action-using-your-code-editor)に記載されているガイドラインに従ってください。

Actionをユニットテストするには、Action関数が受け取る`event`オブジェクトと`api`オブジェクトをモックする必要があります。これらのモックは`auth0/actions`に含まれるTypeScript定義を使って作成でき、テストが本番環境を正確に反映するようになります。モックの管理や機能の検証には、Jestなどのテストフレームワークが最適です。
