title: Actions Modules

Actions Modulesを使用すると、Auth0テナント内の異なるActions間で再利用可能なコードを作成、管理、共有できます。

従来は各Actionが独立して動作していたため、NPMモジュールなどの外部依存関係を使用せずに共通の関数を共有することは困難でした。Actions Modulesを使えば、次のことが可能になります：

* Auth0がホストする関数を持つカスタムモジュールを作成する。
* 各カスタムモジュールで定義した関数を1つ以上のAction内で使用する。
* 各カスタムモジュールで独立したシークレットを定義し、NPMモジュールへの依存関係を追加する。

Actions Modulesを使ったActionの記述について詳しくは、[最初のAction Moduleを作成する](/docs/ja-jp/customize/actions/modules/write-your-first-action-module)をお読みください。

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  Actions Modulesは特定のトリガーやActionの種類に紐付けられていないため、そこで定義した関数は、異なるトリガーにバインドされたAction間で再利用できます。
</Callout>

Actions Modulesの制限について詳しくは、[Actionsの制限](/docs/ja-jp/customize/actions/limitations)をお読みください。

## パフォーマンス {#performance}

[コーディングガイドライン](/docs/ja-jp/customize/actions/action-coding-guidelines)に従ってActions Modulesを採用すると、インスタンス化のコストが高いobjectを共有・再利用できるため、実行パフォーマンスを向上させられます。

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  ただし、向上の度合いは具体的なユースケースや実装、実行の負荷と頻度によって変わるため、必ず改善されるとは限りません。
</Callout>
