[`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions) NPMパッケージは、Auth0 Actions向けの公式TypeScript／JavaScript型定義ライブラリです。Auth0 Dashboardの外、つまりお使いのコードエディターでActionsを記述する場合でも、IDEのサポートや型チェック、構造化されたコード記述が可能になります。

## メリット {#benefits}

* **IDE/コードエディターの支援**: Actions 内の `event` および `api` オブジェクトについて、自動補完、インラインドキュメント、型ヒントを利用できます。
* **TypeScript での開発**: 型安全性を完全に確保した TypeScript で Actions を記述でき、導入前にエラーを検出できます。
* **ユニットテストの改善**: 同梱の型定義を使用して、テスト用に `event` および `api` オブジェクトの正確なモックを作成できます。
* **AI による Actions の生成**: AI コーディングアシスタントにより適切なコンテキストを提供し、生成される Action コードの品質を高められます。

## 仕組み {#how-it-works}

[`@auth0/actions`](https://www.npmjs.com/package/@auth0/actions) をプロジェクトの開発依存関係としてインストールし、その型をインポートすれば、Auth0 Dashboard の外部で Actions のコードを記述できます。このパッケージには、Auth0 が実行時に Action へ渡す `event` と `api` の各 オブジェクト の型定義が含まれているため、コードを書きながらエディターでデータの構造を検証できます。

これらの型は Dashboard のランタイムが提供するものと一致しているため、ローカルで記述して型チェックした Action は、導入後もまったく同じように動作します。

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
  `@auth0/actions` パッケージはオープンソースです。ソースコードの確認、問題の報告、コントリビュートは [auth0/auth0-actions](https://github.com/auth0/auth0-actions) から行えます。
</Callout>
