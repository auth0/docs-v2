---
title: Actions リファレンス
description: Dev Tools 配下にある Actions リファレンスカタログで、各トリガーにおいて Auth0 Actions で利用可能なイベントオブジェクトと API オブジェクトを確認できます。
---

Actions リファレンスでは、各 Actions トリガーでカスタムコードから利用できる**イベントオブジェクト** (読み取り専用のトランザクションコンテキスト) と**API オブジェクト** (トランザクションの動作を変更するメソッド) について説明します。

このリファレンスは現在、**Dev Tools** 配下の専用カタログにあり、API、SDK、イベントカタログのリファレンスと並んでいます。

<a href="/docs/ja-jp/actions/reference" target="_blank" rel="noopener noreferrer">
  <Card title="Actions リファレンスカタログ" icon="book-open" iconType="solid">
    すべての Actions トリガーのイベントオブジェクトと API オブジェクトのリファレンスを確認できます。新しいタブで開きます。
  </Card>
</a>

各トリガーがいつ実行されるか、および Actions がどのように関連付けられるかについては、[トリガーを確認する](/docs/ja-jp/customize/actions/explore-triggers)を参照してください。
