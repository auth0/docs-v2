The Security AI Agent monitors your Auth0 tenant for identity-based attacks, analyzes anomalous activity, and delivers remediation recommendations to your security team in Slack. When the agent detects an attack, your team can investigate, review recommendations, and apply configuration changes without leaving Slack.

Security AI Agent is powered by Okta AI. All changes the agent applies are logged in your tenant logs under the approving administrator's identity. No configuration changes are made to your tenant without explicit approval from an authenticated Auth0 administrator.

## How it works

Security AI Agent runs a continuous detection and response cycle:

| **Stage** | **Description** |
|---|---|
| Detect | The agent monitors your tenant's rate limit responses (`HTTP 429` errors). When the rate exceeds the threshold continuously for 15 minutes, the agent posts an alert to your designated Slack channel. |
| Investigate | An investigation is initiated from Slack. The agent analyzes your tenant's authentication logs, IP addresses, JA4 fingerprints, user agent strings, and traffic patterns to classify the attack and generate a triage report. |
| Recommend | Based on the triage report and your current tenant configuration, the agent surfaces up to three prioritized remediation options. |
| Action | An authenticated Auth0 administrator, a human-in-the-loop, reviews and applies recommendations directly from Slack. Every applied action is logged in your tenant logs under the administrator's identity. |

## Detect

The Security AI Agent detects rate limit anomalies and distributed credential stuffing attacks that deliberately stay below rate limit thresholds.

## Investigate

From Slack, the Security AI Agent reviews accessible data types you allow the agent to access, like tenant logs and traffic signals.

## Recommend

When the agent identifies a threat, it can recommend the following configuration changes based on your current tenant setup:

- [Bot Detection](/docs/secure/attack-protection/bot-detection) sensitivity and challenge policy adjustments
- [Breached Password Detection](/docs/secure/attack-protection/breached-password-detection) — enable and set shields to block
- [Suspicious IP Throttling](/docs/secure/attack-protection/suspicious-ip-throttling) — enable and set shields to block
- [Brute Force Protection](/docs/secure/attack-protection/brute-force-protection) — enable and set shields to block
- [Tenant ACL](/docs/secure/tenant-access-control-list) rules to block specific IP addresses or JA4 fingerprints identified as attack sources

<Warning>
Before applying Tenant ACL recommendations, confirm your proxy configuration preserves the original client IP address. Blocking a proxy IP address stops all traffic routed through it, not just attack traffic.
</Warning>

## Data access

Security AI Agent accesses the following data from your Auth0 tenant. Data access is scoped to your own tenant only.

| **Data type** | **Purpose** |
|---|---|
| Authentication event logs | Baseline comparison and anomaly detection from the last 28 days. |
| Traffic signals | Attack classification and scope analysis of IP data, JA4 fingerprints, geographic data, user agent data |
| Tenant configuration | Generating accurate, context-aware recommendations based on Attack Protection settings and your Tenant ACL rules |
| Rate limit data | Anomaly detection of `HTTP 429` error counts and rates |

## Roles

| **Capability** | **Anyone in the channel** | **Authenticated Auth0 administrator** |
|---|---|---|
| View alert cards and investigation threads | ✓ | ✓ |
| Apply recommendations | | ✓ |

Any team member with access to the Slack channel can follow an active incident in real time. Only authenticated Auth0 administrators can apply configuration changes.

## Limitations

- Detection covers rate limit anomalies and distributed credential stuffing attacks.
- Alert cards show absolute traffic levels, not deviation from your historical baseline.
- Security AI Agent supports one Auth0 tenant per Slack workspace installation.
- Security AI Agent is available in Slack only.
- Only users with the Auth0 Tenant Administrator role can authenticate in Slack and apply recommendations.
