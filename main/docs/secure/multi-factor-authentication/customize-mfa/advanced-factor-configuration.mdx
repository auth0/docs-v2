Advanced Factor Configuration allows tenant administrators to: 
* Customize length and expirty time of one-time passwords (OTPs) for phone (SMS and Voice) and email MFA factors 
* Control the visibility and default state of the **Remember this device** checkbox in your MFA prompts

<Warning>
Customers are responsible for any diminishment in security posture resulting from a change to: (i) the Code Expiration Time or "Remember Me" Session Behavior lifespan to a time period longer than Okta's standard recommended setup; or (ii) the OTP Length to a shorter character length than Okta's standard recommended setup.
</Warning>

## OTP code settings

You can configure OTP code length and expiration time independently for the phone (SMS and Voice) and email factors. Settings apply to all users on your tenant.

| Setting | Default | Range |
| --- | --- | --- |
| OTP Length | 6 digits | 4–10 digits |
| OTP Expiration Time | 300 seconds (5 minutes) | 30–3600 seconds (1 minute–1 hour) |

### Configure phone factor OTP settings

OTP settings for the phone (SMS and Voice) factor can be configured using either the Auth0 Dashboard or the Management API.

<Tabs>
  <Tab title="Auth0 Dashboard">

1. Navigate to [Dashboard > Security > Multi-Factor Auth](https://manage.auth0.com/#/security/mfa). 
2. Under Factors, select **Phone Message** and configure the following:
  - **Code Length**: Enter a value between 6 and 10 digits.
  - **Code Lifetime**: Enter a value between 30 and 3600 seconds.
  </Tab>
  <Tab title="Management API">
    **Required scopes:** `read:guardian_factors` (GET), `update:guardian_factors` (PUT)

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">
    The Dashboard displays expiration time in minutes. The Management API uses seconds. When calling the API directly, use seconds (30–3600).
    </Callout>

    To retrieve current phone factor OTP settings, send a `GET` request to `/api/v2/guardian/factors/phone/settings`:

    ```json
    {
      "otp_length": 6,
      "otp_expiration_time": 300
    }
    ```

    To update phone factor OTP settings, send a `PUT` request to `/api/v2/guardian/factors/phone/settings`:

    ```json
    {
      "otp_length": 8,
      "otp_expiration_time": 600
    }
    ```
  </Tab>
</Tabs>

### Configure email factor OTP settings

OTP settings for the email factor can be configured using either the Auth0 Dashboard or the Management API.

<Tabs>
  <Tab title="Auth0 Dashboard">
    1. Navigate to [Dashboard > Security > Multi-Factor Auth](https://manage.auth0.com/#/security/mfa) and select **Email**.
    2. Under **Email**, configure the following:
       - **Verification Code Length**: Enter a value between 4 and 10 digits.
       - **Verification Code Lifetime**: Enter a value between 5 and 60 minutes.
    3. Select **Save**.
  </Tab>
  <Tab title="Management API">
    **Required scopes:** `read:guardian_factors` (GET), `update:guardian_factors` (PUT)

    <Callout icon="file-lines" color="#0EA5E9" iconType="regular">
    The Dashboard displays expiration time in minutes. The Management API uses seconds. When calling the API directly, use seconds (30–3600).
    </Callout>

    To retrieve current email factor OTP settings, send a `GET` request to `/api/v2/guardian/factors/email/settings`:

    ```json
    {
      "otp_length": 6,
      "otp_expiration_time": 300
    }
    ```

    To update email factor OTP settings, send a `PUT` request to `/api/v2/guardian/factors/email/settings`:

    ```json
    {
      "otp_length": 8,
      "otp_expiration_time": 600
    }
    ```
  </Tab>
</Tabs>

## Remember Me

The **Remember this device** checkbox in MFA prompts lets users skip MFA on subsequent logins from the same browser. You can control whether this checkbox appears and whether it is checked by default.

The **Remember this device** checkbox can be configured using either the Auth0 Dashboard or Auth0 Actions.

<Tabs>
  <Tab title="Auth0 Dashboard">
  1. Navigate to [Dashboard > Security > Multi-Factor Auth](https://manage.auth0.com/#/security/mfa).
  2. Scroll to Additional Settings.
  3. Toggle on **Allow User to Skip MFA on Trusted Browsers**.
  4. Select the checkbox by Remember browser by default.
  5. Configure Lifetime limits in hours or days:
       - **Idle Trusted Browser Lifetime**: Default is 7 days.
       - **Maximum Trusted Browser Lifetime**: Default is 30 days.

  </Tab>
  <Tab title="Auth0 Actions">
  Use the `allowRememberBrowser` property on the `api.multifactor.enable` call in a `post-login` Action:

    ```js
    exports.onExecutePostLogin = async (event, api) => {
      // Allow users to skip MFA on subsequent logins from the same browser
      api.multifactor.enable('any', { allowRememberBrowser: true });
    }
    ```

    | Value | Behavior |
    | --- | --- |
    | `true` | Users are shown the **Remember this device** checkbox and can choose to skip MFA on future logins from the same browser. |
    | `false` | The checkbox is hidden and users are prompted for MFA on every login. |

    To learn more about `allowRememberBrowser` and available options, read [Actions Triggers: post-login - API Object](/docs/customize/actions/explore-triggers/signup-and-login-triggers/login-trigger/post-login-api-object).
  </Tab>
</Tabs>
