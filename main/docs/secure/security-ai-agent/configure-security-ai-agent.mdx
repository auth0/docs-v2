Configure the [Security AI Agent](/docs/secure/security-ai-agent) to monitor your Auth0 tenant for identity attacks and receive remediation recommendations in Slack.

Setup involves two roles that are often different people:

| **Role** | **Responsibilities** |
|---|---|
| **Slack Workspace Owner or Administrator** | Creates the Slack application, installs it to the workspace, and provides credentials to the Auth0 administrator. |
| **Auth0 Tenant Administrator** | Configures Security AI Agent in the Auth0 Dashboard using the credentials provided by the Slack administrator. |

<Card title="Before you start">

- Verify your account is on an Auth0 Enterprise plan with the Attack Protection add-on enabled. To learn more, read [Manage your Auth0 Subscription Plan](/docs/troubleshoot/customer-support/manage-subscriptions).
- Ensure your organization has an active Slack workspace.
- If your organization enforces a Slack application approval policy, coordinate with your Slack administrator before starting. Approval can take several days.
- Create a dedicated Slack channel for security alerts before you begin (for example, `#auth0-security-alerts`). Restrict access to this channel to your security team, as alert cards contain tenant-specific data including IP addresses and rate metrics.

</Card>

## Create the Slack application

Your Auth0 contact provides a Slack application manifest as part of your onboarding package. The manifest pre-configures the application's name, OAuth scopes, and the webhook endpoint used to communicate with Auth0.

The Slack administrator completes this step.

1. Log in to [api.slack.com/apps](https://api.slack.com/apps).
2. Select **Create New App**.
3. Select **From a manifest**.
4. Choose your Slack workspace.
5. Paste in the manifest JSON provided by Auth0.
6. Review the configuration and select **Create**.

## Collect application credentials

After you create the application, the Slack administrator collects three values from the Slack application settings page.

1. Navigate to **Basic Information** and copy the **App ID** and **Signing Secret**.
2. Navigate to **Install App** and copy the **Bot User OAuth Token**.

Provide these values to your Auth0 administrator along with the Channel ID from the Configure your Slack channel step.

## Install the application in your workspace

1. In the Slack application settings, navigate to **Install App**.
2. Select **Install to Workspace**.
3. Review the permission scopes and select **Allow**.

## Configure your Slack channel

1. Invite the bot to your dedicated security channel using `/invite @[bot-name]`.
2. Collect the Channel ID: select the channel name, then select **Settings > About**, and scroll to the bottom to find the Channel ID (format: `C01234ABCDE`).
3. Provide the Channel ID to your Auth0 administrator along with the credentials from the Collect application credentials step.

## Configure Security AI Agent in the Auth0 Dashboard

The Auth0 administrator completes the remaining steps.

1. Navigate to [**Auth0 Dashboard > Security > Attack Protection > Security Agent**](https://manage.auth0.com/#/security-agent).
2. Enter the four values collected by the Slack administrator:
   - App ID
   - Signing Secret
   - Bot User OAuth Token
   - Channel ID

## Create the machine-to-machine application

Security AI Agent requires a machine-to-machine (M2M) application to access your tenant configuration with read-only permissions. The Security Agent configuration page prompts you to create one if none exists.

Select **Create M2M App** on the configuration page. This application gives Security AI Agent read-only access to your Attack Protection settings, Tenant ACL rules, and the data used to generate recommendations.

<Callout icon="file-lines" color="#0EA5E9" iconType="regular">
If the M2M application is deleted from your tenant after setup, the configuration page will show an error. Return to the configuration page to recreate it.
</Callout>

## Enable Security AI Agent

On the Security Agent configuration page, toggle on **Enable Security Agent**.

After you enable the agent, it begins monitoring your tenant's traffic. Your designated Slack channel will receive an alert the next time a sustained anomaly is detected.

## Verify setup

In your designated Slack channel, type `@[bot-name]` to mention the bot. If the bot responds with a help message, setup is complete.

If the bot does not respond, verify the following in [**Auth0 Dashboard > Security > Attack Protection > Security Agent**](https://manage.auth0.com/#/security-agent):

- The App ID, Signing Secret, Bot User OAuth Token, and Channel ID are entered and saved correctly. A copy-paste error such as a trailing space is the most common cause.
- The **Enable Security Agent** toggle is on.
- The M2M application is active.
